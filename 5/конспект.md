# ТЕОРИЯ

В задании 5 почти всегда нужно одно и то же: взять число `N`, построить по нему новую запись и получить число `R`. Сложной математики здесь обычно нет. Важнее не запутаться в преобразованиях и сразу понять, что требуется в ответе: само число `N` или уже результат `R`.

**Картина задания**

Структура задачи обычно такая:

| Шаг | Что происходит |
| --- | --- |
| 1 | Берётся натуральное число `N` |
| 2 | Строится его запись в некоторой системе счисления |
| 3 | Эта запись меняется по правилу |
| 4 | Полученная строка считается записью числа `R` |
| 5 | Нужно найти минимальное или максимальное значение по условию |

Чаще всего меняется не сама идея решения, а один из четырёх элементов:

- система счисления;
- правило изменения записи;
- конечное условие на `R`;
- то, что требуется найти: `N` или `R`.

**Главная идея решения**

В большинстве задач этого номера удобнее всего идти по такому плану:

1. перебрать возможные значения `N`;
2. построить нужную запись числа;
3. точно выполнить все преобразования по условию;
4. перевести результат в десятичную систему;
5. проверить условие и обновить ответ.

Такой путь надёжнее, чем сразу пытаться вывести формулу. Алгоритм в условии уже дан, значит, его проще спокойно воспроизвести в коде шаг за шагом.

**Базовый шаблон**

```python
for n in range(1, 1000):
    b = bin(n)[2:]          # или другая система счисления

    # изменение записи по условию

    r = int(b, 2)           # или int(b, 4), int(b, 12)

    # проверка условия
```

В этом шаблоне обычно меняются только две вещи:

- как строится строка `b`;
- по какому правилу обновляется ответ.

**Перевод чисел: что нужно знать обязательно**

**Встроенные функции**

Для стандартных систем счисления удобнее всего брать готовые функции:

| Функция | Что делает | Пример результата |
| --- | --- | --- |
| `bin(n)` | переводит в двоичную систему | `bin(13) -> '0b1101'` |
| `oct(n)` | переводит в восьмеричную систему | `oct(13) -> '0o15'` |
| `hex(n)` | переводит в шестнадцатеричную систему | `hex(31) -> '0x1f'` |

У этих функций есть служебный префикс, поэтому в задачах почти всегда сразу берут срез:

```python
b = bin(n)[2:]
```

`[2:]` убирает `0b`, `0o` или `0x`.

**Обратный перевод в десятичную систему**

Если запись числа уже хранится как строка, перевести её в десятичную систему можно через `int()`:

```python
int('101010101', 2)
int('123', 4)
int('1ab', 12)
```

Тут важно не забыть одно простое правило.

| Правильно | Неправильно |
| --- | --- |
| `int('111000011', 2)` | `int(111000011, 2)` |
| `int('1adffad222', 16)` | число без кавычек |

В таких задачах запись числа в системе счисления, отличной от десятичной, нужно хранить как строку.

**Нестандартные системы счисления**

Если основание не равно `2`, `8` или `16`, запись обычно строят вручную.

```python
from string import printable


def f(n, b):
    a = printable
    s = ''
    while n > 0:
        s = a[n % b] + s
        n //= b
    return s
```

Как работает эта функция:

| Часть кода | Роль |
| --- | --- |
| `a` | строка `printable`, из которой берутся нужные символы |
| `n % b` | последняя цифра записи в системе с основанием `b` |
| `a[n % b] + s` | добавление цифры в начало строки |
| `n //= b` | переход к следующему разряду |

Примеры использования:

```python
f(n, 4)
f(n, 12)
int(s, 4)
int(s, 12)
```

**Операции, которые встречаются чаще всего**

Ниже собраны действия, которые чаще всего повторяются в разных прототипах.

**1. Подсчёт цифр**

```python
sm = b.count('1')
```

Это удобно, когда правило зависит от количества единиц или от чётности суммы цифр.

**2. Дописывание справа**

```python
b = b + '0'
b = b + '11'
```

Так обычно добавляют бит чётности, остаток или несколько новых разрядов сразу.

**3. Замена всех вхождений**

```python
b = b.replace('1', '11')
b = b.replace('0', '00')
```

`replace()` подходит в тех задачах, где по условию нужно заменить все одинаковые символы сразу.

**4. Работа со срезами**

```python
b = '10' + b[2:] + '0'
```

Полезные срезы:

| Запись | Что означает |
| --- | --- |
| `b[:2]` | два первых разряда |
| `b[2:]` | строка без двух первых разрядов |
| `b[-2:]` | два последних разряда |

Срезы нужны там, где меняют только начало, конец или конкретный кусок записи.

**5. Вставка в середину**

```python
mid = len(b) // 2
b = b[:mid] + '111' + b[mid:]
```

Если длина строки чётная, центр находится между двумя половинами. Поэтому индекс середины удобно задавать как `len(b) // 2`.

**Как выбрать правильный способ перебора**

От вопроса в конце задачи зависит, что именно сохранять как ответ.

| Что спрашивают | Как действовать |
| --- | --- |
| минимальное `N` | перебирать `N` по возрастанию и остановиться на первом подходящем |
| максимальное `N` | перебирать все значения и обновлять ответ через `max()` |
| минимальное `R` | сохранять `R` через `min()` |
| максимальное `R` | сохранять `R` через `max()` |

**Если нужно минимальное `N`**

```python
for n in range(1, 1000):
    ...
    if condition:
        print(n)
        break
```

**Если нужно минимальное или максимальное `R`**

```python
ans = 10**9
for n in range(1, 1000):
    ...
    if condition:
        ans = min(ans, r)
```

Частая ошибка одна и та же: перебирают `N`, а в ответ по условию нужно записать не `N`, а `R`.

**На что смотреть в условии в первую очередь**

Перед тем как писать код, полезно быстро ответить на четыре вопроса:

1. В какой системе счисления строится исходная запись?
2. От чего зависит ветка алгоритма: от `N`, от суммы цифр, от длины строки, от остатка?
3. Что именно нужно сделать со строкой: дописать, заменить, вставить, взять последние цифры?
4. Что требуется найти в ответе: `N` или `R`?

Если на эти четыре вопроса есть ответ, решение обычно уже складывается само.

**Типичные ошибки**

| Ошибка | Что нужно делать правильно |
| --- | --- |
| передавать в `int()` число, а не строку | запись в другой системе хранить в кавычках |
| забывать убрать `0b`, `0o`, `0x` | использовать `[2:]` |
| путать `N` и `R` | отдельно проверить, что именно требует задача |
| использовать `replace()` вместо срезов | заменять только те разряды, о которых сказано в условии |
| неверно искать центр строки | брать `len(b) // 2` |
| дописывать остаток как десятичное число | сначала перевести его в нужную систему счисления |

**Короткая шпаргалка**

| Что нужно | Запись |
| --- | --- |
| десятичное → двоичное | `bin(n)[2:]` |
| двоичное → десятичное | `int(s, 2)` |
| четверичное → десятичное | `int(s, 4)` |
| двенадцатеричное → десятичное | `int(s, 12)` |
| посчитать единицы | `b.count('1')` |
| заменить все единицы | `b.replace('1', '11')` |
| взять две последние цифры | `b[-2:]` |
| убрать два первых разряда | `b[2:]` |

## Прототип 1. Повторения

**Текст задания**

На вход алгоритма подаётся натуральное число `N`. Алгоритм строит по нему новое число `R` следующим образом.

1. Строится двоичная запись числа `N`.
2. К этой записи дописываются справа ещё два разряда по следующему правилу:
   - складываются все цифры двоичной записи, и остаток от деления суммы на 2 дописывается в конец числа;
   - над этой записью производятся те же действия: справа дописывается остаток от деления суммы цифр на 2.

Полученная таким образом запись является двоичной записью искомого числа `R`. Укажите такое наименьшее число `N`, для которого результат работы алгоритма больше `125`. В ответе запишите это число в десятичной системе счисления.

**Идея решения**

Нужно перебрать значения `N`, для каждого построить двоичную запись и дважды дописать справа бит чётности. После этого остаётся перевести запись в десятичную систему и найти первое значение, при котором `R > 125`.

**Код решения**

```python
for n in range(1, 1000):
    b = bin(n)[2:]

    sm = b.count('1')
    b = b + str(sm % 2)

    sm = b.count('1')
    b = b + str(sm % 2)

    r = int(b, 2)
    if r > 125:
        print(n)
        break
```

**Разбор решения**

Сначала программа строит двоичную запись числа `N`. Переменная `sm` хранит количество единиц в текущей строке. Остаток `sm % 2` и есть нужный бит: `0`, если сумма цифр чётная, и `1`, если нечётная.

После первого дописывания строка меняется, поэтому количество единиц нужно посчитать заново. Старое значение `sm` уже не подходит: второй бит зависит от новой записи.

Дальше строка `b` переводится в число `r`. Поскольку по условию нужно минимальное `N`, перебор идёт по возрастанию, а программа останавливается на первом подходящем значении.

**Ответ**

`31`

## Прототип 2. Замены и новое конечное условие

**Текст задания**

На вход алгоритма подаётся натуральное число `N`. Алгоритм строит по нему новое число `R` следующим образом.

1. Строится двоичная запись числа `N`.
2. Далее эта запись обрабатывается по следующему правилу:
   - если число `N` чётное, то в этой записи каждая единица заменяется на `11`;
   - если число `N` нечётное, то в этой записи каждый нуль заменяется на `00`.

Полученная таким образом запись является двоичной записью искомого числа `R`. Укажите максимальное число `N`, после обработки с помощью этого алгоритма дающее число `R`, меньшее `70`, но отличное от самого `N`.

**Идея решения**

В этом прототипе ветка алгоритма выбирается по чётности самого числа `N`, а не по тому, какой стала строка после преобразования. После замены запись переводится в десятичную систему, и дальше остаётся отобрать те `N`, для которых выполнены условия `R < 70` и `R != N`.

**Код решения**

```python
ans = 0

for n in range(1, 1000):
    b = bin(n)[2:]

    if n % 2 == 0:
        b = b.replace('1', '11')
    else:
        b = b.replace('0', '00')

    r = int(b, 2)
    if r < 70 and r != n:
        ans = max(ans, n)

print(ans)
```

**Разбор решения**

Основа решения та же: перебираем `N`, строим двоичную запись и потом переводим результат обратно в десятичную систему. Отличие в самом преобразовании: тут ничего не дописывают по одному символу, а сразу заменяют все `0` или все `1`.

`replace('1', '11')` удваивает каждую единицу, а `replace('0', '00')` удваивает каждый нуль. Поэтому `replace()` тут подходит лучше всего: нужно изменить все такие символы сразу.

В конце проверяются два условия:

- `r < 70`;
- `r != n`.

Так как требуется максимальное `N`, ответ обновляется через `max(ans, n)`.

**Ответ**

`29`

## Прототип 3. Нестандартная система счисления

**Текст задания**

На вход алгоритма подаётся натуральное число `N`. Алгоритм строит по нему новое число `R` следующим образом.

1. Строится четверичная запись числа `N`.
2. Далее эта запись обрабатывается по следующему правилу:
   - если число `N` делится на `4`, то к этой записи дописываются две последние четверичные цифры;
   - если число `N` на `4` не делится, то остаток от деления умножается на `2`, переводится в четверичную систему и дописывается в конец числа.

Полученная таким образом запись является четверичной записью искомого числа `R`. Укажите максимальное число `N`, после обработки которого получается число `R`, меньшее `261`.

**Идея решения**

Главное отличие этого прототипа в системе счисления: исходная запись строится не в двоичной, а в четверичной. Поэтому нужна функция перевода в основание `4`, а результат потом восстанавливается через `int(b, 4)`.

**Код решения**

```python
def f(n, b):
    s = ''
    while n > 0:
        s = str(n % b) + s
        n //= b
    return s


ans = 0

for n in range(1, 1000):
    b = f(n, 4)

    if n % 4 == 0:
        b = b + b[-2:]
    else:
        ost = (n % 4) * 2
        b = b + f(ost, 4)

    r = int(b, 4)
    if r < 261:
        ans = max(ans, n)

print(ans)
```

**Разбор решения**

Функция `f()` строит четверичную запись обычным способом: на каждом шаге берётся остаток от деления на `4`, а затем число уменьшается целочисленным делением.

Если `N` делится на `4`, к записи просто приписывают две последние цифры: `b[-2:]`. Если не делится, сначала находят остаток `n % 4`, потом умножают его на `2`, переводят результат в четверичную систему и дописывают справа.

Важно не приписать остаток как десятичное число. По условию нужна именно четверичная запись, поэтому используется `f(ost, 4)`.

Так как по условию ищут максимальное `N`, ответ обновляется через `max()`.

**Ответ**

`61`

## Прототип 4. Замена разрядов

**Текст задания**

На вход алгоритма подаётся натуральное число `N`. Алгоритм строит по нему новое число `R` следующим образом.

1. Строится двоичная запись числа `N`.
2. Далее эта запись обрабатывается по следующему правилу:
   - если сумма цифр в двоичной записи чётная, то к этой записи справа дописывается `0`, а затем два левых разряда заменяются на `10`;
   - если сумма цифр в двоичной записи нечётная, то к этой записи справа дописывается `1`, а затем два левых разряда заменяются на `11`.

Полученная таким образом запись является двоичной записью искомого числа `R`. Укажите минимальное число `R`, которое может быть результатом работы данного алгоритма, при условии, что `N` больше `27`.

**Идея решения**

В этом прототипе искать нужно уже не `N`, а число `R`. Значит, при переборе подходящих значений `N` надо сохранять минимальный полученный результат.

**Код решения**

```python
ans = 10**9

for n in range(1, 1000):
    b = bin(n)[2:]
    sm = b.count('1')

    if sm % 2 == 0:
        b = '10' + b[2:] + '0'
    else:
        b = '11' + b[2:] + '1'

    r = int(b, 2)
    if n > 27:
        ans = min(ans, r)

print(ans)
```

**Разбор решения**

Тут всё завязано на чётность количества единиц в двоичной записи. Если сумма цифр чётная, новая строка должна начинаться с `10` и заканчиваться на `0`. Если нечётная, в начале будет `11`, а справа допишется `1`.

Операция

```python
'10' + b[2:] + '0'
```

означает:

- заменить два первых разряда на `10`;
- сохранить остальную часть записи `b[2:]`;
- дописать в конец `0`.

Для нечётного случая идея та же. `replace()` не подходит, потому что нужно поменять только два первых разряда, а не все одинаковые символы в строке.

Так как в ответе требуется минимальное `R`, переменная `ans` обновляется через `min(ans, r)`.

**Ответ**

`42`

## Прототип 5. Центр записи

**Текст задания**

На вход алгоритма подаётся натуральное число `N`. Алгоритм строит по нему новое число `R` следующим образом.

1. Строится двоичная запись числа `N`.
2. Далее эта запись обрабатывается по следующему правилу:
   - если количество разрядов в числе чётное, то в центр записи числа дописывается `111`;
   - если количество разрядов в числе нечётное, то к этой записи справа дописывается `1`, а затем два первых разряда заменяются на `11`.

Полученная таким образом запись является двоичной записью искомого числа `R`. Укажите минимальное число `N`, после обработки которого получается число `R`, большее `4000`.

**Идея решения**

В этом прототипе ветка алгоритма выбирается по длине двоичной записи, а не по самому числу и не по количеству единиц. Если длина чётная, нужно вставить подстроку ровно в середину.

**Код решения**

```python
for n in range(1, 1000):
    b = bin(n)[2:]

    if len(b) % 2 == 0:
        mid = len(b) // 2
        b = b[:mid] + '111' + b[mid:]
    else:
        b = '11' + b[2:] + '1'

    r = int(b, 2)
    if r > 4000:
        print(n)
        break
```

**Разбор решения**

В чётном случае программа смотрит на длину строки `len(b)`. Центр находится между двумя половинами, поэтому индекс середины равен `len(b) // 2`. Запись

```python
b[:mid] + '111' + b[mid:]
```

вставляет `111` точно между левой и правой частью строки.

В нечётном случае используется уже знакомый приём: справа дописывают `1`, а два первых разряда заменяют на `11`.

Так как нужно найти минимальное `N`, перебор идёт по возрастанию и заканчивается на первом значении, для которого `R > 4000`.

**Ответ**

`512`

## Прототип 6. Система счисления больше 10

**Текст задания**

Алгоритм получает на вход натуральное число `N > 11` и строит по нему новое число `R` следующим образом.

1. Строится запись числа `N` в системе счисления с основанием `12`.
2. Далее эта запись обрабатывается по следующему правилу:
   - если число `N` делится на `12`, то в конец дописываются две последние цифры двенадцатеричной записи числа;
   - если число `N` на `12` не делится, то остаток от его деления на `12` умножается на `9`, переводится в систему счисления с основанием `12` и дописывается в конец числа.

Полученная таким образом запись является двенадцатеричной записью искомого числа `R`. Укажите минимальное число `R`, большее `300`, которое может быть получено с помощью описанного алгоритма. В ответе запишите это число в десятичной системе счисления.

**Идея решения**

По сути это тот же тип задачи, что и в четверичном прототипе, только теперь основание равно `12`. Значит, в записи числа могут появляться символы `a` и `b`, и для перевода нужен подходящий алфавит.

**Код решения**

```python
from string import printable


def f(n, b):
    a = printable[:12]
    s = ''
    while n > 0:
        s = a[n % b] + s
        n //= b
    return s


ans = 10**9

for n in range(12, 1000):
    b = f(n, 12)

    if n % 12 == 0:
        b = b + b[-2:]
    else:
        ost = (n % 12) * 9
        b = b + f(ost, 12)

    r = int(b, 12)
    if r > 300:
        ans = min(ans, r)

print(ans)
```

**Разбор решения**

В двенадцатеричной системе после цифры `9` идут `a` и `b`, поэтому в функции `f()` алфавит задаётся как `printable[:12]`.

Если `N` делится на `12`, к записи приписываются две последние цифры: `b[-2:]`. Если не делится, остаток `n % 12` умножается на `9`, переводится в двенадцатеричную систему и только после этого дописывается в конец.

После этого строка переводится в десятичное число через `int(b, 12)`. По условию требуется не минимальное `N`, а минимальное `R`, которое больше `300`, поэтому обновляется именно `ans = min(ans, r)`.

**Ответ**

`309`
