# ТЕОРИЯ

## 1. Что такое задание 17
Задание 17 почти всегда строится на последовательности чисел из файла. Нужно:
- считать все числа в массив;
- найти элементы, пары или тройки подряд;
- проверить условия;
- сохранить подходящие значения;
- вывести `количество` и ещё один параметр: `min`, `max`, сумму, произведение и т.д.

Это многопроходное задание, потому что часто сначала нужно найти некоторую опорную величину по всему файлу, а уже потом решать основную часть.

---

## 2. Как считать числа из файла
Базовая запись:

```python
a = [int(x) for x in open('17.txt')]
```

Что происходит:
- `open('17.txt')` открывает файл;
- цикл перебирает строки файла по одной;
- `int(x)` превращает строку в целое число;
- всё складывается в список `a`.

После этого `a` — это массив чисел, с которым дальше и идёт работа.

---

## 3. Почему нужен массив
Массив нужен, потому что в задании часто надо:
- обращаться к соседним элементам;
- брать пары `a[i]` и `a[i+1]`;
- брать тройки `a[i]`, `a[i+1]`, `a[i+2]`;
- искать `min(a)`, `max(a)`, `sum(a)`.

---

## 4. Как перебирать элементы, пары и тройки

### Один элемент
```python
for i in range(len(a)):
    x = a[i]
```

### Пары подряд
```python
for i in range(len(a) - 1):
    x, y = a[i], a[i + 1]
```

Почему `len(a) - 1`:
- у последнего элемента нет соседа справа;
- если дойти до конца списка и попытаться взять `a[i+1]`, будет ошибка.

### Тройки подряд
```python
for i in range(len(a) - 2):
    x, y, z = a[i], a[i + 1], a[i + 2]
```

Почему `len(a) - 2`:
- для тройки нужны ещё два элемента справа.

---

## 5. Как проверять типовые условия

### Последняя цифра
```python
x % 10 == 7
```
Это значит, что число оканчивается на `7`.

### Последние две цифры
```python
abs(x) % 100 == 18
```
`abs` нужен, если в файле могут быть отрицательные числа.

### Чётность
```python
x % 2 == 0
```

### Нечётность
```python
x % 2 != 0
```

### Делится на число
```python
x % 7 == 0
```

### Не делится на число
```python
x % 11 != 0
```

---

## 6. Когда лучше использовать строку
Если в условии говорится:
- содержит цифру;
- оканчивается на несколько цифр;
- в записи числа встречается что-то,

то часто удобнее работать через строку:

```python
'1' in str(x)
str(x)[-1] == '7'
str(abs(x))[-2:] == '18'
```

---

## 7. Многопроходное решение
Иногда сначала надо найти специальное число по всему файлу:
- среднее арифметическое всех чисел;
- сумму максимального и минимального нечётного;
- максимум среди чисел, оканчивающихся на 18;
- сумму цифр всех чисел, делящихся на 49.

Тогда решение строится в 2 прохода:
1. первый проход — ищем опорную величину;
2. второй проход — решаем основную задачу.

---

## 8. Как сохранять ответ
Обычно создают список результатов:

```python
r = []
```

Если условие выполнено, добавляют то, что потом удобно обрабатывать:
- само число;
- сумму пары;
- среднее пары;
- произведение тройки.

Примеры:
```python
r.append(x)
r.append(x + y)
r.append((x + y) // 2)
r.append(x * y * z)
```

Потом:
```python
print(len(r), min(r))
print(len(r), max(r))
```

---

## 9. Условия «хотя бы» и «ровно один»

### Хотя бы два
В Python `True = 1`, `False = 0`, поэтому можно складывать проверки:

```python
(x < sr) + (y < sr) + (z < sr) >= 2
```

Это значит: хотя бы два элемента подходят.

### Ровно один
```python
(x > s) + (y > s) == 1
```

Или:
```python
(x > s) != (y > s)
```

---

## 10. Базовые функции, которые нужны почти всегда
- `len(a)` — количество элементов;
- `min(a)` — минимум;
- `max(a)` — максимум;
- `sum(a)` — сумма;
- `abs(x)` — модуль числа.

# РАЗБОР ПРОТОТИПОВ

## 1. Окончание числа

### Текст задания
В файле `17-4.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `0` до `10 000` включительно. Рассматривается множество элементов последовательности, которые оканчиваются на `5` или `7` и при этом не делятся ни на `9`, ни на `11`. Найдите количество таких чисел и сумму минимального и максимального из них.

### Код
```python
a = [int(x) for x in open('17-4.txt')]
r = []

for i in range(len(a)):
    x = a[i]
    if (x % 10 == 5 or x % 10 == 7) and x % 9 != 0 and x % 11 != 0:
        r.append(x)

print(len(r), min(r) + max(r))
```

### Что здесь происходит
- Считываем все числа в массив `a`.
- Перебираем каждый элемент по индексу.
- `x % 10 == 5 or x % 10 == 7` проверяет последнюю цифру.
- `x % 9 != 0 and x % 11 != 0` проверяет, что число не делится на 9 и 11.
- Подходящие числа сохраняем в `r`.
- `len(r)` — количество найденных чисел.
- `min(r) + max(r)` — сумма минимального и максимального подходящего числа.

---

## 2. Пары

### Текст задания
В файле `17-3.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `-10 000` до `10 000` включительно. Определите и запишите в ответе сначала количество пар элементов последовательности, в которых произведение нечётно, а среднее арифметическое делится на `7`, затем минимальное из средних арифметических элементов таких пар. Под парой понимаются два идущих подряд элемента последовательности.

### Код
```python
a = [int(x) for x in open('17-3.txt')]
r = []

for i in range(len(a) - 1):
    x, y = a[i], a[i + 1]
    if (x * y) % 2 != 0 and ((x + y) // 2) % 7 == 0:
        r.append((x + y) // 2)

print(len(r), min(r))
```

### Что здесь происходит
- Берём пары соседних элементов: `a[i]` и `a[i+1]`.
- Цикл идёт до `len(a) - 1`, чтобы у последнего элемента не пытаться взять соседа справа.
- `(x * y) % 2 != 0` означает, что произведение нечётно.
- `((x + y) // 2) % 7 == 0` означает, что среднее арифметическое делится на 7.
- В список `r` сохраняем именно среднее арифметическое, потому что потом надо:
  - узнать количество таких пар;
  - найти минимальное среднее.
- Количество пар равно `len(r)`, потому что каждому элементу `r` соответствует одна подходящая пара.

## 3. Тройки + многоуровневое решение

### Текст задания
В файле `17.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `-100 000` до `100 000` включительно. Определите количество троек элементов последовательности, в которых хотя бы один из трёх элементов является пятизначным числом, а произведение элементов тройки кратно максимальному элементу последовательности, оканчивающемуся на `18`. В ответе запишите количество найденных троек, затем максимальное из произведений элементов таких троек. Под тройкой понимаются три идущих подряд элемента.

### Код
```python
a = [int(x) for x in open('17.txt')]

m18 = max(x for x in a if abs(x) % 100 == 18)

r = []
for i in range(len(a) - 2):
    x, y, z = a[i], a[i + 1], a[i + 2]
    if (10000 <= abs(x) <= 99999 or
        10000 <= abs(y) <= 99999 or
        10000 <= abs(z) <= 99999):
        p = x * y * z
        if p % m18 == 0:
            r.append(p)

print(len(r), max(r))
```

### Что здесь происходит
- Это уже многопроходная задача.
- Сначала находим `m18` — максимальный элемент файла, оканчивающийся на `18`.
- Используем `abs(x) % 100 == 18`, потому что в файле есть отрицательные числа.
- Потом перебираем тройки подряд.
- Проверяем, что хотя бы одно число пятизначное:
  - у пятизначного числа модуль от `10000` до `99999`.
- Считаем произведение тройки.
- Проверяем, что оно кратно `m18`.
- Сохраняем произведение, потому что в конце нужен максимум из произведений.
- `len(r)` — количество троек, `max(r)` — максимальное произведение.

## 4. Многоуровневый поиск

### Текст задания
В файле `17-257.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые положительные значения до `10 000` включительно. Найдите количество и наименьшую сумму пар элементов последовательности с чётной суммой, большей чем сумма максимального и минимального нечётного числа. Под парой понимаются два идущих подряд элемента.

### Код
```python
a = [int(x) for x in open('17-257.txt')]

odd = [x for x in a if x % 2 != 0]
s_odd = min(odd) + max(odd)

r = []
for i in range(len(a) - 1):
    x, y = a[i], a[i + 1]
    s = x + y
    if s % 2 == 0 and s > s_odd:
        r.append(s)

print(len(r), min(r))
```

### Что здесь происходит
- Сначала выделяем все нечётные числа файла в список `odd`.
- Затем считаем опорную величину `s_odd = min(odd) + max(odd)`.
- Это и есть первый проход.
- Во втором проходе рассматриваем пары подряд.
- Для каждой пары считаем сумму `s`.
- Проверяем два условия:
  - сумма чётная;
  - сумма больше найденной опорной величины.
- Сохраняем сумму пары, потому что в ответе нужно:
  - количество подходящих пар;
  - наименьшая сумма пары.

## 5. Хотя бы два

### Текст задания
В файле `17-1.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `-10 000` до `10 000` включительно. Определите количество троек, в которых хотя бы два из трёх элементов меньше, чем среднее арифметическое всех чисел в файле, и десятичная запись всех трёх элементов тройки содержит цифру `1`. В ответе запишите сначала количество найденных троек, а затем максимальную сумму элементов таких троек. Под тройкой понимаются три идущих подряд элемента.

### Код
```python
a = [int(x) for x in open('17-1.txt')]
sr = sum(a) / len(a)

r = []
for i in range(len(a) - 2):
    x, y, z = a[i], a[i + 1], a[i + 2]

    cond1 = (x < sr) + (y < sr) + (z < sr) >= 2
    cond2 = '1' in str(x) and '1' in str(y) and '1' in str(z)

    if cond1 and cond2:
        r.append(x + y + z)

print(len(r), max(r))
```

### Что здесь происходит
- Сначала считаем среднее арифметическое всех чисел файла: `sr`.
- Дальше перебираем тройки подряд.
- `(x < sr) + (y < sr) + (z < sr) >= 2` — очень важный приём:
  - каждая проверка даёт `True` или `False`;
  - в Python это `1` или `0`;
  - сумма показывает, сколько элементов подошло.
- Если сумма не меньше 2, значит хотя бы два элемента меньше среднего.
- `'1' in str(x)` проверяет, что в записи числа встречается цифра 1.
- То же самое делаем для всех трёх чисел, потому что по условию цифра 1 должна быть во всех трёх.
- Сохраняем сумму тройки, потому что нужен максимум среди сумм.

## 6. Ровно один

### Текст задания
В файле `17-243.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `0` до `10 000` включительно. Определите количество пар чисел, в которых ровно один из двух элементов больше, чем сумма цифр всех чисел в файле, делящихся на `49`, а десятичная запись другого оканчивается на `7`. В ответе запишите сначала количество найденных пар, а затем минимальную сумму элементов таких пар. Под парой понимаются два идущих подряд элемента.

### Код
```python
a = [int(x) for x in open('17-243.txt')]

s49 = sum(sum(map(int, str(x))) for x in a if x % 49 == 0)

r = []
for i in range(len(a) - 1):
    x, y = a[i], a[i + 1]

    if ((x > s49) != (y > s49)) and (
        (x > s49 and y % 10 == 7) or
        (y > s49 and x % 10 == 7)
    ):
        r.append(x + y)

print(len(r), min(r))
```

### Что здесь происходит
- Сначала находим `s49` — сумму цифр всех чисел файла, которые делятся на 49.
- Это опять первый проход.
- `sum(map(int, str(x)))` — сумма цифр одного числа.
- Потом рассматриваем пары подряд.
- `(x > s49) != (y > s49)` означает, что ровно одно из двух условий истинно.
- Но этого мало: второй элемент пары должен оканчиваться на 7.
- Поэтому отдельно проверяем оба возможных случая:
  - `x` больше порога, а `y` оканчивается на 7;
  - `y` больше порога, а `x` оканчивается на 7.
- Сохраняем сумму пары, потому что в конце нужен минимум среди сумм.

## 7. Сложное

### Текст задания
В файле содержится последовательность натуральных чисел, которые нумеруются, начиная с единицы. Определите количество пар элементов последовательности, сумма номеров которых оканчивается на ту же цифру, что и максимальный элемент последовательности. В ответе запишите количество найденных пар, затем минимальное значение среди модулей разностей суммы элементов и суммы номеров таких пар. Под парой понимаются два идущих подряд элемента.

### Код
```python
a = [int(x) for x in open('17.txt')]
last_digit = max(a) % 10

r = []
for i in range(len(a) - 1):
    index_sum = (i + 1) + (i + 2)   # индексация в задаче с 1
    if index_sum % 10 == last_digit:
        value = abs((a[i] + a[i + 1]) - index_sum)
        r.append(value)

print(len(r), min(r))
```

### Что здесь происходит
- Максимальный элемент последовательности нужен только для его последней цифры.
- Нумерация в задаче идёт с единицы, а в Python индексация с нуля.
- Поэтому для пары `a[i]` и `a[i+1]` номера элементов равны:
  - `i + 1`
  - `i + 2`
- Сумма номеров:
```python
(i + 1) + (i + 2)
```
- Проверяем, что эта сумма оканчивается на ту же цифру, что и максимум файла.
- Если пара подходит, считаем:
```python
abs((a[i] + a[i + 1]) - index_sum)
```
- Это модуль разности между:
  - суммой элементов пары;
  - суммой их номеров.
- Сохраняем это значение и потом берём минимум.
