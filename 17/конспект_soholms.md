## Блок 3. Что такое задание 17

Задание 17 почти всегда строится на последовательности чисел из файла. Сначала числа считываются в массив, затем программа перебирает элементы, пары или тройки подряд, проверяет условия задачи и сохраняет подходящие результаты.

Обычно в ответе требуется:
- количество подходящих объектов;
- и ещё одна величина: `min`, `max`, сумма, среднее арифметическое, произведение и так далее.

Главная идея задания 17: не пытаться решить задачу "одним красивым действием", а спокойно разобрать её на этапы и последовательно запрограммировать каждый этап.

## Блок 4. Как считать числа из файла

Базовая запись:

```python
a = [int(x) for x in open('17.txt')]
```

Что здесь происходит:
- `open('17.txt')` открывает файл;
- строки файла перебираются по одной;
- каждая строка превращается в целое число с помощью `int(x)`;
- все числа собираются в список `a`.

После этого `a` — это массив, с которым дальше работает программа.

---

## Блок 5. Почему в задании нужен массив

Массив нужен потому, что в задании 17 часто приходится:
- обращаться к соседним элементам;
- рассматривать пары `a[i]` и `a[i + 1]`;
- рассматривать тройки `a[i]`, `a[i + 1]`, `a[i + 2]`;
- искать `min(a)`, `max(a)`, `sum(a)`;
- делать отдельный первый проход по всему файлу.

---

## Блок 6. Как перебирать элементы, пары и тройки

Если в задаче рассматриваются отдельные элементы:

```python
for i in range(len(a)):
    x = a[i]
```

Если рассматриваются пары подряд:

```python
for i in range(len(a) - 1):
    x, y = a[i], a[i + 1]
```

Почему `len(a) - 1`:
- у последнего элемента нет соседа справа;
- если попытаться обратиться к `a[i + 1]` у последнего элемента, программа выдаст ошибку.

Если рассматриваются тройки подряд:

```python
for i in range(len(a) - 2):
    x, y, z = a[i], a[i + 1], a[i + 2]
```

Почему `len(a) - 2`:
- для тройки нужны ещё два элемента справа.

## Блок 7. Базовые проверки в задании 17

Последняя цифра:

```python
x % 10 == 7
```

Последние две цифры:

```python
abs(x) % 100 == 18
```

Чётность:

```python
x % 2 == 0
```

Нечётность:

```python
x % 2 != 0
```

Делится на число:

```python
x % 7 == 0
```

Не делится на число:

```python
x % 11 != 0
```

Если в условии говорится, что число содержит цифру, удобнее работать как со строкой:

```python
'1' in str(x)
str(x)[-1] == '7'
str(abs(x))[-2:] == '18'
```

## Блок 8. Многопроходные задачи

Иногда задача решается не сразу, а в два этапа.

Сначала по всему файлу надо найти некоторую опорную величину:
- среднее арифметическое всех чисел;
- сумму минимального и максимального нечётного числа;
- максимум среди чисел с нужным окончанием;
- сумму цифр чисел, делящихся на определённое число.

Только после этого начинается основной проход по парам или тройкам.

Значит, многопроходная задача — это задача, где:
1. сначала ищется вспомогательное значение;
2. потом с его помощью решается основная часть.

## Блок 9. Как сохранять ответ

Обычно создают список результатов:

```python
r = []
```

Дальше в него добавляют то, что потом понадобится для ответа:
- само число;
- сумму пары;
- среднее арифметическое пары;
- произведение тройки.

Примеры:

```python
r.append(x)
r.append(x + y)
r.append((x + y) // 2)
r.append(x * y * z)
```

Потом:

```python
print(len(r), min(r))
print(len(r), max(r))
```

## Блок 10. Условия "хотя бы" и "ровно один"

Если в задаче говорится "хотя бы два", удобно использовать тот факт, что в Python:
- `True = 1`
- `False = 0`

Тогда можно написать:

```python
(x < sr) + (y < sr) + (z < sr) >= 2
```

Это означает: хотя бы два элемента подходят.

Если в задаче говорится "ровно один", можно писать так:

```python
(x > s) + (y > s) == 1
```

или так:

```python
(x > s) != (y > s)
```

## Блок 12. Прототип 1. Окончание числа

Текст задания:

В файле `17-4.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `0` до `10 000` включительно. Рассматривается множество элементов последовательности, которые оканчиваются на `5` или `7` и при этом не делятся ни на `9`, ни на `11`. Найдите количество таких чисел и сумму минимального и максимального из них.

Код:

```python
a = [int(x) for x in open('17-4.txt')]
r = []

for i in range(len(a)):
    x = a[i]
    if (x % 10 == 5 or x % 10 == 7) and x % 9 != 0 and x % 11 != 0:
        r.append(x)

print(len(r), min(r) + max(r))
```

Пояснение:

Сначала считываем все числа в массив `a`. Затем перебираем каждый элемент по очереди.  
Условие `x % 10 == 5 or x % 10 == 7` проверяет, что число оканчивается на 5 или 7.  
Условия `x % 9 != 0` и `x % 11 != 0` проверяют, что число не делится на 9 и 11.  
Если число подходит, оно добавляется в список `r`.  
В конце:
- `len(r)` — количество подходящих чисел;
- `min(r) + max(r)` — сумма минимального и максимального числа.

Ответ из презентации:

```python
337 10802
```

## Блок 13. Прототип 2. Пары

Текст задания:

В файле `17-3.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `-10 000` до `10 000` включительно. Определите и запишите в ответе сначала количество пар элементов последовательности, в которых произведение нечётно, а среднее арифметическое делится на `7`, затем минимальное из средних арифметических элементов таких пар. Под парой понимаются два идущих подряд элемента последовательности.

```python
a = [int(x) for x in open('17-3.txt')]
r = []

for i in range(len(a) - 1):
```

`((x + y) // 2) % 7 == 0` означает, что среднее арифметическое делится на 7.  
В список `r` сохраняем именно среднее арифметическое, потому что потом нужно узнать:

## Блок 14. Прототип 3. Тройки плюс многоуровневое решение

Текст задания:

В файле `17.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `-100 000` до `100 000` включительно. Определите количество троек элементов последовательности, в которых хотя бы один из трёх элементов является пятизначным числом, а произведение элементов тройки кратно максимальному элементу последовательности, оканчивающемуся на `18`. В ответе запишите количество найденных троек, затем максимальное из произведений элементов таких троек. Под тройкой понимаются три идущих подряд элемента.

Код:

```python
a = [int(x) for x in open('17.txt')]

m18 = max(x for x in a if abs(x) % 100 == 18)

r = []
for i in range(len(a) - 2):
    x, y, z = a[i], a[i + 1], a[i + 2]
    if (10000 <= abs(x) <= 99999 or
        10000 <= abs(y) <= 99999 or
        10000 <= abs(z) <= 99999):
        p = x * y * z
        if p % m18 == 0:
            r.append(p)

print(len(r), max(r))
```

Пояснение:

Это многопроходная задача.  
Сначала нужно найти `m18` — максимальный элемент всей последовательности, который оканчивается на `18`.  
Используем `abs(x) % 100 == 18`, потому что числа могут быть отрицательными.  
После этого перебираем тройки подряд.  
Проверяем, что хотя бы одно число в тройке пятизначное. Для этого используем модуль:

```python
10000 <= abs(x) <= 99999
```

Затем считаем произведение тройки и проверяем, кратно ли оно `m18`.  
Если кратно, сохраняем произведение в `r`.  
В конце:
- `len(r)` — количество подходящих троек;
- `max(r)` — максимальное произведение.

Ответ из презентации:

```python
7 32313429347472
```

## Блок 15. Прототип 4. Многоуровневый поиск

Текст задания:

В файле `17-257.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые положительные значения до `10 000` включительно. Найдите количество и наименьшую сумму пар элементов последовательности с чётной суммой, большей чем сумма максимального и минимального нечётного числа. Под парой понимаются два идущих подряд элемента последовательности.

Код:

```python
a = [int(x) for x in open('17-257.txt')]

odd = [x for x in a if x % 2 != 0]
s_odd = min(odd) + max(odd)

r = []
for i in range(len(a) - 1):
    x, y = a[i], a[i + 1]
    s = x + y
    if s % 2 == 0 and s > s_odd:
```

```python
s_odd = min(odd) + max(odd)
```

Это сумма минимального и максимального нечётного элемента всей последовательности.  
После этого перебираем пары подряд.  
Для каждой пары считаем сумму и проверяем:
- сумма чётная;
- сумма больше, чем `s_odd`.

Если условия выполнены, сумма пары сохраняется в `r`.  
В конце:
- `len(r)` — количество пар;
- `min(r)` — наименьшая сумма.

Ответ из презентации:

```python
250 10094
```

## Блок 16. Прототип 5. Хотя бы два

Текст задания:

В файле `17-1.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `-10 000` до `10 000` включительно. Определите количество троек, в которых хотя бы два из трёх элементов меньше, чем среднее арифметическое всех чисел в файле, и десятичная запись всех трёх элементов тройки содержит цифру `1`. В ответе запишите сначала количество найденных троек, а затем максимальную сумму элементов таких троек. Под тройкой понимаются три идущих подряд элемента.

Код:

```python
a = [int(x) for x in open('17-1.txt')]
sr = sum(a) / len(a)

r = []
for i in range(len(a) - 2):
    x, y, z = a[i], a[i + 1], a[i + 2]

    cond1 = (x < sr) + (y < sr) + (z < sr) >= 2
    cond2 = '1' in str(x) and '1' in str(y) and '1' in str(z)

    if cond1 and cond2:
        r.append(x + y + z)

print(len(r), max(r))
```

Пояснение:

Сначала находим среднее арифметическое всех чисел файла:

```python
sr = sum(a) / len(a)
```

Потом перебираем тройки подряд.  
Условие

```python
(x < sr) + (y < sr) + (z < sr) >= 2
```

означает, что хотя бы два элемента меньше среднего арифметического.  
Это работает потому, что `True` в Python считается как `1`, а `False` как `0`.  
Дальше проверяем, что в десятичной записи каждого из трёх чисел есть цифра `1`.  
Если оба условия выполнены, сохраняем сумму тройки.  
В конце:
- `len(r)` — количество троек;
- `max(r)` — максимальная сумма.

Ответ из презентации:

```python
203 7191
```

## Блок 17. Прототип 6. Ровно один

Текст задания:

В файле `17-243.txt` содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `0` до `10 000` включительно. Определите количество пар чисел, в которых ровно один из двух элементов больше, чем сумма цифр всех чисел в файле, делящихся на `49`, а десятичная запись другого оканчивается на `7`. В ответе запишите сначала количество найденных пар, а затем минимальную сумму элементов таких пар. Под парой понимаются два идущих подряд элемента.

Код:

```python
a = [int(x) for x in open('17-243.txt')]

s49 = sum(sum(map(int, str(x))) for x in a if x % 49 == 0)

r = []
for i in range(len(a) - 1):
    x, y = a[i], a[i + 1]

    if ((x > s49) != (y > s49)) and (
        (x > s49 and y % 10 == 7) or
        (y > s49 and x % 10 == 7)
    ):
        r.append(x + y)

print(len(r), min(r))
```

Пояснение:

Сначала находим сумму цифр всех чисел файла, делящихся на 49:

```python
s49 = sum(sum(map(int, str(x))) for x in a if x % 49 == 0)
```

Это опорная величина.  
Дальше перебираем пары подряд.  
Проверка

```python
(x > s49) != (y > s49)
```

означает, что ровно один элемент пары больше порога `s49`.  
Но этого недостаточно: второй элемент пары должен оканчиваться на `7`.  
Поэтому отдельно проверяем оба возможных случая:
- первый больше порога, второй оканчивается на 7;
- второй больше порога, первый оканчивается на 7.

Если условие выполнено, сохраняем сумму пары.  
В конце:
- `len(r)` — количество подходящих пар;
- `min(r)` — минимальная сумма.

Ответ из презентации:

```python
385 4867
```

## Блок 18. Прототип 7. Сложное

Текст задания:

В файле содержится последовательность натуральных чисел, которые нумеруются, начиная с единицы. Определите количество пар элементов последовательности, сумма номеров которых оканчивается на ту же цифру, что и максимальный элемент последовательности. В ответе запишите количество найденных пар, затем минимальное значение среди модулей разностей суммы элементов и суммы номеров таких пар. Под парой понимаются два идущих подряд элемента.

Код:

```python
a = [int(x) for x in open('17.txt')]
last_digit = max(a) % 10

r = []
for i in range(len(a) - 1):
    index_sum = (i + 1) + (i + 2)
    if index_sum % 10 == last_digit:
        value = abs((a[i] + a[i + 1]) - index_sum)
        r.append(value)

print(len(r), min(r))
```

Пояснение:

Сначала находим максимальный элемент последовательности и берём его последнюю цифру:

```python
last_digit = max(a) % 10
```

Дальше перебираем пары подряд.  
Важно помнить, что в условии нумерация элементов идёт с единицы, а в Python — с нуля.  
Поэтому сумма номеров пары считается так:

```python
index_sum = (i + 1) + (i + 2)
```

Проверяем, что сумма номеров оканчивается на ту же цифру, что и максимальный элемент последовательности.  
Если условие выполнено, считаем модуль разности между:
- суммой элементов пары;
- суммой их номеров.

Это и есть значение, которое добавляется в список `r`.  
В конце:
- `len(r)` — количество подходящих пар;
- `min(r)` — минимальное значение среди найденных модулей.

Ответ из презентации:

```python
1000 811
```

## Блок 20. Типичные ошибки

Самые частые ошибки в задании 17:
- ученик забывает считать файл в массив;
- вместо пар подряд начинает сравнивать каждый элемент со всеми остальными;
- пишет `range(len(a))` для пар и получает выход за границы массива;
- забывает использовать `abs`, когда в задаче есть отрицательные числа;
- сохраняет в список не то значение, которое потом требуется для ответа;
- путает формулировки `хотя бы один`, `хотя бы два`, `ровно один`;

## Блок 21. Что запомнить после урока

Главное, что нужно унести с урока:
- задание 17 почти всегда решается через массив;
- пары подряд — это `range(len(a) - 1)`;
- тройки подряд — это `range(len(a) - 2)`;
- последняя цифра проверяется через `% 10`;
- последние две цифры у отрицательных чисел удобнее проверять через `abs(x) % 100`;
- если в условии есть "содержит цифру", чаще всего выгоднее работать через `str`;
- если по условию сначала нужно найти специальную величину, задача многопроходная;
