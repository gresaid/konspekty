## 3018

**Текст задания:**  
Текстовый файл содержит строку из заглавных латинских букв, всего не более чем из `10^6` символов. Определите количество подстрок длиной не менее 17 символов, которые начинаются и заканчиваются буквой `A` и не содержат других букв `A` (кроме первой и последней) и букв `B`.

**Решение 1: двойной цикл**
```python
s = open('24.txt').readline().strip()

k = 0

for i in range(len(s)):
    for j in range(i + 16, len(s)):
        string = s[i:j + 1]

        if string[0] == 'A' and string[-1] == 'A' and 'A' not in string[1:-1] and 'B' not in string:
            k += 1
        elif string[0] == 'A' and ('A' in string[1:-1] or 'B' in string):
            break

print(k)
```

**Фишка:**  
Если внутри уже встретились `B` или лишняя `A`, дальше расширять подстроку бессмысленно.

**Решение 2: регулярные выражения**
```python
from re import finditer

s = open('24.txt').readline().strip()

reg = r'(?=(A[^AB]{15,}A))'
k = 0

for s1 in finditer(reg, s):
    k += 1

print(k)
```

**Фишка:**  
Просмотр вперёд `(?=...)` позволяет найти все подходящие подстроки, в том числе пересекающиеся.

**Решение 3: два указателя**
```python
s = open('24.txt').readline().strip()

l = 0
k = 0

for r in range(len(s)):
    if s[r] == 'B':
        l = r + 1
    elif s[r] == 'A':
        if r - l + 1 >= 17:
            k += 1
        l = r

print(k)
```

**Фишка:**  
Левый указатель стоит на последней подходящей `A`, а правый идёт вперёд; `B` сбрасывает окно, новая `A` сразу образует следующую проверяемую пару.

## 20909

**Текст задания:**  
Текстовый файл состоит из заглавных букв латинского алфавита `A`, `B`, `C`, `D`, `E` и `F`.

Определите в прилагаемом файле максимальное количество идущих подряд символов, среди которых пара `AB` (в указанном порядке) встречается ровно 100 раз.

Для выполнения этого задания следует написать программу.

**Решение 1: двойной цикл**
```python
s = open('24.txt').readline().strip()

m = 0

for i in range(len(s)):
    for j in range(i + m, len(s)):
        string = s[i:j + 1]

        if string.count('AB') == 100:
            m = len(string)
        elif string.count('AB') > 100:
            break

print(m)
```

**Фишка:**  
Как только пар `AB` стало больше 100, дальше расширять подстроку уже бессмысленно.

**Решение 2: регулярные выражения**
```python
from re import finditer

s = open('24.txt').readline().strip()

s = s.replace('AB', 'A!B')
ans = 0

for m in finditer(r'(?=(([^!]*!){100}[^!]*))', s):
    fragment = m[1].replace('A!B', 'AB')
    ans = max(ans, len(fragment))

print(ans)
```

**Фишка:**  
Сначала каждая пара `AB` помечается символом `!`, а потом регулярка ищет фрагменты, где таких меток ровно 100.

**Решение 3: два указателя**
```python
s = open('24.txt').readline().strip()

l = 0
k = 0
m = 0

for r in range(len(s)):
    if r > 0 and s[r - 1:r + 1] == 'AB':
        k += 1

    while k > 100:
        if l + 1 <= r and s[l:l + 2] == 'AB':
            k -= 1
        l += 1

    if k == 100:
        m = max(m, r - l + 1)

print(m)
```

**Фишка:**  
Окно двигается по строке, а счётчик хранит, сколько пар `AB` сейчас внутри.

## 22356

**Текст задания:**  
Текстовый файл состоит из десятичных цифр и заглавных букв латинского алфавита. Определите в этом файле последовательность идущих подряд символов, представляющих собой запись максимального нечётного 12-ричного числа. В ответе запишите индекс первого символа, с которого начинается запись этого числа в прилагаемом файле. Нумерация символов в текстовом файле начинается с нуля.

Примечание. Латинские буквы `A` и `B` считаются цифрами 12-ричной системы счисления.

**Решение 1: двойной цикл**
```python
from string import ascii_uppercase

s = open('24.txt').readline().strip()

for x in ascii_uppercase.replace('A', '').replace('B', ''):
    s = s.replace(x, '*')

best = ''
best_i = -1

for i in range(len(s)):
    start = i + max(len(best) - 1, 0)

    for j in range(start, len(s)):
        string = s[i:j + 1]

        if string[0] == '0' or '*' in string:
            break

        if string[-1] in '13579B':
            if len(string) > len(best) or len(string) == len(best) and string > best:
                best = string
                best_i = i

print(best_i)
```

**Фишка:**  
Сначала ищем максимум по длине, а при равной длине сравниваем сами 12-ричные записи.

**Решение 2: регулярные выражения**
```python
from re import finditer

with open('24.txt') as f:
    s = f.readline().strip()

num = r'(?:[13579B]|[1-9AB][0-9AB]*[13579B])'
pat = rf'(?=({num}))'

best = ''
best_i = -1

for m in finditer(pat, s):
    fragment = m.group(1)

    if len(fragment) > len(best) or len(fragment) == len(best) and fragment > best:
        best = fragment
        best_i = m.start(1)

print(best_i)
```

**Фишка:**  
Регулярка сразу задаёт корректное нечётное 12-ричное число без ведущих нулей, а дальше остаётся выбрать максимум.

**Решение 3: два указателя**
```python
s = open('24.txt').readline().strip()

l = 0
best = ''
best_i = -1

for r in range(len(s)):
    if s[r] not in '0123456789AB':
        l = r + 1
        continue

    while l < r and s[l] == '0':
        l += 1

    string = s[l:r + 1]

    if string and string[-1] in '13579B':
        if len(string) > len(best) or len(string) == len(best) and string > best:
            best = string
            best_i = l

print(best_i)
```

**Фишка:**  
Левый указатель держит начало текущего допустимого 12-ричного фрагмента без ведущих нулей, правый расширяет его вправо.

## 9169

**Текст задания:**  
В файле содержится строка длиной не более `10^6` из букв английского алфавита. Определите минимальную длину подстроки, в которой ровно три тройки `BAD` или `FAT`.

Например, в строке `SDFATFDBADZZSFATBADGHTBAD` есть три подходящие подстроки `FATFDBADZZSFAT`, `BADZZSFATBAD` и `FATBADGHTBAD`. Минимальная длина равна `12`.

**Решение 1: двойной цикл**
```python
s = open('24.txt').readline().strip()

m = 10000

for i in range(len(s)):
    for j in range(i + m, i, -1):
        string = s[i:j + 1]
        k = string.count('BAD') + string.count('FAT')

        if k == 3:
            m = len(string)
        elif k < 3:
            break

print(m)
```

**Фишка:**  
Подстроки перебираются от длинной к короткой: если троек стало меньше трёх, дальше их уже не прибавится.

**Решение 2: регулярные выражения**
```python
from re import finditer

with open('24.txt') as f:
    s = f.readline().strip()

s = s.replace('BAD', '!').replace('FAT', '!')
ans = 10000

for m in finditer(r'(?=([^!]*!(?:[^!]*!){2}[^!]*))', s):
    fragment = m.group(1)

    if fragment.count('!') == 3:
        fragment = fragment.replace('!', 'BAD')
        ans = min(ans, len(fragment))

print(ans)
```

**Фишка:**  
Обе тройки заменяются одной меткой, после чего регулярка ищет фрагменты с тремя такими метками.

**Решение 3: два указателя**
```python
s = open('24.txt').readline().strip()

pos = []

for i in range(len(s) - 2):
    if s[i:i + 3] in ('BAD', 'FAT'):
        pos.append(i)

m = 10000
l = 0

for r in range(2, len(pos)):
    if pos[r] - pos[r - 1] >= 3 and pos[r - 1] - pos[r - 2] >= 3:
        left = pos[r - 2]
        right = pos[r] + 2
        m = min(m, right - left + 1)

print(m)
```

**Фишка:**  
Нужно смотреть на тройки подряд по их стартам: минимальный ответ даёт отрезок от начала первой до конца третьей.
