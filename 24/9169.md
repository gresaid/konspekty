## ТЕОРИЯ

### Что нужно заметить в этой задаче
Нужно найти минимальную длину подстроки, в которой ровно три раза встречаются тройки `BAD` или `FAT`.

Здесь удобно использовать двойной цикл:
- внешний цикл выбирает начало подстроки;
- внутренний цикл выбирает конец подстроки.

Так как нужно найти минимум, удобно для каждого начала `i` сначала пробовать более длинные подстроки, а потом постепенно их сокращать.

### Что нужно считать во внутреннем цикле
Пусть подстрока равна `s[i:j + 1]`.

Для неё нужно посчитать:

- сколько раз встречается `BAD`;
- сколько раз встречается `FAT`.

### Когда можно делать `break`
Во внутреннем цикле конец `j` идёт справа налево. Значит, подстрока постепенно укорачивается.

Если в текущей подстроке количество троек `BAD` и `FAT` уже меньше трёх, дальше можно сразу делать `break`.

Это корректно, потому что более короткая подстрока не может содержать больше вхождений, чем более длинная.

## РАЗБОР ПРОТОТИПОВ

### Прототип 9169

**Текст задания**

В файле содержится строка длиной не более `10^6` из букв английского алфавита. Нужно определить минимальную длину подстроки, в которой ровно три тройки `BAD` или `FAT`.

**Идея решения**

Внешний цикл выбирает начало подстроки `i`.

Внутренний цикл перебирает конец `j` справа налево, начиная с подстроки длины `m`, где `m` — текущий лучший ответ.

Для каждой подстроки считается количество вхождений `BAD` и `FAT`.

Если сумма равна 3, минимум обновляется. Если сумма стала меньше 3, внутренний цикл сразу прекращается.

**Код решения**

```python
f = open('24_9169.txt')
s = f.readline().strip()

ans = 10**10

for i in range(len(s)):
    for j in range(i + ans, i - 1, -1):
        string = s[i:j + 1]
        cnt = string.count('BAD') + string.count('FAT')

        if cnt == 3:
            ans = min(ans, len(string))
        elif cnt < 3:
            break

print(ans)
```

**Подробный разбор**

Сначала строка считывается из файла:

```python
s = f.readline().strip()
```

Переменная `ans` хранит минимальную длину подходящей подстроки:

```python
ans = 10**10
```

Внешний цикл перебирает начало подстроки:

```python
for i in range(len(s)):
```

Внутренний цикл перебирает конец подстроки справа налево:

```python
for j in range(i + ans, i - 1, -1):
```

Он начинается с `i + ans`, потому что подстроки короче текущего ответа уже не смогут улучшить минимум.

Текущая подстрока записывается так:

```python
string = s[i:j + 1]
```

Для неё считается общее число вхождений `BAD` и `FAT`:

```python
cnt = string.count('BAD') + string.count('FAT')
```

Если таких вхождений ровно три, ответ можно обновить:

```python
if cnt == 3:
    ans = min(ans, len(string))
```

Если их стало меньше трёх, выполняется:

```python
elif cnt < 3:
    break
```

Это корректно, потому что дальше подстрока будет только укорачиваться, а значит число вхождений уже не увеличится.

В конце программа выводит минимальную длину подходящей подстроки:

```python
print(ans)
```

**Ответ**

Для файла `24_9169.txt` ответ равен `10`.
