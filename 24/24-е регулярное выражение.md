## ТЕОРИЯ

### Что такое регулярные выражения
Регулярные выражения - это язык шаблонов для поиска фрагментов в тексте.

Их используют, когда нужно задать:
- какие символы допустимы;
- как символы могут повторяться;
- где в строке начинается и заканчивается нужный фрагмент;
- какие части текста нужно захватить как одно совпадение.

В 24-м задании это особенно удобно: почти всегда есть одна длинная строка, в которой нужно найти подходящие подстроки.

### Как подключить регулярки в Python
Для работы с регулярными выражениями нужен модуль `re`.

Чаще всего нужны такие функции:
- `fullmatch` - проверяет, подходит ли вся строка под шаблон;
- `finditer` - находит все подходящие подстроки в тексте;
- `search` - находит первое совпадение;
- `sub` - делает замену по шаблону.

В 24-м задании обычно хватает `finditer`.

### Зачем писать `r'...'`
Регулярные выражения удобно записывать как raw string:

```python
r'...'
```

Так Python не трогает обратные слеши и спецсимволы строки.

### Что дают квадратные скобки
Квадратные скобки `[...]` описывают множество допустимых символов на одной позиции.

Например:

```python
[AO]
```

означает `A` или `O` на этой позиции.

Если написать:

```python
[BCD]
```

это значит `B`, `C` или `D` на этой позиции.

### Что даёт отрицание
Если после открывающей квадратной скобки поставить `^`, получится отрицание:

```python
[^AE]
```

Это означает любой символ, кроме `A` и `E`.

### Что дают скобки
Скобки нужны, чтобы объединить несколько символов в один блок.

Если записать:

```python
ab+
```

то `+` относится только к `b`.

Если записать:

```python
(ab)+
```

то повторяется уже вся пара `ab`.

В 24-м задании часто нужно повторять не один символ, а целый блок.

Обычно для таких случаев используют не обычные скобки, а `(?:...)` - группирующие скобки без запоминания.

`(?:...)` нужен, когда блок надо повторять целиком, но отдельная группа внутри результата не нужна.

Если заменить `(?:[BCD][AO])+` на обычные скобки, шаблон останется тем же, но появится лишняя группа. Здесь она не нужна.

Поэтому запись с `?:` короче и чище: скобки нужны только для группировки.

### Что такое квантификаторы
Квантификаторы показывают, сколько раз может повторяться предыдущий элемент.

Основные квантификаторы:
- `*` - 0 или больше повторений;
- `+` - 1 или больше повторений;
- `?` - 0 или 1 повторение;
- `{x,y}` - от `x` до `y` повторений;
- `{x,}` - от `x` повторений и дальше без верхней границы;
- `{,y}` - от 0 до `y` повторений.

Чаще всего в 24-м задании хватает `*` и `+`.

### Как читать шаблон целиком
Если шаблон записан так:

```python
(?:[BCD][AO])+
```

то его нужно читать так:
- `[BCD]` - одна согласная из `B`, `C`, `D`;
- `[AO]` - одна гласная из `A`, `O`;
- `(?:[BCD][AO])` - одна пара согласная + гласная;
- `+` - таких пар подряд должно быть одна или больше.

То есть шаблон находит цепочки из повторяющихся пар.

### Чем полезен `finditer`
`finditer` проходит по строке и выдаёт все непересекающиеся совпадения, которые подходят под шаблон.

Для каждого совпадения можно узнать:
- сам фрагмент;
- его длину;
- его начало и конец.

В 24-м задании это удобно, если нужно:
- найти максимальную длину;
- найти максимальное количество повторяющихся блоков;
- взять индекс начала найденного фрагмента.

Если нужно найти самую длинную подстроку без запрещённых символов, удобно взять шаблон из разрешённых символов.

Например, если в тексте есть только цифры и буквы `A, B, C, D, E, F`, а гласными являются `A` и `E`, то шаблон можно построить так:

```python
[0-9BCDF]+
```

Он находит все непрерывные участки, где встречаются только цифры и буквы `B`, `C`, `D`, `F`.

### Как искать пересечения
Обычный `finditer` после совпадения двигается дальше, поэтому перекрывающиеся варианты может пропустить.

Если нужно проверить строку, начиная с каждой позиции, используют опережающий позитивный просмотр вперёд:

```python
(?=...)
```

Эта конструкция не съедает символы строки. Она только проверяет, что с текущей позиции дальше стоит нужный шаблон.

Если внутри `(?=...)` поставить ещё и скобки:

```python
(?=(...))
```

то:
- внешняя часть делает просмотр вперёд;
- внутренняя группа запоминает фрагмент;
- `finditer` возвращает совпадение нулевой длины;
- текст берётся из группы `1`.

Это и есть способ искать пересечения.

Пусть строка выглядит так:

```python
s = 'AAAA'
```

Если искать обычным шаблоном:

```python
reg = r'AAA'
```

то `finditer` найдёт только одно `AAA` с позиции `0`.

Почему так:
- первое совпадение занимает символы с `0` по `2`;
- после него поиск сдвигается дальше;
- второе вхождение `AAA` начинается с позиции `1`, но оно перекрывается с первым;
- обычный `finditer` такие перекрывающиеся варианты не возвращает.

Теперь посмотрим на просмотр вперёд:

```python
reg = r'(?=(AAA))'
```

На той же строке `AAAA` эта запись проверит каждую позицию:
- с позиции `0` найдётся `AAA`;
- с позиции `1` тоже найдётся `AAA`;
- с позиции `2` уже не найдётся, потому что не хватает символов.

Значит, просмотр вперёд видит все перекрывающиеся вхождения.

Ещё один наглядный пример:

```python
s = 'ABABA'
reg = r'ABA'
```

Обычный поиск найдёт только первое `ABA` с позиции `0`.

А запись

```python
reg = r'(?=(ABA))'
```

вернёт два старта:
- с позиции `0`;
- с позиции `2`.

Именно для таких случаев он и нужен: он не пропускает варианты внутри уже найденного фрагмента.

### Как считать длину найденной подцепочки
Если регулярное выражение найдено как `finditer(reg, s)`, то для каждого совпадения можно сразу взять его длину:

```python
len(fragment)
```

Если нужна самая длинная подцепочка без запрещённых символов, длина найденного фрагмента и есть ответ для этого фрагмента.

Если работать с объектом совпадения из `finditer`, всю найденную подстроку берут как `s1[0]` или `s1.group(0)`.

Число `0` означает весь найденный фрагмент целиком.

### Типичные ошибки
В задачах на регулярки часто ошибаются так:

- забывают `r` перед строкой с шаблоном;
- пишут шаблон без скобок и квантификатор начинает относиться не к тому элементу;
- используют слишком общий класс символов и захватывают лишнее;
- путают `fullmatch` и `finditer`;
- считают длину не того фрагмента;
- не замечают, что одна и та же подстрока должна собираться в один фрагмент.

### Шпаргалка по 24-му заданию

```python
*      - 0 или больше
+      - 1 или больше
?      - 0 или 1
{x,y}  - от x до y
{x,}   - от x и больше
{,y}   - от 0 до y
.      - любой символ
```

```python
[ABC]  - A или B или C
[^ABC] - любой, кроме A, B, C
[0-9]  - любая цифра
[A-Z]  - любая заглавная буква
```

```python
(AB)+      - AB, ABAB, ABABAB...
(?:AB)+    - то же самое, без лишней группы
(?=(...))  - просмотр вперёд, пересечения
```

```python
finditer   - все совпадения
group(0)   - весь фрагмент
group(1)   - первая захваченная группа
start()    - индекс начала
len(...)   - длина
```

```python
[...]+     - кусок из разрешённых символов
[^...]+    - кусок без запрещённых символов
```

Что смотреть первым:
- максимум или минимум;
- разрешённые или запрещённые символы;
- есть ли пересечения;
- один символ или блок;
- что считать: длину, индекс или число блоков.

### Прототип 952

**Текст задания**

В текстовом файле находится цепочка из символов латинского алфавита `A`, `B`, `C`, `D`, `E`, `F` и десятичных цифр. Найдите длину самой длинной подцепочки, не содержащей гласных букв.

Для выполнения этого задания следует написать программу.

**Идея решения**

Гласными буквами в этой задаче являются `A` и `E`. Значит, в подходящей подцепочке не должно быть ни одной из этих букв.

Так как в файле встречаются только цифры и буквы `A`, `B`, `C`, `D`, `E`, `F`, можно сразу описать все разрешённые символы:

```python
[0-9BCDF]+
```

Шаблон ищет все непрерывные фрагменты, состоящие только из разрешённых символов. Среди них нужно выбрать самый длинный.

**Код решения**

```python
from re import finditer

f = open('24_952.txt')
s = f.readline().strip()

reg = r'[0-9BCDF]+'
res = []

for s1 in finditer(reg, s):
    res.append(len(s1.group(0)))

print(max(res))
```

**Подробный разбор**

Строка из файла:

```python
s = f.readline().strip()
```

`strip()` убирает перевод строки в конце файла.

Шаблон:

```python
reg = r'[0-9BCDF]+'
```

Он означает последовательность из цифр и букв `B`, `C`, `D`, `F`.

Здесь не нужны группирующие скобки, потому что `+` относится ко всем символам внутри `[...]`.

`res` - список длин найденных фрагментов:

```python
res = []
```

Перебор совпадений:

```python
for s1 in finditer(reg, s):
```

`finditer` находит все подходящие подстроки.

Берём длину каждого совпадения:

```python
len(s1.group(0))
```

`group(0)` - весь фрагмент целиком.

Эта длина и есть ответ для данного фрагмента.

Дальше:

```python
print(max(res))
```

Берём максимум.

**Ответ**

95

### Прототип 4602

**Текст задания**

Текстовый файл состоит из символов `A`, `B`, `C`, `D` и `O`. Определите максимальное количество идущих подряд пар символов вида согласная + гласная.

Для выполнения этого задания следует написать программу.

**Идея решения**

В файле есть три согласные буквы:
- `B`;
- `C`;
- `D`.

И две гласные:
- `A`;
- `O`.

Одна пара должна состоять из двух символов:
- сначала согласная;
- потом гласная.

Если искать такую цепочку обычным шаблоном, то некоторые варианты могут не попасть в ответ, когда начинается новый фрагмент внутри уже найденного. Поэтому здесь удобнее использовать опережающий просмотр вперёд.

Например, если строка выглядит так:

```python
s = 'BADOBACO'
```

то обычный поиск `(?:[BCD][AO])+` вернёт один длинный фрагмент, который начинается с первой подходящей позиции.

Если внутри строки есть ещё подходящие старты, обычный `finditer` их отдельно не покажет.

А вот просмотр вперёд проверяет каждую позицию.

Ещё пример:

```python
s = 'BADOBACO'
```

Здесь можно увидеть такие старты цепочки:
- с позиции `0` начинается `BADOBACO`;
- с позиции `2` начинается `DOBACO`;
- с позиции `4` начинается `BACO`.

Если искать без просмотра вперёд, программа возьмёт только самый первый подходящий фрагмент и не будет отдельно проверять все последующие старты внутри него.

Шаблон записи такой:

```python
(?=((?:[BCD][AO])+))
```

Он читается так:
- `(?:[BCD][AO])+` - одна или больше подряд идущих пар `согласная + гласная`;
- внешнее `(?=...)` - проверить, что такой фрагмент начинается с текущей позиции, но не сдвигать сам поиск вперёд;
- внутренние скобки `(...)` - сохранить найденный фрагмент в группе `1`.

На строке вроде:

```python
s = 'BADOBACO'
```

это будет работать так:
- с позиции `0` находится `BADOBACO`;
- с позиции `2` находится `DOBACO`;
- с позиции `4` находится `BACO`;
- все эти фрагменты начинаются с согласной и дальше состоят из пар `согласная + гласная`.

Без просмотра вперёд часть таких стартов можно пропустить, потому что обычный `finditer` после совпадения прыгает дальше.

**Код решения**

```python
from re import finditer

f = open('24_4602.txt')
s = f.readline().strip()

reg = r'(?=((?:[BCD][AO])+))'
res = []

for s1 in finditer(reg, s):
    res.append(len(s1.group(1)) // 2)

print(max(res))
```

**Подробный разбор**

Строка из файла:

```python
s = f.readline().strip()
```

`strip()` убирает перевод строки в конце файла.

Дальше задаётся регулярное выражение:

```python
reg = r'(?=((?:[BCD][AO])+))'
```

Разберём его по частям.

`[BCD]` означает любую согласную из набора `B`, `C`, `D`.

`[AO]` означает любую гласную из набора `A`, `O`.

`(?:[BCD][AO])+` означает цепочку из одной или более пар `согласная + гласная`.

Здесь `?:` стоит не случайно. Он показывает, что скобки нужны только для объединения пары в один блок.

Если убрать `?:`, получится лишняя запоминающая группа. Тогда шаблон станет менее удобным для чтения, хотя сам смысл поиска почти не изменится.

Внешняя конструкция `(?=...)` нужна для пересечений. Она проверяет, что с текущей позиции строка начинается с подходящего фрагмента, но не сдвигает поиск.

`finditer` проверяет начало цепочки в каждой позиции строки.

`res` - список длин найденных фрагментов:

```python
res = []
```

Перебор совпадений:

```python
for s1 in finditer(reg, s):
```

Внутри просмотра вперёд нужный фрагмент хранится во внутренней группе:

```python
s1.group(1)
```

`group(1)` - это строка, которая подходит под шаблон внутри `(?=...)`.

Длина найденного фрагмента:

```python
len(s1.group(1))
```

Количество пар:

```python
len(s1.group(1)) // 2
```

Эта величина идёт в `res`.

В конце:

```python
print(max(res))
```

Берём максимум. Это и есть ответ.

**Ответ**

174

### Прототип 21421

**Текст задания**

Текстовый файл состоит из символов, обозначающих десятичные цифры и заглавные буквы латинского алфавита. Определите в прилагаемом файле максимальное количество идущих подряд символов, которые могут представлять запись чётного числа в двенадцатеричной системе счисления. В этой записи отсутствуют незначащие (ведущие) нули.

Для выполнения этого задания следует написать программу.

**Идея решения**

В двенадцатеричной записи можно использовать только:
- цифры `0`-`9`;
- буквы `A` и `B`.

Чётное число в 12-ричной системе должно оканчиваться на одну из цифр:

```python
02468A
```

Ведущий символ не должен быть `0`, если длина числа больше 1. Поэтому для длинных записей первая цифра берётся из набора:

```python
1-9A-B
```

Для однозначного числа подходит и `0`, и любая другая чётная 12-ричная цифра.

**Код решения**

```python
from re import finditer

f = open('24_21421.txt')
s = f.readline().strip()

num = r'(?:[1-9A-B][0-9A-B]*[02468A]|[02468A])'
reg = rf'(?=({num}([-*]{num})+))'
res = []

for s1 in finditer(reg, s):
    res.append(len(s1.group(1)))

print(max(res))
```

**Подробный разбор**

Строка из файла:

```python
s = f.readline().strip()
```

`strip()` убирает перевод строки в конце файла.

Шаблон:

```python
num = r'(?:[1-9A-B][0-9A-B]*[02468A]|[02468A])'
reg = rf'(?=({num}([-*]{num})+))'
```

`num` - это одно двенадцатеричное число без ведущих нулей.

Внутри `num` две части:
- `[1-9A-B][0-9A-B]*[02468A]` - число длиной больше 1;
- `[02468A]` - однозначное чётное число.

`reg` собирает уже всё выражение целиком:
- сначала число `num`;
- потом одна или больше пар `-num` или `*num`.

`(?=...)` нужен, чтобы проверять выражение с каждой позиции и не пропускать подходящие отрезки внутри строки.

`res` - список длин найденных фрагментов:

```python
res = []
```

Перебор совпадений:

```python
for s1 in finditer(reg, s):
```

Берём длину каждого совпадения:

```python
len(s1.group(0))
```

`group(0)` - это весь найденный фрагмент целиком.

Эта длина и есть длина подходящей записи числа, поэтому именно её добавляют в список `res`.

В конце:

```python
print(max(res))
```

Берём максимум. Это и есть ответ.

**Ответ**

19

### Прототип 20813

**Текст задания**

Текстовый файл состоит из цифр `0`, `7`, `8`, `9` и знаков арифметических операций `-` и `*` (вычитание и умножение). Определите максимальное количество символов в непрерывной последовательности, которая является корректным арифметическим выражением с целыми неотрицательными числами. В этом выражении никакие два знака арифметических операций не стоят рядом, в записи чисел отсутствуют незначащие (ведущие) нули и число `0` не имеет знака.

Для выполнения этого задания следует написать программу.

**Идея решения**

Корректное выражение здесь состоит из:
- числа;
- затем нуля или более повторений пары `оператор + число`.

Число бывает двух видов:
- `0`;
- число, начинающееся с `7`, `8` или `9`, а дальше состоящее только из `0`, `7`, `8`, `9`.

Для этого удобно записать шаблон:

```python
num = r'(?:0|[789][0789]*)'
reg = rf'(?=({num}(?:[-*]{num})*))'
```

`num` - это одно число без ведущих нулей.

`reg` описывает всё выражение целиком:
- сначала число;
- потом ноль или больше пар `-число` или `*число`.

**Код решения**

```python
from re import finditer

f = open('24_20813.txt')
s = f.readline().strip()

num = r'(?:0|[789][0789]*)'
reg = rf'(?=({num}(?:[-*]{num})*))'
res = []

for s1 in finditer(reg, s):
    res.append(len(s1.group(1)))

print(max(res))
```

**Подробный разбор**

Строка из файла:

```python
s = f.readline().strip()
```

`strip()` убирает перевод строки в конце файла.

Шаблон:

```python
num = r'(?:0|[789][0789]*)'
reg = rf'(?=({num}(?:[-*]{num})*))'
```

`num` - это одно число без ведущих нулей.

`reg` собирает всё выражение целиком:
- сначала число;
- потом ноль или больше пар `-число` или `*число`.

`(?=...)` проверяет выражение с каждой позиции.

`res` - список длин найденных фрагментов:

```python

```

Перебор совпадений:

```python

```

Берём длину каждого совпадения:

В конце:

```python
print(max(res))
```

Берём максимум. Это и есть ответ.

**Ответ**

### Прототип 22359

**Текст задания**

Текстовый файл состоит из десятичных цифр и заглавных букв латинского алфавита. Определите в этом файле последовательность идущих подряд символов, представляющих собой запись максимального кратного пяти 15-ричного числа. В ответе запишите индекс последнего символа, которым заканчивается запись этого числа в прилагаемом файле. Нумерация символов в текстовом файле начинается с нуля.

Для выполнения этого задания следует написать программу.

**Идея решения**

В 15-ричной записи используются цифры `0-9` и буквы `A-E`.

Число кратно 5, если оно оканчивается на:

```python
05A
```

В записи не должно быть ведущих нулей, если число состоит больше чем из одного символа.

**Код решения**

```python
from re import finditer

f = open('24_22359.txt')
s = f.readline().strip()

num = r'(?:[05A]|[1-9A-E][0-9A-E]*[05A])'
pat = rf'(?=({num}))'

best = ''
best_end = -1

for s1 in finditer(pat, s):
    x = s1.group(1)
    if len(x) > len(best) or len(x) == len(best) and x > best:
        best = x
        best_end = s1.start(1) + len(x) - 1

print(best_end)
```

**Подробный разбор**

Строка из файла:

```python
s = f.readline().strip()
```

`strip()` убирает перевод строки в конце файла.

Шаблон:

```python
num = r'(?:[05A]|[1-9A-E][0-9A-E]*[05A])'
pat = rf'(?=({num}))'
```

`num` описывает:
- однозначное число `0`, `5` или `A`;
- либо более длинное число, которое начинается не с `0`, дальше содержит только цифры 15-ричной системы и оканчивается на `0`, `5` или `A`.

`pat` проверяет это число с каждой позиции строки.

`finditer` находит все такие фрагменты.

Для каждого фрагмента:
- берём саму запись;
- сравниваем длину;
- при равной длине сравниваем запись.

```python
for s1 in finditer(pat, s):
    x = s1.group(1)
    if len(x) > len(best) or len(x) == len(best) and x > best:
        best = x
        best_end = s1.start(1) + len(x) - 1
```

`best_end` хранит индекс последнего символа максимального числа.

```python
print(best_end)
```

Это и есть ответ задачи.

**Ответ**

7432968

**Альтернативный вариант**

Можно сделать в два шага:

1. найти максимальную длину подходящего числа;
2. вывести все кандидаты этой длины с их стартом;
3. выбрать нужную запись глазами и через `s.index(...)` получить индекс последнего символа.

```python
from re import finditer

s = open('24_22359.txt').readline().strip()
pat = r'(?=([1-9A-E][0-9A-E]*[05A]))'

best_len = 0
cands = []

for s1 in finditer(pat, s):
    x = s1.group(1)
    if len(x) > best_len:
        best_len = len(x)
        cands = [(s1.start(1), x)]
    elif len(x) == best_len:
        cands.append((s1.start(1), x))

print(best_len)
for pos, x in cands:
    print(pos, x)

best = cands[0][1]  # здесь глазами выбирают нужную запись
print(s.index(best) + best_len - 1)
```

Сначала выводится максимальная длина, потом печатаются все записи этой длины вместе с их стартом. После этого нужную запись выбирают вручную и считают индекс последнего символа так:

```python
s.index(best) + best_len - 1
```
