## 1. ТЕОРИЯ

### Что требуется в задании 24
В задачах этого типа дан текстовый файл с одной длинной строкой. Нужно найти непрерывный фрагмент строки, который удовлетворяет условию, и определить его длину.

Иногда требуется найти максимальную длину подходящей подстроки, иногда минимальную. Но в обоих случаях работа идёт с одной и той же идеей: нужно рассматривать непрерывные куски строки и проверять условие задачи.

Важно помнить:
- рассматриваются именно подстроки, то есть куски строки подряд;
- ответом обычно является длина подстроки;
- саму подстроку чаще всего выводить не нужно.

### Главная идея решения
Подстрока задаётся двумя индексами:
- `i` — начало;
- `j` — конец.

Если исходная строка хранится в переменной `s`, то подстрока записывается так:

```python
s[i:j + 1]
```

`j + 1` нужен потому, что в Python правая граница среза не входит в результат.

Общий перебор устроен так:
- внешний цикл перебирает все возможные начала подстроки;
- внутренний цикл перебирает возможные концы;
- для каждой подстроки проверяется условие;
- если условие выполнено, обновляется ответ.

### Какие конструкции Python здесь нужны
Для таких задач обычно используются:

- `open(...).readline()` — чтение строки из файла;
- `strip()` — удаление перевода строки в конце;
- `replace()` — замена символов, если это упрощает условие;
- `len()` — длина строки или подстроки;
- `count()` — подсчёт количества символов;
- вложенные циклы `for`;
- проверка вхождения через `in` и `not in`;
- `break` — досрочный выход из внутреннего цикла.

### Зачем нужен `strip()`
После чтения строки из файла в конце обычно остаётся символ перевода строки `\n`. Его лучше сразу убрать:

```python
s = f.readline().strip()
```

Так строка очищается от лишнего символа, который не должен участвовать в решении.

### Базовый шаблон перебора
Если не думать пока об оптимизациях, схема у таких задач одна и та же:

1. Считать строку из файла.
2. При необходимости упростить условие.
3. Завести переменную ответа.
4. Перебрать все возможные начала подстроки.
5. Для каждого начала перебрать все возможные концы.
6. Построить текущую подстроку.
7. Проверить условие.
8. Обновить ответ.

### Частые ошибки
В задачах 24 часто ошибаются в одних и тех же местах:

- забывают сделать `strip()`;
- пишут `s[i:j]` вместо `s[i:j + 1]`;
- путают максимум и минимум при выборе начального значения переменной ответа;
- начинают внутренний цикл не с той границы;
- используют `break` там, где он не подходит по смыслу;
- забывают, что проверяется именно непрерывная подстрока, а не произвольный набор символов.

## 2. РАЗБОР ПРОТОТИПОВ

### Прототип: максимальная подстрока без двух подряд идущих букв из `N`, `O`, `P`

**Текст задания**
Текстовый файл состоит из символов, обозначающих прописные буквы латинского алфавита.
Определите максимальное количество идущих подряд символов, среди которых никакие две буквы из набора букв `N`, `O` и `P` (с учетом повторений) не записаны подряд.
Для выполнения этого задания следует написать программу.

**Идея решения**
По условию нельзя, чтобы рядом стояли две буквы из набора `N`, `O`, `P`.

Если проверять это напрямую, придётся учитывать все пары:
`NN`, `NO`, `NP`, `ON`, `OO`, `OP`, `PN`, `PO`, `PP`.

Так делать неудобно, поэтому условие упрощают:
- все `N` заменяют на `P`;
- все `O` тоже заменяют на `P`.

После этого задача сводится к простой проверке: в подходящей подстроке не должно быть фрагмента `PP`.

**Неоптимизированный код**
```python
f = open('24_8510.txt')
s = f.readline().strip()

s = s.replace('N', 'P')
s = s.replace('O', 'P')

m = 0
lns = len(s)

for i in range(lns):
    for j in range(i, lns):
        string = s[i:j + 1]

        if 'PP' not in string:
            m = max(m, len(string))

print(m)
```

**Почему такой код медленный**
Этот вариант правильный, но делает слишком много лишней работы.

Во-первых, он для каждого `i` перебирает все подстроки до самого конца строки.

Во-вторых, даже если в подстроке уже появился фрагмент `PP`, программа всё равно продолжает удлинять эту же подстроку и проверять её дальше, хотя понятно, что она уже не подойдёт.

Например, пусть рассматривается строка `ABPPCX`.
Если уже получилась подстрока `ABPP`, то дальше будут `ABPPC` и `ABPPCX`.
Во всех них `PP` уже есть, значит проверять их бессмысленно.

**Первая оптимизация**
Если в текущей подстроке уже встретилось `PP`, можно сразу делать `break`.

Причина простая: дальше подстрока только расширяется, а значит фрагмент `PP` никуда не исчезнет.

**Вторая оптимизация**
Если уже найден максимум `m`, нет смысла проверять подстроки длины меньше или равной `m`.

Например, если уже найдена подходящая подстрока длины 5, то для нового начала нет смысла снова проверять строки длины 1, 2, 3, 4 и 5. Они всё равно не дадут лучший ответ.

Пусть строка начинается как `ABCDEFGH`.
Без оптимизации пришлось бы проверить:
`A`, `AB`, `ABC`, `ABCD`, `ABCDE`, `ABCDEF`, `ABCDEFG`, `ABCDEFGH`.

Если уже найдено `m = 5`, можно начинать сразу с `ABCDEF`.

**Код решения**
```python
f = open('24_8510.txt')
s = f.readline().strip()

s = s.replace('N', 'P')
s = s.replace('O', 'P')

m = 0
lns = len(s)

for i in range(lns):
    for j in range(i + m, lns):
        string = s[i:j + 1]

        if 'PP' not in string:
            m = len(string)
        else:
            break

print(m)
```

**Подробный разбор**
Сначала строка считывается из файла:

```python
s = f.readline().strip()
```

`strip()` убирает символ перевода строки в конце файла.

Дальше строка упрощается:

```python
s = s.replace('N', 'P')
s = s.replace('O', 'P')
```

Теперь все буквы `N`, `O`, `P` сведены к одной букве `P`, и проверять нужно только отсутствие `PP`.

Переменная `m` хранит максимальную длину подходящей подстроки:

```python
m = 0
```

Внешний цикл перебирает индекс начала:

```python
for i in range(lns):
```

Внутренний цикл перебирает индекс конца:

```python
for j in range(i + m, lns):
```

Он начинается с `i + m`, потому что более короткие подстроки уже не дадут новый максимум.

Текущая подстрока записывается так:

```python
string = s[i:j + 1]
```

Если `PP` в ней нет, длина подходит:

```python
if 'PP' not in string:
    m = len(string)
```

Здесь можно писать именно `m = len(string)`, а не `max`, потому что цикл уже устроен так, что рассматриваются только подстроки длиннее текущего максимума.

Если же `PP` встретилось, выполняется:

```python
else:
    break
```

Это и есть первая оптимизация. Дальше расширять эту подстроку бессмысленно.

**Ответ**
57

### Прототип: минимальная длина подстроки, в которой буква `Z` встречается не менее 120 раз

**Текст задания**
Текстовый файл состоит не более чем из `10^6` символов и содержит только заглавные буквы латинского алфавита.
Определите минимальную длину подстроки, в которой символ `Z` встречается не менее 120 раз.

**Идея решения**
Здесь уже нужно искать не максимум, а минимум. Общая схема перебора остаётся той же, но логика оптимизаций меняется.

Если уже найден некоторый минимум, то нет смысла рассматривать подстроки длиннее него. Кроме того, здесь выгодно перебирать подстроки от более длинной к более короткой.

Почему это удобно: если в какой-то момент букв `Z` стало меньше 120, то в ещё более коротких подстроках их тоже не хватит. Значит, можно сразу остановиться.

**Неоптимизированный код**
```python
f = open('24_16682.txt')
s = f.readline().strip()

lns = len(s)
m = lns

for i in range(lns):
    for j in range(i, lns):
        string = s[i:j + 1]

        if string.count('Z') >= 120:
            m = min(m, len(string))

print(m)
```

**Почему такой код медленный**
Этот вариант снова перебирает слишком много лишних подстрок.

Он каждый раз идёт от `i` до конца строки и считает `string.count('Z')` даже там, где уже понятно, что улучшить ответ не получится.

Кроме того, если взять очень большое начальное значение `m`, например длину всей строки, то первая итерация получится особенно тяжёлой: программа начнёт с очень длинных подстрок и будет долго их пересчитывать.

**Первая оптимизация**
Нужно разумно выбрать начальное значение `m`.

Для минимума стартовое значение должно быть больше реального ответа, иначе ответ не обновится.

Например, если настоящий ответ равен 2310:
- при `m = 1000` программа может просто вывести 1000, потому что не найдёт подходящую подстроку короче или равную 1000;
- при `m = 10000` программа уже сможет обновить ответ.

**Вторая оптимизация**
Если уже найден текущий минимум `m`, нет смысла рассматривать подстроки длиннее него.

Например, если уже найден ответ длины 8, то для нового начала нет смысла проверять строки длины 9, 10 и больше. Они точно не улучшат минимум.

**Третья оптимизация**
Подстроки удобно перебирать от длинной к короткой.

Например, пусть нужно не менее 3 букв `Z`, а рассматривается строка `ABZZCZD`.
Если идти от длинной подстроки к короткой, можно сначала получить `ABZZCZ`, где 3 буквы `Z`.
Потом будет `ABZZC`, где уже только 2 буквы `Z`.

После этого можно сразу остановиться, потому что в подстроках `ABZZ`, `ABZ` и `AB` букв `Z` уже точно не станет больше.

**Код решения**
```python
f = open('24_16682.txt')
s = f.readline().strip()

lns = len(s)
m = 10000

for i in range(lns):
    for j in range(i + m, i, -1):
        string = s[i:j + 1]

        if string.count('Z') >= 120:
            m = len(string)
        elif string.count('Z') < 120:
            break

print(m)
```

**Подробный разбор**
Сначала строка считывается из файла:

```python
s = f.readline().strip()
```

Дальше находится её длина:

```python
lns = len(s)
```

Переменная `m` хранит текущую минимальную длину подходящей подстроки:

```python
m = 10000
```

Это стартовое значение взято с запасом. Оно должно быть больше реального ответа.

Внешний цикл перебирает начало подстроки:

```python
for i in range(lns):
```

Внутренний цикл идёт справа налево:

```python
for j in range(i + m, i, -1):
```

Это значит, что сначала рассматриваются более длинные подстроки, потом более короткие.

Текущая подстрока:

```python
string = s[i:j + 1]
```

Если в ней хотя бы 120 букв `Z`, она подходит:

```python
if string.count('Z') >= 120:
    m = len(string)
```

Если же букв `Z` уже меньше 120, выполняется:

```python
elif string.count('Z') < 120:
    break
```

Это и есть ключевая оптимизация для задачи на минимум. Дальше подстрока будет только укорачиваться, а значит букв `Z` больше уже не станет.

**Ответ**
2310
