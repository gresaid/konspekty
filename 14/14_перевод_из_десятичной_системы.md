# ТЕОРИЯ

**Что нужно уметь в этой теме**

В этой части задания 14 схема почти всегда одна и та же: число или значение выражения переводят из десятичной системы в другую, а затем задают вопрос уже к новой записи.

Обычно спрашивают:

| Что ищем | Как выглядит вопрос |
|---|---|
| Количество конкретной цифры | Сколько цифр `6` в записи? |
| Сумму цифр | Чему равна сумма всех цифр? |
| Количество цифр с условием | Сколько цифр не превышают `9`? |
| Значение переменной | При каком `x` выполняется нужное условие? |

Поэтому нужно уметь:
- переводить число из десятичной системы в систему с основанием `b`;
- понимать, что означает каждая цифра новой записи;
- работать с цифрами как со списком данных.

**Главная схема решения**

Тему удобно держать в голове как один маршрут:

```text
выражение -> значение числа -> перевод в систему с основанием b -> список цифр -> ответ на вопрос задачи
```

Чаще всего меняется только последний шаг. Сам перевод почти всегда делается по одному и тому же шаблону.

**Системы счисления: быстрый ориентир**

Система счисления задаётся основанием `b`. Основание показывает, сколько разных цифр можно использовать в записи числа.

| Система | Основание | Допустимые цифры |
|---|---:|---|
| Десятичная | `10` | `0, 1, 2, ..., 9` |
| Двоичная | `2` | `0, 1` |
| Пятеричная | `5` | `0, 1, 2, 3, 4` |
| Семеричная | `7` | `0, 1, 2, 3, 4, 5, 6` |
| Девятеричная | `9` | `0, 1, 2, ..., 8` |

Главное правило:

```text
максимальная цифра в системе с основанием b равна b - 1
```

Отсюда сразу следуют типичные наблюдения:
- в двоичной системе есть только `0` и `1`;
- в пятеричной системе нет цифры `5`;
- в восьмеричной системе нет цифры `8`.

**Если основание больше 10**

Когда цифр становится больше десяти, после `9` используют латинские буквы.

| Числовое значение | Обозначение |
|---:|---|
| 10 | `A` |
| 11 | `B` |
| 12 | `C` |
| 13 | `D` |
| 14 | `E` |
| 15 | `F` |

Для ручного чтения записи это важно. Но в задачах ЕГЭ чаще удобнее хранить цифры как числа `10`, `11`, `12`, а не как символы `A`, `B`, `C`: так их проще считать, сравнивать и суммировать.

**Как выполняется перевод из 10-й системы**

Перевод из десятичной системы в систему с основанием `b` строится на делении с остатком.

Алгоритм:
1. Делим число на `b`.
2. Запоминаем остаток.
3. Делим частное снова на `b`.
4. Повторяем, пока частное не станет равно `0`.
5. Остатки читаем снизу вверх.

Главная мысль:

> Цифры новой записи появляются как остатки от деления на основание системы.

**Пример перевода вручную**

Переведём `67` в пятеричную систему:

```text
67 : 5 = 13, остаток 2
13 : 5 = 2,  остаток 3
2  : 5 = 0,  остаток 2
```

Остатки получаются в таком порядке:

```text
2, 3, 2
```

Но записывать ответ нужно с конца к началу:

```text
67(10) = 232(5)
```

Поэтому в коде цифры сначала накапливаются в обратном порядке, а потом разворачиваются.

**Два действия, которые нельзя путать**

| Операция | Что она делает |
|---|---|
| `x % base` | даёт очередную цифру новой записи |
| `x //= base` | убирает уже обработанный разряд |

Если вместо `//` использовать `/`, алгоритм перестаёт быть переводом по разрядам: число становится вещественным, и решение ломается.

**Универсальная функция перевода**

Для задач ЕГЭ удобнее сразу получать список цифр:

```python
def f(x, b):
    d = []

    while x > 0:
        d.append(x % b)
        x //= b

    return d[::-1]
```

Почему здесь именно список:
- `count` удобно считает нужные цифры;
- `sum` сразу даёт сумму цифр;
- цикл `for` позволяет проверять любые дополнительные условия;
- список чисел удобнее строки, если основание больше `10`.

**Как читать функцию `f`**

| Строка кода | Смысл |
|---|---|
| `d = []` | сюда собираются цифры новой записи |
| `d.append(x % b)` | добавляем текущий остаток |
| `x //= b` | переходим к следующему шагу деления |
| `d[::-1]` | получаем правильный порядок цифр |

Пример:

```python
print(f(67, 5))
```

Результат:

```text
[2, 3, 2]
```

Это означает, что число `67` в пятеричной системе записывается как `232`.

**Особый случай: число равно нулю**

В большинстве задач темы переводят большие положительные числа, поэтому базового шаблона обычно достаточно. Но полностью универсальная версия должна отдельно обрабатывать `0`:

```python
def f(x, b):
    if x == 0:
        return [0]

    d = []

    while x > 0:
        d.append(x % b)
        x //= b

    return d[::-1]
```

Это полезно как общий надёжный шаблон, хотя в большинстве прототипов отдельный случай `0` не влияет на решение.

**Встроенные функции Python**

Для трёх систем счисления Python уже умеет делать перевод сам:

| Функция | Что возвращает |
|---|---|
| `bin(x)` | двоичную запись |
| `oct(x)` | восьмеричную запись |
| `hex(x)` | шестнадцатеричную запись |

Пример:

```python
a = 250

print(bin(a))
print(oct(a))
print(hex(a))
```

Результат:

```text
0b11111010
0o372
0xfa
```

Важно помнить:

| Функция | Служебный префикс |
|---|---|
| `bin` | `0b` |
| `oct` | `0o` |
| `hex` | `0x` |

Эти функции возвращают строку, а первые два символа не относятся к самой записи числа. Поэтому при необходимости их срезают:

```python
a = 250

print(bin(a)[2:])
print(oct(a)[2:])
print(hex(a)[2:])
```

**Когда брать встроенную функцию, а когда свою**

| Ситуация | Что использовать |
|---|---|
| Основание `2` | `bin` |
| Основание `8` | `oct` |
| Основание `16` | `hex` |
| Любое другое основание | `f(x, b)` |

Практически это означает:
- для двоичной, восьмеричной и шестнадцатеричной записи часто выгодно использовать встроенные функции;
- для `5`, `7`, `9`, `25`, `49` и других систем нужна своя функция перевода `f`.

**Что делать после перевода**

После перевода задача обычно становится короткой.

| Что нужно найти | Как это выглядит в коде |
|---|---|
| Количество цифры `6` | `d.count(6)` |
| Количество нулей | `d.count(0)` |
| Сумму цифр | `sum(d)` |
| Длину записи | `len(d)` |

Если условие относится не к одной цифре, а к диапазону значений, нужен перебор цифр.

Количество цифр, превышающих `10`:

```python
cnt = 0

for x in d:
    if x > 10:
        cnt += 1
```

Количество цифр, не превышающих `9`:

```python
cnt = 0

for x in d:
    if x <= 9:
        cnt += 1
```

**Базовый шаблон решения**

Для большинства задач этой темы подходит такой каркас:

```python
v = ...
d = f(v, b)

# дальше вопрос к цифрам
```

Если в условии есть переменная `x`, шаблон становится таким:

```python
for x in range(...):
    v = ...
    d = f(v, b)

    # проверка условия
```

**Как вести перебор переменной**

Здесь важно различать два типа вопросов.

| Что требует задача | Как действовать |
|---|---|
| Найти минимальное `x` | идти по возрастанию и после первого подходящего значения делать `break` |
| Найти максимальное `x` | проверить весь диапазон и хранить лучший ответ |

Это уже часть логики решения, а не просто стиль записи.

**Типичные ошибки**

| Ошибка | Почему это неверно |
|---|---|
| Остатки читают сверху вниз | правильная запись получается только в обратном порядке |
| Используют `/` вместо `//` | алгоритм перевода должен работать с целыми частными |
| Забывают убрать `0b`, `0o`, `0x` | служебные символы не входят в саму запись числа |
| Хранят цифры больших оснований как строки без необходимости | числа `10`, `11`, `12` удобнее сравнивать и суммировать |
| Отвечают на вопрос до перевода в нужную систему | проверять нужно именно новую запись |
| Не ставят `break`, когда нужен минимальный ответ | программа продолжает перебор и теряет смысл поиска первого подходящего значения |

**Шпаргалка перед практикой**

```text
1. Вычислить значение выражения.
2. Перевести его в систему с основанием b.
3. Получить список цифр.
4. Ответить на вопрос задачи по этому списку.
```

## Прототип 1. Классика: подсчёт одной цифры

**Текст задания**

Значение выражения `7^103 + 20 * 7^204 - 3 * 7^57 + 97` записали в системе счисления с основанием `7`. Сколько цифр `6` содержится в этой записи?

**Идея решения**

Система счисления здесь не стандартная, поэтому используем универсальную функцию перевода в основание `7`. После перевода остаётся только посчитать количество цифр `6`.

**Код решения**

```python
def f(x, b):
    d = []

    while x > 0:
        d.append(x % b)
        x //= b

    return d[::-1]


v = 7**103 + 20 * 7**204 - 3 * 7**57 + 97
d = f(v, 7)

print(d.count(6))
```

**Разбор решения**

Сначала вычисляется значение выражения. Python умеет работать с очень большими целыми числами, поэтому степени такого размера считаются напрямую.

Функция `f` переводит число в семеричную систему и возвращает список цифр. После этого задача сводится к одной операции: `d.count(6)`.

Это базовый шаблон для большого числа задач №14: перевести и задать вопрос к списку цифр.

**Ответ**

```text
48
```

## Прототип 2. Классика: сумма цифр

**Текст задания**

Значение арифметического выражения `6 * 343^1156 - 5 * 49^1147 + 4 * 7^1153 - 875` записали в системе счисления с основанием `7`. Определите сумму всех цифр в записи этого числа.

**Идея решения**

Основа решения та же: вычисляем значение выражения и переводим его в семеричную систему. Отличие только в последнем действии: теперь нужно не количество одной цифры, а сумма всех цифр.

**Код решения**

```python
def f(x, b):
    d = []

    while x > 0:
        d.append(x % b)
        x //= b

    return d[::-1]


v = 6 * 343**1156 - 5 * 49**1147 + 4 * 7**1153 - 875
d = f(v, 7)

print(sum(d))
```

**Разбор решения**

Функция перевода не меняется. Меняется только вопрос к уже готовому списку цифр.

Вместо `count` используется `sum`, потому что каждый элемент списка `d` — это числовое значение цифры в семеричной записи.

Этот прототип показывает важную мысль: после перевода число уже представлено в удобной форме, и дальше задача зависит только от того, что именно требуется посчитать.

**Ответ**

```text
13950
```

## Прототип 3. Подсчёт цифр с условием

**Текст задания**

Значение арифметического выражения `2 * 2401^525 + 3 * 343^524 - 4 * 49^523 + 5 * 49^522 - 6 * 7^521 - 35` записали в системе счисления с основанием `49`. Определите в `49`-ричной записи числа количество цифр с числовым значением, не превышающим `9`.

**Идея решения**

Здесь уже недостаточно одного `count`, потому что подходят разные цифры: `0, 1, 2, ..., 9`. Поэтому после перевода нужно перебрать все цифры и проверить условие `d <= 9`.

**Код решения**

```python
def f(x, b):
    d = []

    while x > 0:
        d.append(x % b)
        x //= b

    return d[::-1]


v = 2 * 2401**525 + 3 * 343**524 - 4 * 49**523 + 5 * 49**522 - 6 * 7**521 - 35
d = f(v, 49)

cnt = 0

for x in d:
    if x <= 9:
        cnt += 1

print(cnt)
```

**Разбор решения**

Главное отличие от предыдущих задач — вопрос относится не к одной конкретной цифре, а к диапазону значений.

В системе счисления с основанием `49` каждая цифра может быть от `0` до `48`. Поэтому условие `d <= 9` означает: нужно посчитать все цифры с числовыми значениями `0, 1, ..., 9`.

Здесь особенно важно хранить цифры как числа. Если переводить запись в строку, пришлось бы отдельно думать о цифрах больше `9`. В списке чисел эта проблема исчезает.

**Ответ**

```text
267
```

## Прототип 4. Минимальное значение переменной по сумме цифр

**Текст задания**

При каком наименьшем натуральном значении переменной `x` в выражении `81^20 - 9^x + 50` сумма цифр в девятеричной записи числа равна `138`?

**Идея решения**

Появляется неизвестная `x`, поэтому её нужно перебирать. Для каждого значения `x` считаем выражение, переводим результат в девятеричную систему и проверяем сумму цифр.

Так как требуется наименьшее значение `x`, перебор ведём по возрастанию и останавливаемся сразу после первого подходящего ответа.

**Код решения**

```python
def f(x, b):
    d = []

    while x > 0:
        d.append(x % b)
        x //= b

    return d[::-1]


for x in range(1, 1000):
    v = 81**20 - 9**x + 50
    d = f(v, 9)

    if sum(d) == 138:
        print(x)
        break
```

**Разбор решения**

Так как `x` — натуральное число, перебор начинается с `1`.

Верхнюю границу в таких задачах берут с запасом. Здесь важно не угадать минимально возможный предел, а гарантированно попасть в область, где есть ответ.

Проверка состоит из двух шагов:
- вычислить запись числа в системе счисления с основанием `9`;
- проверить условие `sum(d) == 138`.

Команда `break` здесь обязательна по смыслу задачи: без неё программа найдёт все подходящие значения, а нужен именно минимальный `x`.

**Ответ**

```text
24
```

## Прототип 5. Перебор с условием на точное количество нулей

**Текст задания**

Значение арифметического выражения `3^100 - x`, где `x` — целое положительное число, не превышающее `2030`, записали в троичной системе счисления. Определите наибольшее значение `x`, при котором в троичной записи числа содержится ровно пять нулей. В ответе запишите число в десятичной системе счисления.

**Идея решения**

Здесь тоже есть перебор параметра, но теперь требуется наибольшее подходящее значение. Поэтому удобно пройти по всем `x` из допустимого диапазона и обновлять ответ, когда выполняется условие `d.count(0) == 5`.

**Код решения**

```python
def f(x, b):
    d = []

    while x > 0:
        d.append(x % b)
        x //= b

    return d[::-1]


ans = 0

for x in range(1, 2031):
    v = 3**100 - x
    d = f(v, 3)

    if d.count(0) == 5:
        ans = x

print(ans)
```

**Разбор решения**

Перебираются все значения `x` от `1` до `2030` включительно, потому что диапазон дан в условии.

После перевода в троичную систему остаётся проверить только одно свойство записи: ровно ли пять нулей в списке цифр.

Переменная `ans` хранит последнее подходящее значение `x`. Так как перебор идёт по возрастанию, после завершения цикла в `ans` останется максимальный подходящий ответ.

Это отличие от предыдущего прототипа: там нужен был минимальный `x`, поэтому использовался `break`, а здесь нужен максимальный, поэтому перебор надо довести до конца.

**Ответ**

```text
2024
```

## Прототип 6. Перебор с оптимизацией по целевой цифре

**Текст задания**

Значение арифметического выражения `3^100 - x`, где `x` — целое положительное число, не превышающее `2030`, записали в троичной системе счисления. Определите наибольшее значение `x`, при котором количество нулей в троичной записи числа максимально. В ответе запишите число в десятичной системе счисления.

**Идея решения**

Теперь условие не задаёт точное число нулей заранее. Сначала нужно понять, какое количество нулей вообще максимально, а потом выбрать наибольшее `x`, при котором этот максимум достигается.

**Код решения**

```python
def f(x, b):
    d = []

    while x > 0:
        d.append(x % b)
        x //= b

    return d[::-1]


a = []

for x in range(1, 2031):
    v = 3**100 - x
    d = f(v, 3)
    z = d.count(0)

    a.append(z)

mx = max(a)
r = []

for x in range(1, 2031):
    v = 3**100 - x
    d = f(v, 3)

    if d.count(0) == mx:
        r.append(x)

print(max(r))
```

**Разбор решения**

В отличие от предыдущего прототипа, здесь заранее неизвестно, сколько нулей даёт лучший результат. Поэтому решение удобно разбить на два прохода.

В первом цикле для каждого `x` считается количество нулей в троичной записи, и эти значения добавляются в список `a`. После этого команда `max(a)` даёт максимальное возможное число нулей.

Во втором цикле перебор повторяется, и в список `r` собираются все `x`, при которых число нулей равно найденному максимуму. Команда `max(r)` выбирает из них наибольшее значение, которое и требуется по условию.

**Ответ**

```text
2025
```
