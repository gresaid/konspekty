# ТЕОРИЯ

**О чём эта тема**

В этом типе задания число уже записано в некоторой системе счисления, а ответ нужно получить в десятичной системе или через свойства этой записи. Обычно задача сводится к одному из четырёх вопросов.

| Что неизвестно | Что нужно сделать |
|---|---|
| Значение числа | Перевести запись в десятичную систему |
| Цифра `x` | Перебрать допустимые значения и проверить условие |
| Основание `N` | Составить формулу или перебрать основания |
| Свойство записи | Использовать остаток, количество разрядов или делимость |

Главная идея темы простая: любую такую задачу нужно свести к обычным действиям с десятичными числами.

**Как устроен перевод в десятичную систему**

Если число записано в системе с основанием `b`, то каждая цифра даёт вклад в зависимости от своего разряда:

$a_n a_{n-1} \ldots a_1 a_0 = a_n \cdot b^n + a_{n-1} \cdot b^{n-1} + \ldots + a_1 \cdot b + a_0$

Правая цифра умножается на `b^0`, следующая справа налево — на `b^1`, затем на `b^2` и так далее.

Пример:

$321_{(5)} = 3 \cdot 5^2 + 2 \cdot 5 + 1 = 75 + 10 + 1 = 86$

Это главный принцип всей темы. Всё остальное — лишь удобные способы быстро применить эту формулу.

**Когда достаточно функции `int`**

Если основание системы не больше `36`, удобнее всего использовать встроенную функцию Python:

```python
int(s, base)
```

| Аргумент | Что означает |
|---|---|
| `s` | строка с записью числа |
| `base` | основание системы счисления |
| результат | десятичное значение числа |

Пример:

```python
print(int('101101', 2))
print(int('1234', 5))
print(int('1af', 16))
```

Нужно помнить несколько правил.

| Что важно | Пояснение |
|---|---|
| `int` работает только для оснований от `2` до `36` | при большем основании нужен ручной перевод |
| буквы обозначают цифры после `9` | `a = 10`, `b = 11`, `c = 12` и так далее |
| регистр не важен | `a` и `A` читаются одинаково |
| перевод идёт сразу в десятичную систему | отдельный перевод "через промежуточную систему" не нужен |

**Какие цифры допустимы в записи**

В системе с основанием `b` можно использовать цифры от `0` до `b - 1`. Это правило нужно проверять почти в каждой задаче с подстановкой.

| Основание | Допустимые цифры |
|---:|---|
| `2` | `0, 1` |
| `8` | `0, 1, ..., 7` |
| `11` | `0, 1, ..., 9, a` |
| `19` | `0, 1, ..., 9, a, b, ..., i` |

Из этого сразу следуют два типичных вывода:
- если в записи уже есть цифра `8`, основание точно больше `8`;
- если одна и та же переменная встречается в числах с разными основаниями, брать нужно только те значения, которые допустимы везде.

Например, если `x` стоит и в `19`-ричном числе, и в `11`-ричном, то реальный диапазон для `x` — от `0` до `10`.

**Как удобно перебирать неизвестную цифру**

Если неизвестная цифра может быть больше `9`, удобно брать символы из `printable`:

```python
from string import printable
```

Первые символы этой строки как раз соответствуют цифрам систем счисления:

```python
printable[:19]
```

Для `19`-ричной системы это даст:

```text
0123456789abcdefghi
```

Значит, буква `e` здесь играет роль цифры `14`, а буква `i` — цифры `18`.

Базовый шаблон для подстановки выглядит так:

```python
from string import printable

for x in printable[:base]:
    v = int(f'...', base)

    if ...:
        print(...)
```

Если нужно максимальное значение `x`, можно:
- идти по возрастанию и не прерывать цикл;
- идти по убыванию и остановиться на первом подходящем значении.

Оба способа корректны. Здесь важнее не стиль, а понимание, почему именно найденное значение будет максимальным.

**Что делать, если основание больше 36**

Для оснований больше `36` функция `int` уже не подходит. Тогда число нужно переводить по той же формуле разрядов, но вручную.

Если число `12x45` записано в системе с основанием `98`, его удобно хранить как список цифр:

```python
[1, 2, x, 4, 5]
```

Тогда перевод можно оформить так:

```python
def to_dec(digits, base):
    s = 0

    for i in range(len(digits)):
        s += digits[-1 - i] * base**i

    return s
```

Что здесь происходит:

| Строка | Смысл |
|---|---|
| `digits[-1 - i]` | берём цифры справа налево |
| `base**i` | считаем вес разряда |
| `s += ...` | накапливаем сумму |

Этот шаблон нужен для задач с основаниями вроде `98`, `123` и любыми другими, которые больше `36`.

**Как искать неизвестное основание**

Если неизвестно основание системы счисления, обычно работают два подхода.

| Способ | Когда удобен |
|---|---|
| Формула | когда запись короткая и легко раскрывается по разрядам |
| Перебор | когда выражение неудобно считать вручную или нужно быстро проверить варианты |

Пример:

$110_{(N)} = 39800_{(10)}$

Тогда:

$1 \cdot N^2 + 1 \cdot N + 0 = 39800$

Получаем:

$N^2 + N = 39800$

В коротких записях такой путь обычно самый быстрый.

**Как использовать свойства записи без полного перевода**

Не всегда нужно полностью переводить число в другую систему. Иногда достаточно использовать одно свойство записи.

**Последняя цифра**

Если запись числа в системе с основанием `N` оканчивается на цифру `r`, то при делении на `N` это число даёт остаток `r`.

| Свойство записи | Что это означает |
|---|---|
| оканчивается на `0` | `x % N == 0` |
| оканчивается на `1` | `x % N == 1` |
| оканчивается на `r` | `x % N == r` |

То есть последняя цифра — это остаток от деления на основание.

**Количество цифр**

Если запись числа в системе с основанием `N` содержит ровно `k` цифр, то:

$N^{k-1} \le x < N^k$

Примеры:

| Условие | Неравенство |
|---|---|
| число двузначное | $N \le x < N^2$ |
| число трёхзначное | $N^2 \le x < N^3$ |
| число четырёхзначное | $N^3 \le x < N^4$ |

Это свойство часто позволяет сразу резко сузить диапазон возможных оснований.

**Типичные ошибки**

- Подставляют в `int` основание больше `36`.
- Забывают проверить, допустима ли цифра `x` во всех числах задачи.
- Путают буквенное обозначение цифры и её числовое значение.
- Считают степени основания слева направо, а не справа налево.
- Путают последнюю цифру записи и частное от деления: последняя цифра — это остаток.
- При поиске максимального значения останавливают цикл слишком рано.

**Короткая схема решения**

| Ситуация | Что делать |
|---|---|
| Основание известно и не больше `36` | использовать `int(s, base)` |
| Основание известно и больше `36` | переводить по формуле разрядов вручную |
| Неизвестна цифра | перебрать допустимые значения |
| Неизвестно основание | составить формулу или перебрать варианты |
| Известна последняя цифра | перейти к остатку от деления |
| Известно число разрядов | записать неравенство $N^{k-1} \le x < N^k$ |

# РАЗБОР ПРОТОТИПОВ

Из приведённых ниже примеров только первый прототип встречался на реальном ЕГЭ. Все остальные прототипы полезно разобрать как возможные варианты усложнения этой темы.

## Прототип 1. Подстановка в известную систему счисления

**Текст задания**

Операнды арифметического выражения записаны в системе счисления с основанием `19`:

```text
14626x7(19) + 14161769x(19) + 72x383(19)
```

В записи чисел переменной `x` обозначена неизвестная цифра из алфавита `19`-ричной системы счисления. Определите наибольшее значение `x`, при котором значение данного арифметического выражения кратно `18`. Для найденного `x` вычислите частное от деления значения арифметического выражения на `18` и укажите его в ответе в десятичной системе счисления.

**Идея решения**

Основание известно и не превышает `36`, значит, каждое число можно сразу переводить через `int`. Неизвестная цифра `x` перебирается по всем допустимым символам `19`-ричной системы. Если нравится более наглядная запись, можно отдельно посчитать каждое слагаемое и не останавливать цикл: тогда последним выведенным значением будет ответ для максимальной подходящей цифры.

**Код решения**

```python
from string import printable

for x in printable[:19]:
    a = int(f'14626{x}7', 19)
    b = int(f'14161769{x}', 19)
    c = int(f'72{x}383', 19)
    v = a + b + c

    if v % 18 == 0:
        print(v // 18)
```

**Разбор решения**

Строка `printable[:19]` даёт все допустимые цифры `19`-ричной системы: от `0` до `i`.

Для каждого символа `x` отдельно считаются три слагаемых:
- `a` — значение числа `14626x7(19)`;
- `b` — значение числа `14161769x(19)`;
- `c` — значение числа `72x383(19)`.

После этого они складываются в переменную `v`.

После этого задача сводится к обычной проверке делимости:

```python
if v % 18 == 0
```

Подходящих значений может быть несколько, но перебор идёт по возрастанию, поэтому последним будет решение с максимальной цифрой `x`.

Подходящее наибольшее значение — `x = e`, то есть цифра `14`.

**Ответ**

```text
1149809562
```

## Прототип 2. Подстановка при основаниях больше 36

**Текст задания**

Значение выражения

```text
124x5(98) + 1x98(123)
```

кратно `123`. Здесь `x` — цифра, допустимая в обеих системах счисления. Найдите значение выражения, делённое на `123`.

**Идея решения**

Основания `98` и `123` больше `36`, поэтому `int` использовать нельзя. Нужно хранить каждое число как список цифр и переводить его в десятичную систему по формуле разрядов.

Так как `x` должна быть допустимой и в `98`-ричной, и в `123`-ричной системе, достаточно перебирать `x` от `0` до `97`.

**Код решения**

```python
def to_dec(digits, base):
    s = 0

    for i in range(len(digits)):
        s += digits[-1 - i] * base**i

    return s


for x in range(98):
    v = to_dec([1, 2, 4, x, 5], 98) + to_dec([1, x, 9, 8], 123)

    if v % 123 == 0:
        print(v // 123)
        break
```

**Разбор решения**

Число `124x5(98)` хранится как список `[1, 2, 4, x, 5]`, а число `1x98(123)` — как `[1, x, 9, 8]`. В таком виде каждая цифра уже является числом, поэтому не нужно отдельно придумывать обозначения для цифр больше `35`.

Функция `to_dec` идёт по цифрам справа налево и считает сумму:

```text
цифра * основание^номер_разряда
```

В этой задаче главное отличие от предыдущего прототипа — сам способ перевода в десятичную систему. Логика подбора остаётся той же: перебираем `x`, считаем значение выражения, проверяем кратность и выводим частное.

**Ответ**

```text
792604
```

## Прототип 3. Неизвестное основание системы счисления

**Текст задания**

Определите число `N`, для которого выполняется равенство:

$110_{(N)} = 39800_{(10)}$

**Идея решения**

Число `110(N)` удобно сразу расписать по формуле разрядов:

$1 \cdot N^2 + 1 \cdot N + 0$

Получаем уравнение:

$N^2 + N = 39800$

Такой тип задач можно решать и аналитически, и перебором. В конспекте полезно видеть программный шаблон, потому что он переносится и на более сложные случаи.

На реальном ЕГЭ такой прототип пока не встречался, но как возможное усложнение темы его полезно держать в голове.

**Код решения**

```python
for n in range(2, 1000):
    if n**2 + n == 39800:
        print(n)
        break
```

**Разбор решения**

Перебор начинается с `2`, потому что основание системы счисления не может быть меньше `2`.

Проверка `n**2 + n == 39800` — это уже не перевод функцией `int`, а запись того же числа `110(N)` через степени основания:

$110_{(N)} = 1 \cdot N^2 + 1 \cdot N + 0$

После нахождения подходящего `N` перебор можно остановить. Здесь получается:

$199^2 + 199 = 39601 + 199 = 39800$

Значит, равенство выполняется при `N = 199`.

**Ответ**

```text
199
```

## Прототип 4. Подстановка с условием "при любом значении"

**Текст задания**

Операнды арифметического выражения записаны в системе счисления с основанием `21`:

```text
12yx9(21) + 36y99(21)
```

В записи чисел переменными `x` и `y` обозначены неизвестные цифры из алфавита `21`-ричной системы счисления. Определите наименьшее значение `x`, при которых значение данного арифметического выражения кратно `18` при любом значении `y`. Для найденного значения `x` вычислите частное от деления значения арифметического выражения на `18` при `y = 5` и укажите его в ответе в десятичной системе счисления.

**Идея решения**

Основание `21` не превышает `36`, значит, оба числа удобно переводить через `int`. Но здесь есть важное отличие от обычной подстановки: нужно найти такое `x`, при котором делимость на `18` выполняется не для одного значения `y`, а для всех допустимых значений.

Поэтому внешний цикл перебирает `x`, а внутренний — все возможные `y`. Если для какого-то `y` делимость нарушается, текущее `x` сразу не подходит.

**Код решения**

```python
for x in range(21):
    ok = True

    for y in range(21):
        v = int(f'12{y}{x}9', 21) + int(f'36{y}99', 21)

        if v % 18 != 0:
            ok = False
            break

    if ok:
        v = int(f'125{x}9', 21) + int(f'36599', 21)
        print(v // 18)
        break
```

**Разбор решения**

Перебор `x` идёт от `0` до `20`, потому что именно такие цифры допустимы в `21`-ричной системе.

Для каждого `x` запускается полный перебор `y`. Переменная `ok` показывает, подходит ли текущее значение `x` для всех проверок сразу:

- если хотя бы при одном `y` выражение не делится на `18`, ставим `ok = False`;
- после этого сразу выходим из внутреннего цикла, потому что дальше проверять это `x` уже не нужно.

Если после полного перебора `y` переменная `ok` осталась истинной, значит, найдено нужное значение `x`. Так как внешний цикл идёт по возрастанию, первое найденное значение и будет наименьшим.

После нахождения такого `x` остаётся подставить `y = 5`, снова вычислить значение выражения и разделить его на `18`.

В этой задаче получается `x = 3`, а при `y = 5` частное равно `47594`.

**Ответ**

```text
47594
```
