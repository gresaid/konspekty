# ТЕОРИЯ

Задания этого типа устроены одинаково: нужно перечислить все слова фиксированной длины из заданного набора букв, расположить их в нужном порядке и либо найти номер слова, либо посчитать количество слов с дополнительным условием.

В основе решения почти всегда лежит полный перебор с помощью `product` из модуля `itertools`.

```python
from itertools import product
```

Если даны буквы `АИМРЯ` и длина слова `4`, то все варианты можно получить так:

```python
for p in product('АИМРЯ', repeat=4):
    s = ''.join(p)
    print(s)
```

`product` возвращает кортежи символов, поэтому их обычно склеивают в строку через `''.join(...)`.

Алфавитный порядок зависит не от условия сам по себе, а от того, в каком порядке буквы переданы в `product`. Если буквы поданы не по алфавиту, то и слова будут сгенерированы не в том порядке, который нужен в задаче.

Часто удобно писать так:

```python
for p in product(sorted(set('МАРИЯ')), repeat=4):
    ...
```

Функция `set(...)` оставляет только уникальные буквы. Это важно в задачах, где в исходном слове какая-то буква встречается несколько раз. Например, в слове `КРАТЕР` буква `Р` повторяется дважды. Если передать строку `КРАТЕР` в `product` без `set`, одинаковые слова будут строиться по нескольку раз, и правильной нумерации уже не получится.

Если все буквы в слове и так разные, как в словах `МАРИЯ`, `АПРЕЛЬ` или `ВЕРОНИКА`, то `set` ничего не меняет по смыслу. Его можно оставить как универсальный приём, а можно не использовать вовсе.

Но здесь есть два важных замечания.

Первое: если в исходном слове есть повторяющиеся буквы, их нельзя передавать в `product` по нескольку раз. Иначе одинаковые слова будут порождаться несколько раз, а нумерация собьётся. Поэтому при необходимости сначала оставляют только уникальные буквы.

Второе: с русской буквой `Ё` нужно быть осторожным. `sorted` упорядочивает символы по кодам, и для `Ё` это не всегда совпадает со школьным алфавитным порядком. Если в наборе есть `Ё`, порядок букв лучше задавать вручную.

Когда слова нужно пронумеровать, обычно вводят счётчик:

```python
num = 0
for p in product(sorted(set(word)), repeat=n):
    s = ''.join(p)
    num += 1
```

Если по условию в список попадают не все слова, а только слова с некоторым свойством, то увеличивать номер надо только для подходящих слов. Например, если буква `В` должна входить ровно один раз, то слова без этого свойства вообще не получают номера.

```python
num = 0
for p in product(sorted(set(word)), repeat=3):
    s = ''.join(p)
    if s.count('В') == 1:
        num += 1
```

Проверки в таких задачах обычно простые:

- `s.count('Е') <= 1` означает, что буква `Е` встречается не более одного раза;
- `'Л' not in s` означает, что буквы `Л` в слове нет;
- `'А' not in s` означает, что буква `А` отсутствует;
- `s[-1] == 'Ь'` проверяет последнюю букву;
- `s[i] != s[i + 1]` проверяет, что соседние буквы не совпадают.

Если слова записываются в обратном алфавитном порядке, буквы нужно передать в `product` в обратном порядке:

```python
for p in product(sorted(set('АПРЕЛЬ'), reverse=True), repeat=5):
    ...
```

Тогда перебор сразу пойдёт в нужной последовательности, и дополнительный разворот списка не понадобится.

Во многих задачах полезно завершать перебор раньше. Если слова уже идут в правильном порядке и найдено первое подходящее слово, можно сделать `break`. Это не меняет ответ, но избавляет от лишних проверок.

## Прототип 1. Позиция слова в алфавитном списке

**Текст задания**

Маша выписывает в алфавитном порядке буквенные комбинации длиной 4, составленные из букв `М, А, Р, И, Я`. На какой позиции от начала списка будет комбинация `АРИЯ`?

Начало списка:

1. `АААА`
2. `АААИ`
3. `АААМ`
4. `АААР`
5. `АААЯ`
6. `ААИА`

**Идея решения**

Нужно сгенерировать все слова длины `4` из данных букв в алфавитном порядке, пронумеровать их и вывести номер слова `АРИЯ`.

**Код решения**

```python
from itertools import product

num = 0

for p in product(sorted('МАРИЯ'), repeat=4):
    s = ''.join(p)
    num += 1
    if s == 'АРИЯ':
        print(num)
        break
```

**Подробный разбор**

В `product` сразу передаётся `sorted('МАРИЯ')`. После сортировки получается список букв в порядке `АИМРЯ`. Именно в таком порядке буквы должны попасть в перебор, чтобы нумерация совпала с условием.

Цикл перебирает все четырёхбуквенные слова. На каждой итерации `p` — это кортеж из четырёх букв, а `s` — уже готовая строка.

Переменная `num` играет роль номера слова в списке. Она увеличивается на `1` для каждого слова, потому что в этой задаче нумеруются все слова без исключений.

Когда текущая строка стала равна `АРИЯ`, можно сразу вывести номер и завершить цикл. Более раннего вхождения быть не может, потому что каждое слово встречается в списке ровно один раз.

**Ответ**

`85`

## Прототип 2. Первое слово с ограничением на буквы

**Текст задания**

Все пятибуквенные слова, в составе которых могут быть только русские буквы `С, О, Л, Н, Ц, Е`, записаны в алфавитном порядке и пронумерованы начиная с `1`.

Начало списка:

1. `ЕЕЕЕЕ`
2. `ЕЕЕЕЛ`
3. `ЕЕЕЕН`
4. `ЕЕЕЕО`
5. `ЕЕЕЕС`
6. `ЕЕЕЕЦ`
7. `ЕЕЕЛЕ`

Под каким номером в списке идёт первое слово, которое содержит не более одной буквы `Е` и не содержит букв `Л`?

**Идея решения**

Нужно перебирать слова в алфавитном порядке, нумеровать их и искать первое слово, которое одновременно удовлетворяет двум условиям:

- `Е` встречается не более одного раза;
- буквы `Л` нет совсем.

Как только найдено первое подходящее слово, перебор можно остановить.

**Первая оптимизация**

Здесь полезен `break`. Слова уже идут в правильном порядке, значит первое найденное подходящее слово автоматически имеет минимальный номер.

Например, если сначала встретились слова `ЕЕССС`, `ЕСССС`, `ННННН`, то после проверки `ННННН` можно сразу закончить работу: дальше номера будут только больше.

**Код решения**

```python
from itertools import product

num = 0

for p in product(sorted('СОЛНЦЕ'), repeat=5):
    s = ''.join(p)
    num += 1
    if s.count('Е') <= 1 and 'Л' not in s:
        print(num)
        break
```

**Подробный разбор**

После сортировки буквы идут как `ЕЛНОСЦ`. Поэтому первое слово в переборе действительно `ЕЕЕЕЕ`, как и в условии.

Переменная `num` увеличивается для каждого слова, потому что в список попадают все возможные слова длины `5`.

Проверка `s.count('Е') <= 1` считает число букв `Е` в слове. Проверка `'Л' not in s` убеждается, что буква `Л` не встречается ни разу.

Обе проверки объединены через `and`, потому что слово должно удовлетворять сразу двум условиям.

Когда условие выполнилось впервые, выводим текущий номер и останавливаем цикл.

**Ответ**

`519`

## Прототип 3. Подсчёт слов после заданной позиции

**Текст задания**

Петя составляет четырёхбуквенные слова из букв слова `СТЕПУХА` и записывает их в алфавитном порядке в список.

Начало списка:

1. `АААА`
2. `АААЕ`
3. `АААП`
4. `АААС`
5. `АААТ`
6. `АААУ`
7. `АААХ`
8. `ААЕА`

Сколько существует слов, стоящих на позициях с номером больше `1000`, в которых нет двух одинаковых подряд идущих букв?

**Идея решения**

Нужно перебрать все четырёхбуквенные слова, для каждого знать его номер и дополнительно проверить два условия:

- номер больше `1000`;
- ни одна пара соседних букв не совпадает.

Если оба условия выполнены, увеличиваем счётчик ответа.

**Код решения**

```python
from itertools import product

num = 0
count_words = 0

for p in product(sorted('СТЕПУХА'), repeat=4):
    s = ''.join(p)
    num += 1
    if num > 1000 and s[0] != s[1] and s[1] != s[2] and s[2] != s[3]:
        count_words += 1

print(count_words)
```

**Подробный разбор**

После сортировки буквы идут как `АЕПСТУХ`, поэтому начало списка совпадает с условием.

`num` хранит текущий номер слова, а `count_words` — количество слов, удовлетворяющих условию.

Проверка на соседние одинаковые буквы записана явно:

- `s[0] != s[1]`;
- `s[1] != s[2]`;
- `s[2] != s[3]`.

Если хотя бы одна из этих проверок ложна, значит где-то есть одинаковые соседние буквы, и слово не подходит.

Сначала проверяется ограничение по номеру `num > 1000`, затем условие на соседние символы. Для подходящих слов счётчик увеличивается на `1`.

**Ответ**

`883`

## Прототип 4. Сколько слов стоит между двумя словами

**Текст задания**

Все шестибуквенные слова, составленные из букв слова `КРАТЕР`, записаны в алфавитном порядке и пронумерованы начиная с `1`. Буквы могут входить в слово много раз или не входить вовсе. Сколько слов будет расположено между словами `КАРЕТА` и `РАКЕТА`?

**Идея решения**

Нужно найти номера двух заданных слов, а затем вычислить, сколько слов стоит строго между ними.

Главная тонкость задачи в том, что в слове `КРАТЕР` буква `Р` встречается два раза. Передавать обе `Р` в `product` нельзя, потому что одинаковые слова начнут появляться по нескольку раз. Нужно оставить только уникальные буквы.

**Код решения**

```python
from itertools import product

num = 0
num1 = 0
num2 = 0

for p in product(sorted(set('КРАТЕР')), repeat=6):
    s = ''.join(p)
    num += 1
    if s == 'КАРЕТА':
        num1 = num
    if s == 'РАКЕТА':
        num2 = num

print(num2 - num1 - 1)
```

**Подробный разбор**

После применения `set` из слова `КРАТЕР` остаются уникальные буквы `К, Р, А, Т, Е`. После сортировки получается алфавитный набор `АЕКРТ`.

Если не убрать повторяющуюся `Р`, то одно и то же слово будет получаться несколько раз, а нумерация перестанет соответствовать условию. В таких задачах `product` уже сам разрешает использовать каждую букву сколько угодно раз, поэтому дублировать буквы в исходном наборе не нужно.

Переменная `num` хранит текущий номер слова. Когда встречается `КАРЕТА`, её номер записывается в `num1`. Когда встречается `РАКЕТА`, её номер записывается в `num2`.

Если между словами с номерами `a` и `b` нужно посчитать количество слов строго между ними, используется формула `b - a - 1`.

**Ответ**

`2999`

## Прототип 5. Обратный алфавитный порядок

**Текст задания**

Катя составляет пятибуквенные слова из букв слова `АПРЕЛЬ` и упорядочивает их в обратном алфавитном порядке.

Начало списка:

1. `ЬЬЬЬЬ`
2. `ЬЬЬЬР`
3. `ЬЬЬЬП`
4. `ЬЬЬЬЛ`
5. `ЬЬЬЬЕ`
6. `ЬЬЬЬА`
7. `ЬЬЬРЬ`

Сколько слов, оканчивающихся на `Ь`, запишет Катя, если заполнит список до `387` позиции включительно?

**Идея решения**

Нужно сразу генерировать слова в обратном алфавитном порядке, нумеровать их и считать те слова из первых `387`, у которых последняя буква равна `Ь`.

**Код решения**

```python
from itertools import product

num = 0
count_words = 0

for p in product(sorted('АПРЕЛЬ', reverse=True), repeat=5):
    s = ''.join(p)
    num += 1
    if num <= 387 and s[-1] == 'Ь':
        count_words += 1

print(count_words)
```

**Подробный разбор**

Поскольку нужен обратный алфавитный порядок, буквы сразу сортируются с параметром `reverse=True`. Благодаря этому первое слово в переборе будет максимальным по алфавиту, то есть `ЬЬЬЬЬ`.

`num` хранит номер текущего слова, а `count_words` подсчитывает подходящие слова.

Проверка `num <= 387` оставляет только первые `387` слов списка. Проверка `s[-1] == 'Ь'` смотрит на последнюю букву слова.

Если обе проверки истинны, счётчик увеличивается.

**Ответ**

`65`

## Прототип 6. Нумеруются только слова с ровно одной буквой

**Текст задания**

Вероника составляет трёхбуквенные коды из букв `В, Е, Р, О, Н, И, К, А`, причём буква `В` должна входить в код ровно один раз. Все полученные коды Вероника записала в алфавитном порядке и пронумеровала.

Начало списка:

1. `ААВ`
2. `АВА`
3. `АВЕ`

На каком месте будет записан первый код, не содержащий ни одной буквы `А`?

**Идея решения**

Здесь нумеруются не все трёхбуквенные слова подряд, а только те, где буква `В` встречается ровно один раз. Значит, увеличивать номер нужно не на каждой итерации, а только после такой проверки.

После этого среди уже пронумерованных слов нужно найти первое слово без буквы `А`.

**Первая оптимизация**

Сразу после нахождения первого подходящего слова нужно сделать `break`.

Например, если в правильном порядке уже встретилось слово `ВЕЕ`, то дальше могут быть только слова с тем же или большим номером. Значит, более раннего ответа уже не появится.

**Код решения**

```python
from itertools import product

num = 0

for p in product(sorted('ВЕРОНИКА'), repeat=3):
    s = ''.join(p)
    if s.count('В') == 1:
        num += 1
        if 'А' not in s:
            print(num)
            break
```

**Подробный разбор**

После сортировки буквы идут как `АВЕИКНОР`. Поэтому перебор начинается с самых ранних по алфавиту слов.

Проверка `s.count('В') == 1` отделяет слова, которые вообще попадают в список. Если в слове нет буквы `В` или буква `В` встречается дважды или трижды, такое слово не нумеруется.

Именно поэтому нельзя делать `num += 1` до проверки. Иначе номер получили бы и лишние слова, которых в реальном списке нет.

Когда найдено слово из списка, дополнительно проверяется условие `'А' not in s`. Это означает, что буква `А` в слове отсутствует.

Первым таким словом оказывается `ВЕЕ`. В этот момент `num` уже равен правильному номеру этого слова в списке.

**Ответ**

`23`
