## 4. Перестановки без повторений
Если все символы различны и каждый используется ровно один раз, то это перестановка.

Пример:

```text
ABC
ACB
BAC
BCA
CAB
CBA
```

Количество перестановок считается по формуле:

```text
n!
```

Например:

```text
3! = 1 * 2 * 3 = 6
```

В Python для таких задач чаще всего используют:

```python
from itertools import permutations
```

---

## 5. Размещения без повторений
Если из алфавита длины `n` нужно составить слова длины `k`, причём символы не повторяются, то это размещения без повторений.

В Python:

```python
from itertools import permutations
```

Потому что `permutations(alphabet, k)` как раз строит все варианты длины `k` без повторений.

---

## 6. Размещения с повторениями
Если буквы или цифры могут повторяться, то это размещения с повторениями.

В Python:

```python
from itertools import product
```

Например:

```python
product('ТОК', repeat=6)
```

построит все слова длины 6 из букв `Т`, `О`, `К`, если каждая буква может встречаться сколько угодно раз.

---

## 7. Главное правило выбора между `product` и `permutations`

### Если повторения разрешены
Используем:

```python
product(...)
```

### Если повторения запрещены
Используем:

```python
permutations(...)
```

---

## 8. Важный момент про повторяющиеся буквы
Если в слове есть повторяющиеся буквы, например в слове `ВОРОТА`, то в `itertools` их нельзя передавать как есть, если вы хотите считать разные слова, а не перестановки позиций.

Почему это важно:
- `itertools` воспринимает одинаковые буквы на разных местах как разные объекты;
- из-за этого при прямом переборе появляются дубликаты.

Поэтому в задачах с повторяющимися буквами нужно:
- либо убирать дубликаты через `set`;
- либо использовать отдельную логику подсчёта;
- либо после перебора преобразовывать результат в множество.

Пример:

```python
set(permutations('ВОРОТА'))
```

## 9. Как работать со словами
Обычно слово собирают так:

```python
''.join(x)
```

где `x` — кортеж из `itertools`.

Пример:

```python
for x in product('ТОК', repeat=6):
    word = ''.join(x)
```

## 10. Как работать с числами
Если задача про числа, то часто удобнее сразу собирать строку:

```python
num = ''.join(x)
```

а потом проверять её как строку:
- первая цифра;
- последняя цифра;
- наличие соседних одинаковых цифр;
- количество цифр.

Иногда можно переводить в число:

```python
int(num, 16)
```

Но чаще в задании 8 это не нужно. Обычно достаточно анализа строки.

---

## 11. Главное правило для чисел
Числа никогда не начинаются с нуля.

Значит, если задача про числа, обязательно отдельно проверяем:

```python
num[0] != '0'
```

или сразу ограничиваем первый символ при построении.

## 12. Алфавитный порядок
В задачах на номер слова или на диапазон слова выписываются в алфавитном порядке.

В Python можно отсортировать символы так:

```python
sorted('МАРИЯ')
```

или:

```python
alphabet = ''.join(sorted('МАРИЯ'))
```

Но есть важный нюанс:
- нужно брать все буквы ровно такие, как даны в условии;
- нельзя заменять алфавит на “свой удобный”;
- буква `Ё` сортируется нестандартно, поэтому с ней нужно быть особенно внимательным.

---

## 13. Как находить номер слова
Есть два основных способа:

### 1. Полный перебор
Строим все слова в правильном порядке и считаем номера:

```python
for i, x in enumerate(product(alphabet, repeat=4), start=1):
    word = ''.join(x)
```

### 2. Отбор по условию
Перебираем все слова и ищем нужное:

```python
if word == 'АРИЯ':
    print(i)
```

---

## 14. Как находить количество слов после некоторой позиции
Если слова уже нумеруются при переборе, можно просто проверять:

```python
if i > 1000:
    ...
```

То есть сначала идёт номер, а потом проверка самого слова.

---

## 15. Полезные функции и приёмы

### Подсчёт количества букв
```python
word.count('К') == 2
```

### Проверка начала слова
```python
not word.startswith('Й')
```

### Проверка подстроки
```python
'ИА' not in word
```

### Проверка соседних одинаковых символов
```python
all(word[i] != word[i + 1] for i in range(len(word) - 1))
```

### Проверка чередования
Обычно проверяют каждую соседнюю пару отдельно:

```python
for i in range(len(word) - 1):
    ...
```

## 4. Буквы. Перестановки с повторяющимися буквами

```python
from itertools import permutations

vowels = 'ОА'
count = 0

for x in set(permutations('ВОРОТА')):

print(count)
```

### Что здесь происходит
- В слове `ВОРОТА` есть повторяющиеся буквы `О` и `Р`.
- Поэтому обычный `permutations` даст дубликаты.
- Чтобы убрать повторы, используем `set(...)`.
- Затем проверяем, чтобы рядом не стояли две гласные.
- Если среди соседних символов не встретились две гласные подряд, слово подходит.

### Ответ из презентации
```python
72
```

## 5. Буквы. Чередование гласных и согласных

### Текст задания

### Код
```python
from itertools import permutations

vowels = 'ОУА'
consonants = 'КБР'
count = 0

for x in permutations('КОБУРА'):

    ok = True
    for i in range(len(word) - 1):
        if (word[i] in vowels and word[i + 1] in vowels) or (word[i] in consonants and word[i + 1] in consonants):
            ok = False
            break
    if ok:
        count += 1

print(count)
```

### Что здесь происходит
- Все буквы различны, поэтому используем `permutations`.
- У слова есть гласные `О`, `У`, `А` и согласные `К`, `Б`, `Р`.
- Чередование означает, что рядом не должны стоять:
  - две гласные;
  - две согласные.
- Проверяем каждую соседнюю пару.

### Ответ из презентации
```python
72
```

## 6. Буквы. Мягкий знак

### Код
```python
from itertools import permutations

consonants = 'ПЛСН'
count = 0

for x in permutations('АПЕЛЬСИН', 7):
    word = ''.join(x)
    if 'Ь' in word:
        i = word.index('Ь')
        if 0 < i < len(word) - 1 and word[i - 1] in consonants and word[i + 1] in consonants:
            count += 1
    else:
        count += 1

print(count)
```

### Что здесь происходит
- Используем `permutations(..., 7)`, потому что слово длины 7, а исходных букв 8.
- Все буквы различны, повторений нет.
- Если мягкий знак попал в слово, проверяем:
  - он не первый;
  - он не последний;
  - слева и справа от него стоят согласные.
- Если мягкого знака нет, слово тоже может подходить.

### Ответ из презентации
```python
12240
```

## 13. Упорядоченный перебор. Последнее слово с чётным номером

### Текст задания
Все пятибуквенные слова, составленные из букв `С`, `Т`, `Р`, `О`, `К`, `А`, записаны в алфавитном порядке и пронумерованы. Определите, под каким номером в этом списке стоит последнее слово с чётным номером, которое не начинается с букв `А`, `С` или `Т` и при этом содержит ровно две буквы `О`.

### Код
```python
from itertools import product

alphabet = ''.join(sorted('СТРОКА'))
answer = 0

for i, x in enumerate(product(alphabet, repeat=5), start=1):
    word = ''.join(x)
    if i % 2 == 0 and word[0] not in 'АСТ' and word.count('О') == 2:
        answer = i

print(answer)
```

### Что здесь происходит
- Перебираем все слова в алфавитном порядке.
- Проверяем:
  - номер слова чётный;
  - слово не начинается на `А`, `С`, `Т`;
  - в слове ровно две буквы `О`.
- Нужно последнее подходящее слово, поэтому не делаем `break`, а просто каждый раз обновляем ответ.

### Ответ из презентации
```python
5058
```

## 14. Упорядоченный перебор. Диапазон между словами

### Текст задания
Все шестибуквенные слова, в составе которых могут быть только русские буквы `Н`, `О`, `Р`, `М`, `А`, `Л`, `Ь`, `Е`, записаны в алфавитном порядке и пронумерованы начиная с 1. Определите, сколько слов находится между первым словом, начинающимся на `НОРМ`, и словом `НЕНОРМ` (не включая эти слова).

### Код
```python
from itertools import product

alphabet = ''.join(sorted('НОРМАЛЬЕ'))
first_pos = 0
second_pos = 0

for i, x in enumerate(product(alphabet, repeat=6), start=1):
    word = ''.join(x)
    if first_pos == 0 and word.startswith('НОРМ'):
        first_pos = i
    if word == 'НЕНОРМ':
        second_pos = i
        break

print(second_pos - first_pos - 1)
```

### Что здесь происходит
- Перебираем все слова длины 6 в алфавитном порядке.
- Ищем:
  - первое слово, начинающееся на `НОРМ`;
  - слово `НЕНОРМ`.
- После этого считаем, сколько слов между ними:

```python
second_pos - first_pos - 1
```

### Почему вычитаем 1
Потому что границы диапазона не включаются.

## 15. Типичные ошибки
- Использовать `permutations`, когда по условию буквы могут повторяться.
- Использовать `product`, когда буквы не должны повторяться.
- Забывать, что числа не могут начинаться с нуля.
- Брать не тот алфавитический порядок букв.
- Забывать, что в задачах на номер важна нумерация с 1.
- Не убирать дубликаты, если в слове есть повторяющиеся буквы.
- Проверять только количество букв, но забывать про ограничения на начало, конец или соседние символы.
- Останавливаться слишком рано, если нужно найти не первое, а последнее подходящее слово.

---

## 16. Что запомнить
- `product` — если повторения разрешены.
- `permutations` — если повторения запрещены.
- Повторяющиеся буквы в исходном слове требуют особой обработки.
- Для чисел всегда отдельно проверяем первый символ.
- Для упорядоченного перебора важно правильно отсортировать алфавит.
- Если нужно найти первое слово, после нахождения можно делать `break`.
- Если нужно найти последнее слово, `break` делать нельзя.
