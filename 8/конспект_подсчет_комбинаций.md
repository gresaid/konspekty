# ТЕОРИЯ

Задачи на подсчёт комбинаций в восьмом задании обычно решаются полным перебором всех допустимых слов или чисел с последующей проверкой условия.

Чаще всего используются две функции из модуля `itertools`:

```python
from itertools import product, permutations
```

`product` применяют, когда символы могут повторяться. Если из букв `ТОК` нужно составить слова длины `6`, каждая позиция выбирается независимо, поэтому используется именно `product`.

```python
for p in product('ТОК', repeat=6):
    s = ''.join(p)
```

`permutations` применяют, когда каждый символ нужно использовать не более одного раза. Если составляется код перестановкой букв, то повторов быть не должно.

```python
for p in permutations('КАЛИЙ', r=5):
    s = ''.join(p)
```

`p` — это кортеж символов. Чтобы получить готовое слово или число, его обычно склеивают в строку с помощью `''.join(p)`. После этого уже удобно проверять количество букв, наличие подстрок и соседние символы.

В задачах на слова и коды важно заранее понять, можно ли повторять буквы:

- если в условии сказано, что буква может встречаться несколько раз, нужен `product`;
- если код составляется перестановкой букв, нужен `permutations`;
- если в исходном слове есть одинаковые буквы, например в слове `ВОРОТА`, то при использовании `permutations` одинаковые перестановки будут получаться несколько раз, поэтому результат нужно очищать от дублей или считать более аккуратно.

Обычно решение строится по одному и тому же шаблону:

1. сгенерировать все варианты;
2. собрать их в строку;
3. проверить условие;
4. если вариант подходит, увеличить счётчик.

Базовый шаблон выглядит так:

```python
count = 0

for p in product('ABC', repeat=4):
    s = ''.join(p)
    if ...:
        count += 1

print(count)
```

Если задача про числа, нужно помнить, что запись числа не может начинаться с `0`. Это условие почти всегда проверяется отдельно:

```python
if s[0] != '0':
```

или, если перебор идёт числами:

```python
if x[0] != 0:
```

Если в задаче нужна строка цифр некоторой системы счисления, её можно записать прямо руками, например `0123456789ABCDEF` для шестнадцатеричной системы. Как альтернативный приём можно использовать:

```python
from string import printable
```

Тогда нужный набор символов можно брать срезом до нужного основания. Например, для шестнадцатеричной системы это может быть срез первых `16` подходящих символов. В этом конспекте основные наборы цифр записаны явно: так проще сразу видеть, какие символы участвуют в переборе.

Часто встречаются такие проверки:

- `s.count('К') == 2` — буква `К` встречается ровно два раза;
- `s.count('7') == 1` — цифра `7` встречается ровно один раз;
- `'ИА' not in s` — в строке нет подстроки `ИА`;
- `s[0] in 'ТК'` — первая буква согласная;
- `all(s[i] != s[i + 1] for i in range(len(s) - 1))` — соседние символы не совпадают.

Если нужно проверить соседние пары, удобно использовать `all`. Тогда условие читается просто: для всех соседних позиций символы должны отличаться или должны иметь разные свойства.

```python
all(s[i] != s[i + 1] for i in range(len(s) - 1))
```

Иногда условие проще проверять не напрямую, а после замены символов. Например, если нужно запретить соседство двух чётных или двух нечётных цифр, можно заменить все чётные цифры на один символ, а все нечётные — на другой, а затем проверить отсутствие подстрок `AA` и `FF`.

Такой приём сокращает длинные проверки, но здесь важно не потерять исходную информацию. Если среди заменяемых символов есть `0`, то проверку на первую цифру числа нужно делать до замен или по исходному кортежу, иначе после `replace` уже нельзя понять, был ли на первом месте именно ноль.

Во многих задачах полезно отделять наивный перебор от более удобной записи.

Наивный вариант может использовать вложенные циклы:

```python
count = 0

for l1 in 'ТК':
    for l2 in 'ТОК':
        for l3 in 'ТОК':
            for l4 in 'ТОК':
                for l5 in 'ТОК':
                    for l6 in 'ТОК':
                        s = l1 + l2 + l3 + l4 + l5 + l6
                        count += 1
```

Такой код работает, но плохо масштабируется. Если длина слова меняется, весь набор циклов приходится переписывать. Поэтому в большинстве задач лучше сразу использовать `product` или `permutations`.

В каждой задаче важно отдельно понимать:

- что именно перебирается: буквы, цифры, кортежи чисел;
- допускаются ли повторы;
- как проверяется первое место;
- как проверяется количество нужных символов;
- как проверяется запрет на подстроки и соседние элементы.


# РАЗБОР ПРОТОТИПОВ

## Прототип 1. Слова из букв Т, О, К

**Текст задания**

Сколько слов длины `6`, начинающихся с согласной буквы, можно составить из букв `Т`, `О`, `К`? Каждая буква может входить в слово несколько раз.

**Идея решения**

Поскольку каждая буква может повторяться, нужно перебрать все слова длины `6`. На первой позиции должна стоять согласная буква, значит первая буква выбирается из `ТК`, а остальные пять позиций — из `ТОК`.

**Неоптимизированный код**

```python
count = 0

for l1 in 'ТК':
    for l2 in 'ТОК':
        for l3 in 'ТОК':
            for l4 in 'ТОК':
                for l5 in 'ТОК':
                    for l6 in 'ТОК':
                        s = l1 + l2 + l3 + l4 + l5 + l6
                        count += 1

print(count)
```

**Почему такой код медленный**

В этой задаче такой код ещё работает быстро, но запись получается громоздкой. Если длина слова изменится, придётся вручную добавлять или убирать циклы. В таком коде легко ошибиться в одной из позиций.

**Первая оптимизация**

Вместо шести вложенных циклов можно использовать `product`. Он сам перебирает все комбинации заданной длины.

```python
from itertools import product

count = 0

for p in product('ТОК', repeat=6):
    s = ''.join(p)
    if s[0] in 'ТК':
        count += 1

print(count)
```

**Вторая оптимизация**

Ещё удобнее сразу ограничить первую позицию. Тогда внутри цикла не понадобится отдельная проверка на согласную.

Например, если первая буква фиксируется из строки `ТК`, то слова на `О` даже не генерируются. Значит, мы не тратим время на лишние варианты.

**Код решения**

```python
count = 0

for l1 in 'ТК':
    for l2 in 'ТОК':
        for l3 in 'ТОК':
            for l4 in 'ТОК':
                for l5 in 'ТОК':
                    for l6 in 'ТОК':
                        s = l1 + l2 + l3 + l4 + l5 + l6
                        count += 1

print(count)
```

**Подробный разбор**

`count` хранит количество подходящих слов. Переменные `l1`, `l2`, `l3`, `l4`, `l5`, `l6` — буквы на первой, второй, третьей, четвёртой, пятой и шестой позициях.

Первый цикл идёт по строке `ТК`, потому что на первой позиции нужна только согласная. Остальные циклы идут по строке `ТОК`, потому что дальше ограничений нет.

Строка `s` собирается сложением шести символов. В этой задаче дополнительная проверка уже не нужна: каждое сгенерированное слово автоматически подходит под условие. Поэтому счётчик просто увеличивается на `1` для каждого варианта.

**Ответ**

`486`

## Прототип 2. Ровно две буквы К

**Текст задания**

Вася составляет `6`-буквенные слова, в которых есть только буквы `К`, `А`, `Н`, `Т`, причём буква `К` используется в каждом слове ровно `2` раза. Каждая из других букв может встречаться любое количество раз или не встречаться совсем.

**Идея решения**

Здесь разрешены повторы, значит нужен `product`. После генерации слова нужно проверить, что буква `К` встречается ровно два раза.

**Код решения**

```python
from itertools import product

count = 0

for p in product('КАНТ', repeat=6):
    s = ''.join(p)
    if s.count('К') == 2:
        count += 1

print(count)
```

**Подробный разбор**

`product('КАНТ', repeat=6)` перебирает все слова длины `6` из четырёх букв. `p` — кортеж из шести символов, `s` — готовая строка.

Проверка `s.count('К') == 2` считает, сколько раз в слове встретилась буква `К`. Если ровно два раза, слово подходит.

Переменная `count` увеличивается только для подходящих слов. В конце в ней остаётся итоговое количество.

**Ответ**

`1215`

## Прототип 3. Перестановка букв слова КАЛИЙ

**Текст задания**

Вася составляет `5`-буквенные коды из букв `К`, `А`, `Л`, `И`, `Й`. Каждую букву нужно использовать ровно `1` раз, при этом код не может начинаться с буквы `И` и не может содержать сочетания `ИА`.

**Идея решения**

Каждая буква используется ровно один раз, поэтому нужен `permutations`. После этого остаётся проверить два ограничения: первая буква не `И` и в коде нет подстроки `ИА`.

**Код решения**

```python
from itertools import permutations

count = 0

for p in permutations('КАЛИЙ', r=5):
    s = ''.join(p)
    if s[0] != 'И' and 'ИА' not in s:
        count += 1

print(count)
```

**Подробный разбор**

`permutations('КАЛИЙ', r=5)` строит все перестановки длины `5` из данных букв. Поскольку в наборе `5` разных букв и длина тоже `5`, каждая перестановка использует все буквы ровно по одному разу.

`s[0] != 'И'` проверяет первую букву кода. Условие `'ИА' not in s` запрещает соседнюю пару букв `И` и `А` именно в таком порядке.

Если выполнены оба условия, код засчитывается, и переменная `count` увеличивается на `1`.

**Ответ**

`78`

## Прототип 4. Перестановки букв слова ВОРОТА

**Текст задания**

Артур составляет `6`-буквенные коды перестановкой букв слова `ВОРОТА`. Нельзя ставить рядом две гласные.

**Идея решения**

Слово `ВОРОТА` содержит повторяющуюся букву `О`, поэтому при обычном `permutations` одинаковые перестановки будут возникать несколько раз. Нужно оставить только уникальные коды и для каждого проверить, что рядом не стоят две гласные.

**Код решения**

```python
from itertools import permutations

count = 0

for p in set(permutations('ВОРОТА', 6)):
    s = ''.join(p)
    if 'ОО' not in s and 'ОА' not in s and 'АО' not in s:
        count += 1

print(count)
```

**Подробный разбор**

У этой задачи есть важная особенность: в слове `ВОРОТА` буква `О` встречается два раза. Для человека эти две буквы неразличимы: если в слове на втором и пятом месте стоят `О`, то нам неважно, какая именно `О` туда попала. Это одна и та же буква.

Но `permutations('ВОРОТА', 6)` работает не так, как человек. Для Python строка — это последовательность из шести позиций:

- `В`
- первая `О`
- `Р`
- вторая `О`
- `Т`
- `А`

Хотя визуально обе буквы одинаковые, в исходной строке они стоят на разных местах. Поэтому при перестановках Python фактически меняет местами не просто буквы, а элементы с разными исходными позициями.

Из-за этого возникают дубли. Например, строка `ВОРОТА` может получиться двумя способами:

- на второе место взяли первую `О`, а на четвёртое место — вторую `О`;
- на второе место взяли вторую `О`, а на четвёртое место — первую `О`.

Для нас результат один и тот же: в обоих случаях получается строка `ВОРОТА`. Но `permutations` считает такие перестановки разными, потому что меняет местами два разных элемента исходной последовательности.

Именно поэтому `set(permutations('ВОРОТА', 6))` здесь нужен поверх `permutations`. Сначала `permutations` строит все перестановки длины `6`, включая повторяющиеся кортежи, которые появились из-за двух одинаковых букв `О`. Затем `set` удаляет одинаковые кортежи и оставляет только уникальные варианты.

Можно увидеть это на маленьком примере. Если взять слово `ТОПОР`, то две буквы `О` тоже одинаковые. Перестановка, где первая `О` стоит раньше второй, и перестановка, где их поменяли местами, дадут одну и ту же строку. Без `set` такая строка была бы посчитана дважды.

После удаления дублей остаётся проверить запрет на соседние гласные. В слове `ВОРОТА` гласные — это `О` и `А`. Значит, нельзя допускать подстроки:

- `ОО`;
- `ОА`;
- `АО`.

Если ни одной из этих подстрок нет, значит рядом нет двух гласных, и код подходит.

После преобразования кортежа в строку остаётся короткая проверка по подстрокам. Если встретилось `ОО`, `ОА` или `АО`, такой код не подходит. Если ни одной из этих подстрок нет, счётчик `count` увеличивается.

**Ответ**

`72`

## Прототип 5. Чередование гласных и согласных

**Текст задания**

Семён составляет слова перестановкой букв слова `КОБУРА`. Гласные и согласные буквы должны чередоваться.

**Идея решения**

Все буквы разные, поэтому нужен `permutations`. После получения перестановки удобно заменить все гласные одной буквой, а все согласные другой. Тогда задача о чередовании сведётся к проверке соседних одинаковых типов.

**Код решения**

```python
from itertools import permutations

count = 0

for p in permutations('КОБУРА'):
    s = ''.join(p)

    for gl in 'ОУА':
        s = s.replace(gl, 'У')
    for sg in 'КБР':
        s = s.replace(sg, 'Б')

    if 'ББ' not in s and 'УУ' not in s:
        count += 1

print(count)
```

**Почему такая проверка работает**

В слове `КОБУРА` гласные — это `О`, `У`, `А`, а согласные — `К`, `Б`, `Р`.

После замен:

- любая гласная превращается в `У`;
- любая согласная превращается в `Б`.

Например:

- `КОБУРА` превратится в `БУБУУУ`, поэтому такое слово не подойдёт;
- `ОКУБАР` превратится в `УБУБУБ`, и здесь символы чередуются правильно.

Если в преобразованной строке есть `ББ`, значит рядом стоят две согласные. Если есть `УУ`, значит рядом стоят две гласные. А если нет ни `ББ`, ни `УУ`, то типы букв обязательно чередуются на всех соседних позициях.

Этот способ удобен тем, что не нужно отдельно проверять два случая: слово начинается с гласной или с согласной. Оба варианта автоматически подходят, если после замен не возникло двух одинаковых соседних символов.

**Подробный разбор**

`permutations('КОБУРА')` перебирает все перестановки шести разных букв. Каждая перестановка даёт одно возможное слово без повторений.

Сначала кортеж `p` склеивается в строку `s`. Затем в двух циклах строка преобразуется:

- буквы `О`, `У`, `А` заменяются на `У`;
- буквы `К`, `Б`, `Р` заменяются на `Б`.

После этого конкретные буквы уже не важны. Остаётся только последовательность типов: гласная или согласная.

Если в полученной строке нет `ББ` и нет `УУ`, значит никакие две соседние буквы не относятся к одному типу. Следовательно, в исходном слове гласные и согласные действительно чередуются.

**Ответ**

`72`

## Прототип 6. Слова из букв К, Р, Ы, Ш, А

**Текст задания**

Лида составляет слова из букв `К`, `Р`, `Ы`, `Ш`, `А`. Каждая гласная буква встречается в слове не более двух раз. Каждая согласная может стоять только на первой позиции либо не встречаться вовсе. Нужно найти количество слов длиной более двух символов.

**Идея решения**

Здесь буквы могут повторяться, значит нужен `product`. Длина слова должна быть больше двух, но не бесконечной: согласные разрешены только в начале, а каждая из двух гласных может встретиться не более двух раз. Поэтому достаточно перебрать длины `3`, `4` и `5`.

**Код решения**

```python
from itertools import product

count = 0

for n in range(3, 6):
    for p in product('КРЫША', repeat=n):
        s = ''.join(p)

        if s.count('Ы') <= 2 and s.count('А') <= 2 and all(ch not in s[1:] for ch in 'КРШ'):
            count += 1

print(count)
```

**Подробный разбор**

Внешний цикл перебирает длину слова: `3`, `4`, `5`. Внутренний цикл строит все слова такой длины.

`s.count('Ы') <= 2` и `s.count('А') <= 2` проверяют ограничение на гласные.

Проверка `all(ch not in s[1:] for ch in 'КРШ')` означает, что каждая согласная из набора `КРШ` отсутствует начиная со второй позиции. Если это верно для всех трёх согласных, то любая согласная может стоять только на первом месте или не встречаться вовсе.

`all` здесь удобно читать как фразу: для всех согласных должно выполняться одно и то же условие. Если хотя бы одна согласная встретится не на первой позиции, выражение станет ложным, и слово не будет засчитано.

**Ответ**

`60`

## Прототип 7. Буква Ь между двумя согласными

**Текст задания**

Ася составляет семибуквенные слова из букв `А`, `П`, `Е`, `Л`, `Ь`, `С`, `И`, `Н`. Все буквы в слове различны. Буква `Ь`, если встречается, стоит между двумя согласными.

**Идея решения**

Все буквы различны, а длина слова равна `7`, значит нужно брать перестановки длины `7` из восьми разных букв. После этого удобно заменить все согласные на одну букву и проверить, что мягкий знак либо не встретился вообще, либо оказался между двумя такими обозначениями согласных.

**Код решения**

```python
from itertools import permutations

count = 0

for p in permutations('АПЕЛЬСИН', r=7):
    s = ''.join(p)
    s = s.replace('П', 'Л').replace('С', 'Л').replace('Н', 'Л')
    if 'Ь' not in s or 'ЛЬЛ' in s:
        count += 1

print(count)
```

**Подробный разбор**

`permutations('АПЕЛЬСИН', r=7)` перебирает все слова длины `7` без повторения букв.

После получения очередного слова выполняются замены:

- `П` заменяется на `Л`;
- `С` заменяется на `Л`;
- `Н` заменяется на `Л`.

Буква `Л` здесь выбрана как условное обозначение согласной. После замен все согласные в этой задаче выглядят одинаково.

Дальше остаются два случая.

Первый случай: мягкого знака в слове нет. Тогда ограничение из условия не нарушается, и слово сразу подходит. Это проверяется условием `'Ь' not in s`.

Второй случай: мягкий знак есть. Тогда он должен стоять между двумя согласными. После замен это означает, что в строке должна встретиться подстрока `ЛЬЛ`. Именно это проверяется условием `'ЛЬЛ' in s`.

Если выполняется хотя бы одно из этих двух условий, слово засчитывается.

**Ответ**

`12240`

## Прототип 8. Пятизначные шестнадцатеричные числа

**Текст задания**

Определите количество пятизначных чисел в шестнадцатеричной системе счисления, которые не оканчиваются чётными цифрами и не начинаются с цифры `1`.

**Идея решения**

Так как цифры могут повторяться, нужно использовать `product`. При этом число не может начинаться с `0`, даже если это не сказано отдельно, потому что тогда запись не была бы пятизначной.

**Код решения**

```python
from itertools import product

count = 0

for p in product('0123456789ABCDEF', repeat=5):
    s = ''.join(p)
    if s[0] != '0' and s[0] != '1' and s[-1] not in '02468ACE':
        count += 1

print(count)
```

**Подробный разбор**

Строка `'0123456789ABCDEF'` задаёт все цифры шестнадцатеричной системы. Проверка `s[0] != '0'` гарантирует, что число действительно пятизначное. Проверка `s[0] != '1'` учитывает условие задачи. Проверка `s[-1] not in '02468ACE'` означает, что последняя цифра не чётная.

Если все три проверки выполнены, число подходит.

**Ответ**

`458752`

## Прототип 9. Семизначные числа в девятеричной системе

**Текст задания**

Определите количество семизначных чисел в девятеричной системе счисления, которые не начинаются с цифр `3` и `7` и не содержат пары соседних одинаковых цифр.

**Идея решения**

Нужен полный перебор всех записей длины `7` в системе с цифрами от `0` до `8`. После этого остаётся проверить три условия:

- первая цифра не `0`;
- первая цифра не `3` и не `7`;
- соседние цифры не совпадают.

**Код решения**

```python
from itertools import product

count = 0

for p in product('012345678', repeat=7):
    s = ''.join(p)
    if s[0] != '0' and s[0] not in '37' and all(s[i] != s[i + 1] for i in range(6)):
        count += 1

print(count)
```

**Подробный разбор**

Первые две проверки относятся к первой цифре числа. Они нужны отдельно, потому что именно первая позиция определяет, является ли запись корректным семизначным числом.

Проверка через `all` проходит по парам соседних символов:

- `s[0]` и `s[1]`;
- `s[1]` и `s[2]`;
- ...
- `s[5]` и `s[6]`.

Если хотя бы одна пара равна, `all` вернёт `False`, и число не будет засчитано.

**Ответ**

`1572864`

## Прототип 10. Трёхзначные шестнадцатеричные числа разной чётности

**Текст задания**

Сколько существует шестнадцатеричных трёхзначных чисел, в которых все цифры различны и никакие две чётные или две нечётные цифры не стоят рядом?

**Идея решения**

Все цифры различны, значит нужен `permutations`. После построения числа удобно заменить все нечётные цифры на один символ, а все чётные — на другой. Тогда условие о чётности соседних цифр сведётся к проверке, что в строке нет `FF` и `AA`.

**Код решения**

```python
from itertools import permutations

count = 0

for p in permutations('0123456789ABCDEF', r=3):
    s = ''.join(p)

    if s[0] == '0':
        continue

    for odd in '13579BDF':
        s = s.replace(odd, 'F')
    for even in '02468ACE':
        s = s.replace(even, 'A')

    if 'FF' not in s and 'AA' not in s:
        count += 1

print(count)
```

**Подробный разбор**

`permutations('0123456789ABCDEF', r=3)` перебирает все трёхсимвольные записи без повторяющихся цифр.

Сначала кортеж `p` превращается в строку `s`. Сразу после этого проверяется `s[0] == '0'`. Это важно сделать до замен, потому что позже ноль уже не удастся отличить от других чётных цифр.

Затем все нечётные цифры `1, 3, 5, 7, 9, B, D, F` заменяются на символ `F`, а все чётные цифры `0, 2, 4, 6, 8, A, C, E` — на символ `A`.

После этого исходные цифры уже не важны: остаётся только запись их чётности.

Например:

- `1A3` превратится в `FAF`, и такое число подходит;
- `18B` превратится в `FFA`, и такое число не подходит, потому что рядом стоят две нечётные цифры;
- `2C4` превратится в `AAA`, и такое число тоже не подходит, потому что рядом стоят две чётные цифры.

Проверка `'FF' not in s` означает, что рядом не стоят две нечётные цифры. Проверка `'AA' not in s` означает, что рядом не стоят две чётные цифры. Если обе проверки истинны, чётность соседних цифр чередуется.

**Ответ**

`840`

## Прототип 11. Шестизначные числа в шестеричной системе

**Текст задания**

Определите количество шестизначных чисел, записанных в шестеричной системе счисления, в записи которых ровно одна цифра `2`, при этом никакая нечётная цифра не стоит рядом с цифрой `2`.

**Идея решения**

Так как цифры могут повторяться, используем `product`. Нужно проверить:

- первая цифра не `0`;
- цифра `2` встречается ровно один раз;
- рядом с `2` нет нечётных цифр.

**Код решения**

```python
from itertools import product

count = 0

for p in product('012345', repeat=6):
    s = ''.join(p)
    if s[0] != '0' and s.count('2') == 1:
        t = s.replace('3', '1').replace('5', '1')
        if '12' not in t and '21' not in t:
            count += 1

print(count)
```

**Подробный разбор**

В шестеричной системе нечётные цифры — это `1`, `3`, `5`. В коде цифры `3` и `5` заменяются на `1`, чтобы все нечётные цифры выглядели одинаково.

После этого достаточно проверить отсутствие подстрок `12` и `21`. Это означает, что рядом с `2` не стоит ни одна нечётная цифра.

Проверка первой цифры выполняется до замен. Здесь это безопасно ещё и потому, что ноль не заменяется, но общий порядок всё равно лучше сохранять именно таким.

**Ответ**

`3700`

## Прототип 12. Пятизначные числа в 12-ричной системе

**Текст задания**

Определите количество `12`-ричных пятизначных чисел, в записи которых ровно одна цифра `7` и не более трёх цифр с числовым значением, превышающим `8`.

**Идея решения**

Удобно перебирать не строки, а числа `0, 1, ..., 11`. Тогда цифры с числовым значением больше `8` — это просто `9`, `10`, `11`.

**Код решения**

```python
from itertools import product

count = 0

for x in product(range(12), repeat=5):
    if x[0] != 0 and x.count(7) == 1:
        big_digits = [d for d in x if d > 8]
        if len(big_digits) <= 3:
            count += 1

print(count)
```

**Подробный разбор**

`product(range(12), repeat=5)` генерирует все записи длины `5`, где каждая цифра — число от `0` до `11`.

`x[0] != 0` проверяет, что запись пятизначная. `x.count(7) == 1` означает, что цифра `7` встретилась ровно один раз.

Список `big_digits` содержит только те цифры, которые больше `8`. Это и есть цифры с числовым значением, превышающим `8`. Если длина списка не больше трёх, число подходит.

Такой способ удобен тем, что не нужно отдельно работать с символами `A` и `B`: в переборе они уже представлены числами `10` и `11`.

**Ответ**

`67476`
