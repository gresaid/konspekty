# ТЕОРИЯ

Задание 9 по структуре очень похоже на задание 17, но здесь данные записаны не по одному числу в строке, а сразу по несколько чисел. Поэтому основная идея остаётся той же: нужно перебрать все строки файла, для каждой строки проверить условие и обновить ответ.

Это задание удобнее решать на Python. Исходные данные часто даны в формате электронной таблицы, поэтому их сначала переводят в обычный текстовый файл. После этого каждая строка файла читается как строка текста и превращается в список чисел.

Базовая заготовка выглядит так:

```python
for s in open('9.txt'):
    a = [int(x) for x in s.split()]
```

Здесь `s` — одна строка файла, а `a` — список чисел из этой строки. Метод `split()` разбивает строку по пробелам, а `int(x)` превращает каждый фрагмент в целое число.

Во многих задачах строку полезно сразу отсортировать:

```python
a.sort()
```

После сортировки:
- `a[0]` — минимальное число;
- `a[-1]` — максимальное число;
- элементы между ними можно удобно брать по индексам.

Сортировка особенно полезна, когда в задаче нужно работать с минимумом, максимумом, средними элементами или быстро отделять крайние значения от остальных.

В 9 задании часто нужно отделить повторяющиеся числа от тех, которые встретились один раз. Для этого удобно использовать такие заготовки:

```python
rpt = [x for x in a if a.count(x) > 1]
nrt = [x for x in a if a.count(x) == 1]
```

`rpt` содержит повторяющиеся числа, а `nrt` — неповторяющиеся. Если число встречается дважды, оно попадёт в `rpt` два раза. Если в строке два разных числа повторяются по два раза, длина `rpt` будет равна `4`.

Если нужно выделить число, которое повторяется ровно два раза, или точнее задать проверку на повторы, можно писать так:

```python
rpt = [x for x in a if a.count(x) == 2]
nrt = [x for x in a if a.count(x) == 1]
```

В задачах этого типа постоянно используются:
- `min(a)` и `max(a)`;
- `sum(a)` для суммы всех чисел;
- `sum(nrt) / len(nrt)` для среднего арифметического;
- проверки вида `a.count(x) == 2`, `a.count(x) == 3`;
- счётчик строк, если нужно найти номер строки.

Если по условию требуется количество строк, обычно заводят счётчик:

```python
k = 0
for s in open('9.txt'):
    a = [int(x) for x in s.split()]
    if ...:
        k += 1
print(k)
```

Если нужен номер строки, вводят отдельный счётчик:

```python
num = 0
for s in open('9.txt'):
    num += 1
    a = [int(x) for x in s.split()]
    if ...:
        print(num)
        break
```

Если просят наименьший номер строки, программу можно завершить сразу после первого подходящего варианта. Если просят наибольший номер строки, перебор не прерывают и каждый раз обновляют ответ.

В задачах на среднее арифметическое лучше по возможности использовать `sum(...)`, а не складывать элементы вручную. Это делает код короче и уменьшает риск ошибки:

```python
sr = sum(nrt) / len(nrt)
```

Главный принцип решения 9 задания такой:
- отдельно обработать каждую строку;
- выделить в ней нужные группы чисел;
- записать условие точно по формулировке задачи;
- обновить ответ в нужном формате: количество, номер строки, сумму чисел и так далее.

## Прототип 1. Сравнение квадратов после сортировки

**Текст задания**

В файле электронной таблицы `9-154.xls` в каждой строке содержатся пять натуральных чисел. Сколько среди них строк, в которых квадрат суммы максимального и минимального чисел в строке больше суммы квадратов трёх оставшихся?

**Идея решения**

В каждой строке нужно найти минимальное и максимальное число, затем отдельно посчитать квадрат их суммы и сумму квадратов трёх остальных чисел. Так как чисел всего пять, строку проще сразу отсортировать: первый элемент станет минимальным, последний — максимальным, а три средних элемента будут остальными числами.

**Код решения**

```python
k = 0

for s in open('9-154.txt'):
    a = [int(x) for x in s.split()]
    a.sort()

    sq1 = (a[0] + a[4]) ** 2
    sq2 = a[1] ** 2 + a[2] ** 2 + a[3] ** 2

    if sq1 > sq2:
        k += 1

print(k)
```

**Подробный разбор**

Цикл перебирает все строки файла. Каждая строка превращается в список из пяти чисел.

После сортировки крайние элементы списка — это минимум и максимум. Поэтому квадрат суммы максимального и минимального чисел записывается как `(a[0] + a[4]) ** 2`.

Три оставшихся числа стоят между ними, поэтому сумма их квадратов вычисляется как `a[1] ** 2 + a[2] ** 2 + a[3] ** 2`.

Если первое выражение больше второго, строка подходит, и счётчик `k` увеличивается на `1`.

**Ответ**

`2585`


## Прототип 2. Две пары с равными суммами

**Текст задания**

В файле электронной таблицы `9-160.xls` в каждой строке содержатся четыре натуральных числа. Определите количество строк таблицы, содержащих числа, для которых выполнены оба условия:

- наибольшее из четырёх чисел меньше суммы трёх других;
- четыре числа можно разбить на две пары чисел с равными суммами.

**Идея решения**

Строку лучше отсортировать. Тогда `a[0]` будет минимальным числом, `a[3]` — максимальным, а `a[1]` и `a[2]` — двумя средними числами.

После сортировки второе условие удобно проверять так: сумма минимального и максимального должна быть равна сумме двух средних чисел. Тогда четыре числа действительно разбиваются на две пары с равными суммами.

**Код решения**

```python
k = 0

for s in open('9-160.txt'):
    a = [int(x) for x in s.split()]
    a.sort()

    if a[3] < a[0] + a[1] + a[2]:
        if a[0] + a[3] == a[1] + a[2]:
            k += 1

print(k)
```

**Подробный разбор**

После сортировки четыре числа стоят по возрастанию. Поэтому:
- `a[0]` — минимум;
- `a[3]` — максимум;
- `a[1]` и `a[2]` — средние элементы.

Первое условие задачи записывается как `a[3] < a[0] + a[1] + a[2]`. Это и есть проверка того, что наибольшее число меньше суммы трёх остальных.

Второе условие после сортировки удобно проверять через равенство

```python
a[0] + a[3] == a[1] + a[2]
```

Если оно выполнено, то числа можно разбить на пары с равными суммами: крайние элементы дадут одну пару, а два средних — вторую.

Например, если после сортировки строка равна `2 4 5 7`, то:
- сумма крайних чисел равна `2 + 7 = 9`;
- сумма средних чисел равна `4 + 5 = 9`.

Значит, второе условие выполнено.

Если выполнены оба условия, счётчик `k` увеличивается на `1`.

**Ответ**

`104`


## Прототип 3. Одно число повторяется трижды

**Текст задания**

В файле электронной таблицы `9-170.xls` в каждой строке содержатся шесть неотрицательных целых чисел. Определите количество строк таблицы, для которых выполнены оба условия:

- в строке только одно число повторяется трижды, остальные числа не повторяются;
- утроенная сумма неповторяющихся чисел строки не больше произведения повторяющихся чисел.

**Идея решения**

Нужно выделить число, которое встречается ровно три раза, и отдельно собрать неповторяющиеся числа. После этого остаётся проверить количество элементов в обеих группах и сравнить нужные выражения.

**Код решения**

```python
k = 0

for s in open('9-170.txt'):
    a = [int(x) for x in s.split()]

    rpt = [x for x in a if a.count(x) == 3]
    nrt = [x for x in a if a.count(x) == 1]

    if len(rpt) == 3 and len(nrt) == 3:
        if 3 * sum(nrt) <= rpt[0] * rpt[1] * rpt[2]:
            k += 1

print(k)
```

**Подробный разбор**

Если одно число повторяется трижды, то список `rpt` будет состоять из трёх одинаковых элементов. Например, для строки `5 5 5 2 7 9` список `rpt` равен `[5, 5, 5]`, а `nrt` равен `[2, 7, 9]`.

Проверка `len(rpt) == 3 and len(nrt) == 3` гарантирует, что в строке действительно одно число встречается ровно три раза, а остальные три числа различны.

Во втором условии нужно сравнить `3 * sum(nrt)` и произведение повторяющихся чисел. Так как все элементы в `rpt` одинаковы, произведение можно считать прямо по списку.

**Ответ**

`134`


## Прототип 4. Разбиение на три пары одинаковых чисел

**Текст задания**

В файле электронной таблицы `9-157.xls` в каждой строке содержатся шесть натуральных чисел. Определите количество строк, в которых числа можно разбить на три пары, состоящие из одинаковых чисел.

**Идея решения**

Если шесть чисел можно разбить на три пары одинаковых, то после сортировки список должен выглядеть так:

```python
a[0] == a[1]
a[2] == a[3]
a[4] == a[5]
```

Дополнительно нужно убедиться, что это именно три разные пары, а не, например, одно число встречается четыре раза.

**Код решения**

```python
k = 0

for s in open('9-157.txt'):
    a = [int(x) for x in s.split()]
    a.sort()

    if a[0] == a[1] and a[2] == a[3] and a[4] == a[5]:
        if len(set(a)) == 3:
            k += 1

print(k)
```

**Подробный разбор**

После сортировки одинаковые числа стоят рядом. Поэтому пары удобно проверять по соседним индексам.

Например, строка `1 2 3 3 1 2` после сортировки превращается в `1 1 2 2 3 3`. Видно, что она действительно разбивается на три пары одинаковых чисел.

Проверка `len(set(a)) == 3` нужна для того, чтобы в строке было ровно три разных значения. Тогда структура действительно соответствует трём парам.

**Ответ**

`3`


## Прототип 5. Ровно одно из двух условий

**Текст задания**

В файле электронной таблицы `9-190.xls` в каждой строке записаны 6 натуральных чисел. Определите количество строк таблицы, содержащих числа, для которых выполнено ровно одно из двух условий:

- в строке есть повторяющиеся числа;
- в строке есть ровно три нечётных числа.

**Идея решения**

Нужно отдельно проверить оба условия, а затем оставить только те строки, где выполняется ровно одно из них. Здесь удобно использовать сумму логических значений.

**Код решения**

```python
k = 0

for s in open('9-190.txt'):
    a = [int(x) for x in s.split()]

    c1 = len(set(a)) < len(a)
    c2 = len([x for x in a if x % 2 != 0]) == 3

    if c1 + c2 == 1:
        k += 1

print(k)
```

**Подробный разбор**

Условие `len(set(a)) < len(a)` означает, что хотя бы одно число повторяется. Если бы все числа были различны, количество элементов в множестве и в списке совпадало бы.

То же самое условие можно записать и через список повторяющихся элементов:

```python
rpt = [x for x in a if a.count(x) > 1]
```

Тогда наличие повторов проверяется так:

```python
len(rpt) > 0
```

Оба способа корректны. В этой задаче вариант через `set` короче, а вариант через `rpt` полезен тем, что совпадает с приёмом, который часто используется и в других прототипах задания 9.

Второе условие проверяет количество нечётных чисел. Список `[x for x in a if x % 2 != 0]` содержит только нечётные элементы строки.

Нам нужно, чтобы выполнялось ровно одно из условий. В Python значения `True` и `False` можно воспринимать как `1` и `0`. Поэтому запись `c1 + c2 == 1` означает, что из двух условий выполнилось ровно одно.

Например:
- если в строке есть повторы, но нечётных не три, строка подходит;
- если нечётных ровно три, но повторов нет, строка тоже подходит;
- если оба условия одновременно истинны или одновременно ложны, строка не подходит.

**Ответ**

`1852`


## Прототип 6. Минимум не повторяется и сравнение со средним

**Текст задания**

В файле электронной таблицы `9-210.xls` в каждой строке записаны 6 натуральных чисел. Определите количество строк таблицы, содержащих числа, для которых выполнены следующие условия:

- минимальное число не повторяется;
- среди остальных чисел строки есть повторяющиеся;
- сумма максимального и минимального чисел строки меньше, чем удвоенное среднее арифметическое остальных четырёх чисел.

**Идея решения**

Здесь тоже лучше отсортировать строку. Тогда минимальное число — это `a[0]`, максимальное — `a[5]`, а остальные четыре числа — это `a[1:5]`.

Нужно отдельно проверить:
- что минимум встречается ровно один раз;
- что среди остальных чисел есть хотя бы один повтор;
- что сумма крайних элементов меньше удвоенного среднего арифметического середины.

**Код решения**

```python
k = 0

for s in open('9-210.txt'):
    a = [int(x) for x in s.split()]
    a.sort()

    mid = a[1:5]
    sr = sum(mid) / 4

    if a.count(a[0]) == 1 and len(set(mid)) < len(mid):
        if a[0] + a[5] < 2 * sr:
            k += 1

print(k)
```

**Подробный разбор**

После сортировки минимальное число находится в начале списка, а максимальное — в конце.

Проверка `a.count(a[0]) == 1` означает, что минимум не повторяется.

Список `mid = a[1:5]` содержит четыре числа, которые остаются после удаления минимума и максимума. Если `len(set(mid)) < len(mid)`, то среди них есть повторяющиеся значения.

Среднее арифметическое этих четырёх чисел равно `sum(mid) / 4`. По условию нужно сравнить сумму максимального и минимального чисел с удвоенным средним, то есть проверить неравенство `a[0] + a[5] < 2 * sr`.

Например, если после сортировки строка равна `2 4 4 7 9 10`, то:
- минимум `2` не повторяется;
- среди середины `4 4 7 9` есть повтор `4`;
- остаётся проверить последнее неравенство.

То же решение можно записать и через минимальный элемент и список повторяющихся чисел:

```python
k = 0

for s in open('9-210.txt'):
    a = [int(x) for x in s.split()]
    a.sort()
    mn = min(a)
    rpt = [x for x in a if a.count(x) > 1]

    if mn not in rpt and len(rpt) > 0:
        if a[0] + a[5] < 2 * ((a[1] + a[2] + a[3] + a[4]) / 4):
            k += 1

print(k)
```

В этом варианте `mn not in rpt` означает, что минимальное число не повторяется, а `len(rpt) > 0` показывает, что среди чисел есть хотя бы один повтор. Такой способ ближе к общему шаблону с `rpt`, который часто используется в задачах этого типа.

**Ответ**

`428`


## Прототип 7. Наименьший номер строки

**Текст задания**

В файле электронной таблицы `9-222.xls` в каждой строке записаны шесть натуральных чисел. Определите наименьший номер строки таблицы, для чисел которой выполнены оба условия:

- в строке есть только одно число, которое повторяется дважды, остальные четыре числа различны;
- повторяющееся число строки не меньше, чем среднее арифметическое четырёх её неповторяющихся чисел.

В ответе запишите только число.

**Идея решения**

Нужно перебирать строки по порядку и одновременно считать их номера. Как только встретится первая подходящая строка, можно сразу вывести её номер и завершить перебор.

**Код решения**

```python
num = 0

for s in open('9-222.txt'):
    num += 1
    a = [int(x) for x in s.split()]

    rpt = [x for x in a if a.count(x) == 2]
    nrt = [x for x in a if a.count(x) == 1]

    if len(rpt) == 2 and len(nrt) == 4:
        sr = sum(nrt) / 4
        if rpt[0] >= sr:
            print(num)
            break
```

**Подробный разбор**

Если в строке ровно одно число повторяется дважды, то в список `rpt` войдут два одинаковых элемента. Остальные четыре различных числа попадут в `nrt`.

Проверка `len(rpt) == 2 and len(nrt) == 4` точно соответствует условию задачи.

Среднее арифметическое неповторяющихся чисел вычисляется как `sum(nrt) / 4`. Для сравнения достаточно взять `rpt[0]`, потому что оба элемента списка `rpt` одинаковы.

Так как нужен наименьший номер строки, после первой найденной строки используется `break`.

**Ответ**

`34`


## Прототип 8. Сумма чисел в первой подходящей строке

**Текст задания**

В файле электронной таблицы `9-226.xls` в каждой строке записаны семь натуральных чисел. Определите сумму чисел в строке таблицы с наименьшим номером, для которой выполнены оба условия:

- в строке есть два числа, которые повторяются дважды, остальные три числа различны;
- максимальное число строки не повторяется.

В ответе запишите только число.

**Идея решения**

Здесь снова нужен первый подходящий вариант, поэтому строки надо проверять по порядку. В строке должно быть ровно два разных числа, и каждое из них должно встретиться дважды. Значит, список повторяющихся элементов будет иметь длину `4`, а остальные три числа должны встретиться по одному разу.

После проверки условий достаточно вывести сумму чисел строки.

**Код решения**

```python
for s in open('9-226.txt'):
    a = [int(x) for x in s.split()]

    rpt = [x for x in a if a.count(x) == 2]
    nrt = [x for x in a if a.count(x) == 1]

    if len(rpt) == 4 and len(nrt) == 3:
        if max(a) in nrt:
            print(sum(a))
            break
```

**Подробный разбор**

Если два числа повторяются дважды, то в `rpt` попадут четыре элемента: по два вхождения каждого из этих чисел.

Например, для строки `17 17 38 42 42 48 57` список `rpt` будет равен `[17, 17, 42, 42]`, а `nrt` — `[38, 48, 57]`.

Проверка `len(rpt) == 4 and len(nrt) == 3` подтверждает нужную структуру строки.

Условие `max(a) in nrt` означает, что максимальное число не повторяется. Если максимум был бы повторяющимся, он попал бы в `rpt`, а не в `nrt`.

Так как нужна сумма чисел в строке с наименьшим номером, после первой подходящей строки сразу печатается `sum(a)` и выполняется `break`.

**Ответ**

`261`
