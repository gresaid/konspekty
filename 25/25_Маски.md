# ТЕОРИЯ

**Что проверяет задание 25**

В задачах на маски нужно найти числа, запись которых подходит под шаблон. Сама маска задаёт форму числа, а дальше добавляется обычное условие задачи: делимость, сумма цифр, ограничение на отдельные разряды.

**Как читать маску**

| Элемент маски | Что означает | Как записывается в regex |
| --- | --- | --- |
| Обычная цифра | Эта цифра стоит на своём месте | Та же цифра |
| `?` | Ровно одна цифра | `[0-9]` |
| `*` | Любая последовательность цифр, в том числе пустая | `[0-9]*` |
| `#` | Фиксированное количество цифр | Например, `[0-9]{3}` |
| Ограничение на цифры | Подходят не все цифры, а только нужные | Например, `[02468]`, `[13579]*` |

> Если символ в условии определён нестандартно, опираться нужно именно на это определение. Нельзя автоматически заменять `?` на `[0-9]`, если по условию требуется только чётная цифра.

**Почему используют `fullmatch(...)`**

Маска описывает всё число целиком, а не только его начало. Поэтому число переводят в строку и проверяют через `fullmatch(...)`.

```python
from re import fullmatch

fullmatch(pattern, str(n))
```

`fullmatch(...)` проверяет всю строку. Это важно: `match(...)` смотрит только на начало и может принять число, у которого справа есть лишние цифры.

**Порядок решения**

Обычно решение строят по одной схеме:

1. Перевести маску в регулярное выражение.
2. Выбрать удобный перебор.
3. Проверить маску.
4. Наложить дополнительные условия.
5. Вывести число и нужную характеристику.

### Базовый шаблон

По этой схеме решается большая часть прототипов в файле.

Если в условии требуется делимость на число `k`, не нужно перебирать все числа подряд. Сразу идём по кратным `k`, и отдельная проверка делимости уже не нужна.

Шаблон:

```python
from re import fullmatch

pattern = r'...'

for n in range(k, limit + 1, k):
    s = str(n)
    if fullmatch(pattern, s):
        if extra_condition(s, n):
            print(n, n // k)
```

Что здесь важно:

- `str(n)` нужен, потому что маска проверяет запись числа по цифрам;
- сначала проверяют маску, потом дополнительные условия;
- `n // k` даёт частное, потому что в цикл уже попадают только кратные `k`.

**Что ещё часто проверяют**

После проверки маски часто добавляют ещё одно условие:

| Что нужно проверить | Как обычно делаем |
| --- | --- |
| Делимость числа | Перебираем сразу кратные нужного числа |
| Сумму цифр | `sum(int(x) for x in str(n))` |
| Чётность или нечётность цифры | Используем `[02468]` или `[13579]` |

### Шпаргалка по `range(...)`

| Формулировка в условии | Какой диапазон брать |
| --- | --- |
| Не превышает `limit` | `range(k, limit + 1, k)` |
| Меньше `limit` | `range(k, limit, k)` |

Правая граница в `range(...)` не включается. Это место легко пропустить.

**Типичные ошибки**

- использовать `match(...)` вместо `fullmatch(...)`;
- забывать, что `*` может обозначать пустую последовательность;
- автоматически заменять `?` на `[0-9]`, когда по условию нужна только чётная или нечётная цифра;
- перебирать все числа подряд, хотя в задаче есть делимость на `k`;
- забывать про невключённую правую границу в `range(...)`.

# РАЗБОР ПРОТОТИПОВ

**Прототип 1. Маска `3?12?14*5`**

**Текст задания**

Среди натуральных чисел, не превышающих `10^10`, найти все числа, соответствующие маске `3?12?14*5`, делящиеся на `1917` без остатка.

В ответ записать в первом столбце таблицы все найденные числа в порядке возрастания, а во втором столбце - соответствующие им результаты деления этих чисел на `1917`.

**Идея решения**

Маска переводится в регулярное выражение:

- `?` -> ровно одна цифра, значит `[0-9]`;
- `*` -> любая последовательность цифр, в том числе пустая, значит `[0-9]*`.

Для маски `3?12?14*5` получаем шаблон `r'3[0-9]12[0-9]14[0-9]*5'`.

Дальше перебираем все числа в диапазоне и проверяем:

1. число подходит под маску;
2. число делится на `1917`.

**Код решения**

```python
from re import fullmatch

for n in range(1917, 10**10 + 1, 1917):
    if fullmatch(r'3[0-9]12[0-9]14[0-9]*5', str(n)):
        print(n, n // 1917)
```

**Разбор решения**

Перебор идёт не по всем числам подряд, а только по кратным `1917`. Так сразу убираем лишнюю проверку делимости и резко сокращаем количество кандидатов.

`str(n)` нужен, потому что маска задана по цифрам числа, а регулярное выражение работает со строкой.

`fullmatch(...)` проверяет всю строку целиком. Это важно: если использовать `match`, можно случайно принять число, у которого подходит только начало.

В шаблоне:

- `3` и `12`, `14`, `5` - фиксированные части маски;
- `[0-9]` - один произвольный разряд вместо `?`;
- `[0-9]*` - любая последовательность цифр вместо `*`.

`n // 1917` - это результат деления без остатка, потому что в цикл уже попадают только кратные `1917`.

**Ответ**

351261495 183235
3212614035 1675855
3412614645 1780185
3712414275 1936575
3912414885 2040905

**Прототип 2. Маска `21#68?79`**

**Текст задания**

Среди натуральных чисел, не превышающих `10^10`, найти все числа, соответствующие маске `21#68?79`, делящиеся на `1777` без остатка.

В ответ записать в первом столбце таблицы все найденные числа в порядке возрастания, а во втором столбце - соответствующие им результаты деления этих чисел на `1777`.

**Идея решения**

Основа та же, что в первом прототипе: перебираем кратные `1777` и проверяем маску через регулярное выражение.

Отличие только в символе `#`:

- `#` означает ровно три цифры, значит `[0-9]{3}`;
- `?` по-прежнему означает одну цифру, значит `[0-9]`.

Для маски `21#68?79` получаем шаблон `r'21[0-9]{3}68[0-9]79'`.

**Код решения**

```python
from re import fullmatch

for n in range(1777, 10**10 + 1, 1777):
    if fullmatch(r'21[0-9]{3}68[0-9]79', str(n)):
        print(n, n // 1777)
```

**Разбор решения**

Перебор и проверка делимости не меняются: цикл сразу идёт по кратным `1777`, поэтому внутри остаётся только проверка маски.

Главное отличие в шаблоне:

- `[0-9]{3}` заменяет `#`, потому что нужны ровно три цифры;
- `[0-9]` заменяет `?`, потому что нужна ровно одна цифра.

`fullmatch(...)` опять нужен для проверки всей строки целиком, иначе можно принять число с лишними цифрами по краям.

Вывод `n // 1777` даёт частное, потому что в цикл попадают только числа, кратные `1777`.

**Ответ**

2110768579 1187827
2135468879 1201727
2137068179 1202627
2161768479 1216527
2186468779 1230427
2188068079 1231327

**Прототип 3. Маска `1*2?3*45`**

**Текст задания**

Среди натуральных чисел, не превышающих `10^8`, найти все числа, соответствующие маске `1*2?3*45`, делящиеся на `153` без остатка.

В этой маске:

- `?` означает ровно одну произвольную чётную цифру;
- `*` означает любую последовательность нечётных цифр произвольной длины, в том числе пустую.

В ответ записать в первом столбце таблицы все найденные числа в порядке возрастания, а во втором столбце - соответствующие им результаты деления этих чисел на `153`.

**Идея решения**

Здесь уже нельзя заменить `?` и `*` на обычные шаблоны для всех цифр.

- `?` -> одна чётная цифра, значит `[02468]`;
- `*` -> любая последовательность нечётных цифр, значит `[13579]*`.

Для маски `1*2?3*45` получаем регулярное выражение `r'1[13579]*2[02468]3[13579]*45'`.

Как и раньше, перебираем кратные `153` и проверяем, подходит ли число под маску.

**Код решения**

```python
from re import fullmatch

for n in range(153, 10**8 + 1, 153):
    if fullmatch(r'1[13579]*2[02468]3[13579]*45', str(n)):
        print(n, n // 153)
```

**Разбор решения**

Основа решения прежняя: перебор только кратных `153` и проверка строки через `fullmatch(...)`.

Отличие в том, что теперь маска ограничивает не просто длину вставки, а сами цифры внутри вставки:

- `[13579]*` разрешает только нечётные цифры и может быть пустым;
- `[02468]` разрешает ровно одну чётную цифру.

Поэтому шаблон уже нельзя собрать заменой одних символов на другие без учёта чётности.

`str(n)` нужен для проверки числа как последовательности цифр.

`n // 153` - частное для всех чисел, которые дошли до вывода, потому что цикл идёт только по кратным `153`.

**Ответ**

1203345 7865
12035745 78665
12433545 81265
12831345 83865
15126345 98865

**Прототип 4. Маска `112?57*4` и нечётная сумма цифр**

**Текст задания**

Среди натуральных чисел, не превышающих `10^10`, найти все числа с нечётной суммой цифр, соответствующие маске `112?57*4` и делящиеся на `2024` без остатка.

В ответ записать в первом столбце таблицы все найденные числа в порядке возрастания, а во втором столбце - соответствующие им результаты деления этих чисел на `2024`.

**Идея решения**

Сначала проверяем маску, потом дополнительное условие на сумму цифр.

- `?` -> одна цифра, значит `[0-9]`;
- `*` -> любая последовательность цифр, значит `[0-9]*`.

Шаблон маски: `r'112[0-9]57[0-9]*4'`.

После совпадения с маской считаем сумму цифр числа и оставляем только числа с нечётной суммой.

**Код решения**

```python
from re import fullmatch

for n in range(2024, 10**10 + 1, 2024):
    if fullmatch(r'112[0-9]57[0-9]*4', str(n)):
        if sum(int(x) for x in str(n)) % 2 != 0:
            print(n, n // 2024)
```

**Разбор решения**

Основа та же: перебираем только кратные `2024`, чтобы не проверять делимость отдельно.

`fullmatch(...)` проверяет, что число целиком подходит под маску `112?57*4`.

После этого идёт вторая фильтрация:

- `sum(int(x) for x in str(n))` считает сумму цифр;
- `% 2 != 0` оставляет только нечётную сумму.

Порядок проверок важен: сначала дешёвая проверка маски, потом более дорогая сумма цифр. Так меньше лишней работы.

`n // 2024` - частное для найденных чисел.

**Ответ**

11275704 5571
1124576904 555621
1126570544 556606
1127572424 557101
1128574304 557596

**Прототип 5. 24 делителя и маска `4*`**

**Текст задания**

Найти все числа, меньшие `10^6`, которые имеют ровно `24` делителя, соответствуют маске `4*`, и максимальный делитель таких чисел соответствует маске.

В ответ указать найденные числа в порядке возрастания, справа от каждого числа вывести его максимальный делитель, соответствующий маске.

**Идея решения**

Тут две проверки:

1. у числа ровно `24` делителя;
2. среди его делителей есть такие, что они подходят под маску `4*`.

Маска `4*` значит: делитель начинается с `4`, а дальше идут любые цифры. Это удобно проверять через `fullmatch(r'4\d*', str(x))`.

Чтобы не перебирать делители в лоб, находим все делители числа через перебор до корня:

- если `i` делит `n`, то в список попадают и `i`, и `n // i`;
- потом убираем повторы через `set`;
- сортируем.

После этого считаем, сколько делителей подходит под маску, и берём максимальный среди них.

**Код решения**

```python
from re import fullmatch


def divisors(n):
    r = set()
    for i in range(1, int(n ** 0.5) + 1):
        if n % i == 0:
            r.add(i)
            r.add(n // i)
    return sorted(r)


for n in range(1, 10**6):
    divs = divisors(n)
    mask_divs = [x for x in divs if fullmatch(r'4\d*', str(x))]
    if len(divs) == 24 and mask_divs:
        print(n, max(mask_divs))
```

**Разбор решения**

`divisors(n)` строит список всех делителей числа. Перебор идёт только до `sqrt(n)`, потому что делители идут парами. Это ускоряет решение по сравнению с проверкой всех чисел до `n`.

`set()` нужен, чтобы не получить дубль в случае квадрата, где `i == n // i`.

Дальше для каждого `n`:

- `len(divs) == 24` проверяет число делителей;
- `fullmatch(r'4\d*', str(x))` оставляет только делители, начинающиеся с `4`;
- `max(mask_divs)` берёт максимальный подходящий делитель.

Если подходящих делителей нет, число не выводится.

**Ответ**

997920 498960
