# 19-21 задание

## ТЕОРИЯ

Задания 19-21 посвящены логическим играм. Здесь мало увидеть один удачный ход. Нужно понять, у кого есть выигрышная стратегия и на каком ходу она срабатывает.

Обычно в условии есть:
- начальная позиция;
- набор разрешённых ходов;
- условие окончания игры;
- правило определения победителя;
- вопрос про выигрыш первым или вторым ходом.

**Что хотят проверить**

| Что проверяется | Что это означает на практике |
|---|---|
| Анализ позиции | Нужно понять, выгодна ли текущая позиция для игрока |
| Понимание стратегии | Нужно учитывать не один ход, а ответы соперника |
| Работа с условием | Важно точно перенести в код все ограничения на ходы и конец игры |
| Различение 19, 20 и 21 | Формулировки похожи, но смысл проверок разный |

**Шпаргалка по вопросам 19, 20 и 21**

| Номер | Что обычно спрашивают | Как это читается в коде |
|---|---|---|
| 19 | Ваня выигрывает своим первым ходом | `f(s, 2)` |
| 20 | Петя не может выиграть сразу, но выигрывает вторым ходом | `f(s, 3) and not f(s, 1)` |
| 21 | Ваня выигрывает первым или вторым ходом, но не гарантированно первым | `f(s, 4) and not f(s, 2)` |

Это базовая схема. Если в условии появляются слова вроде «после неудачного хода Пети», читать задачу нужно внимательнее: в таких местах на одном из шагов меняется логика `all` и `any`.

**Как считать ходы**

| Номер хода | Кто ходит |
|---|---|
| 1 | Петя |
| 2 | Ваня |
| 3 | Петя |
| 4 | Ваня |

Это удобно держать в голове при чтении вопросов 19, 20 и 21. Если начинается путаница, можно просто загибать пальцы по порядку и отмечать, чей сейчас ход: первый палец — Петя, второй — Ваня, третий — снова Петя, четвёртый — снова Ваня.

**Первый способ: универсальный рекурсивный шаблон**

Главная идея проста: описать функцию, которая отвечает на вопрос, можно ли из текущей позиции добиться нужного результата за заданное число ходов.

```python
def f(..., m):
    ...
```

Параметр `m` показывает, сколько ходов осталось до интересующего нас исхода.

Базовый каркас:

```python
def f(s, m):
    if s >= 25:
        return m % 2 == 0
    if m == 0:
        return 0
    h = [
        f(s + 2, m - 1),
        f(s * 2, m - 1)
    ]
    return any(h) if m % 2 != 0 else all(h)
```

**Как устроен этот шаблон**

| Фрагмент кода | Смысл |
|---|---|
| `if ...:` в начале | Проверка, не закончилась ли игра |
| `return m % 2 == 0` | Определение, кто сделал последний ход |
| `if m == 0:` | Ходы закончились, а нужный результат не получен |
| `h = [...]` | Все возможные продолжения из текущей позиции |
| `any(h)` | Достаточно одного удачного хода |
| `all(h)` | Нужна победа при любом ответе соперника |

**Почему работает `m % 2 == 0`**

Если игра уже закончилась, победитель определяется тем, кто сделал последний ход.

Запись

```python
return m % 2 == 0
```

означает:
- если `m` чётное, последний ход сделал тот игрок, для которого строится выигрыш;
- если `m` нечётное, последний ход сделал соперник.

Именно поэтому первый способ подходит почти для всех задач 19-21: чаще всего меняются только ходы, граница окончания игры и диапазон перебора `S`.

**Что чаще всего меняется от задачи к задаче**

| Что меняется | Пример |
|---|---|
| Ходы | `+2`, `*2`, деление, уменьшение, ходы только при делимости |
| Условие конца игры | `s >= 25`, `k + s >= 45`, `k + s <= 20` |
| Правило победы | обычная победа последним ходом или особое условие поражения |
| Число куч | одна куча или две |
| Диапазон начальных значений | `range(1, 25)`, `range(1, 41)`, `range(20, 1000)` |

**Быстрые формулы для ответов**

```python
# 19
print([s for s in range(...) if f(..., 2)])

# 20
print([s for s in range(...) if f(..., 3) and not f(..., 1)])

# 21
print([s for s in range(...) if f(..., 4) and not f(..., 2)])
```

**Типичные ошибки**

- Перепутать, кто выигрывает в конечной позиции.
- Неправильно выбрать знак в условии окончания: `>=` вместо `<=` или наоборот.
- Проверять одну кучу вместо суммы двух куч.
- Неправильно собрать список ходов `h`.
- Забыть условие на доступность хода: чётность, кратность, округление.
- Перепутать смысл 20 номера и написать `f(..., 3)` без `not f(..., 1)`.
- Оставить замену `all` на `any` там, где она нужна только для специальной формулировки вопроса 19.

## РАЗБОР ПРОТОТИПОВ

### Прототип 1. Одна куча, ходы на увеличение

**Текст задания**

Два игрока, Петя и Ваня, играют в игру. Перед игроками лежит куча камней. Игроки ходят по очереди, первый ход делает Петя. За один ход игрок может добавить в кучу два камня или увеличить количество камней в куче в два раза. Игра завершается в тот момент, когда количество камней в куче становится не менее 25. Победителем считается игрок, сделавший последний ход. В начале в куче было `S` камней, `1 <= S <= 24`.

Вопрос 19. Найдите минимальное значение `S`, при котором Ваня выигрывает своим первым ходом при любой игре Пети.

Вопрос 20. Сколько существует значений `S`, при которых у Пети есть выигрышная стратегия, причём одновременно выполняются два условия:
- Петя не может выиграть за один ход.
- Петя может выиграть своим вторым ходом независимо от того, как будет ходить Ваня.

Вопрос 21. Найдите два значения `S`, при которых одновременно выполняются два условия:
- у Вани есть выигрышная стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети;
- у Вани нет стратегии, которая позволит ему гарантированно выиграть первым ходом.

**Идея решения**

Это базовый шаблон для одной кучи. Позиция задаётся числом `s`. Из каждой позиции есть два хода: `s + 2` и `s * 2`.

**Код решения**

```python
def f(s, m):
    if s >= 25:
        return m % 2 == 0
    if m == 0:
        return 0
    h = [
        f(s + 2, m - 1),
        f(s * 2, m - 1)
    ]
    return any(h) if m % 2 != 0 else all(h)


print([s for s in range(1, 25) if f(s, 2)])
print([s for s in range(1, 25) if f(s, 3) and not f(s, 1)])
print([s for s in range(1, 25) if f(s, 4) and not f(s, 2)])
```

**Разбор решения**

Здесь используется самый прямой вариант универсального шаблона, без дополнительных условий:
- конец игры: `s >= 25`;
- обычная победа последним ходом;
- два фиксированных хода в списке `h`.

Этот прототип удобно держать в голове как основную модель для одной кучи.

**Ответ**

| Номер | Ответ |
|---|---|
| 19 | `11` |
| 20 | `3` |
| 21 | `7 8` |

### Прототип 2. Одна куча, есть условие поражения

**Текст задания**

Два игрока, Петя и Ваня, играют в игру. Перед игроками лежит куча камней. Игроки ходят по очереди, первый ход делает Петя. За один ход игрок может добавить в кучу два камня или увеличить количество камней в куче в три раза.

Игра завершается, когда количество камней в куче становится не менее 45. Если при этом в куче оказалось не более 112 камней, победителем считается игрок, сделавший последний ход. Если в куче оказалось больше 112 камней, победителем считается его противник. В начале в куче было `S` камней, `1 <= S <= 44`.

Вопрос 19. Найдите минимальное значение `S`, при котором Ваня выигрывает своим первым ходом при любой игре Пети.

Вопрос 20. Сколько существует значений `S`, при которых у Пети есть выигрышная стратегия, причём одновременно выполняются два условия:
- Петя не может выиграть за один ход.
- Петя может выиграть своим вторым ходом независимо от того, как будет ходить Ваня.

Вопрос 21. Найдите минимальное и максимальное значения `S`, при которых одновременно выполняются два условия:
- у Вани есть выигрышная стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети;
- у Вани нет стратегии, которая позволит ему гарантированно выиграть первым ходом.

**Идея решения**

Каркас тот же, что и в предыдущем прототипе. Меняется только блок проверки конца игры: здесь есть обычная победа и отдельная ситуация проигрыша при слишком большом значении.

**Код решения**

```python
def f(s, m):
    if 45 <= s <= 112:
        return m % 2 == 0
    if s > 112:
        return m % 2 != 0
    if m == 0:
        return 0
    h = [
        f(s + 2, m - 1),
        f(s * 3, m - 1)
    ]
    return any(h) if m % 2 != 0 else all(h)


print([s for s in range(1, 45) if f(s, 2)])
print([s for s in range(1, 45) if f(s, 3) and not f(s, 1)])
print([s for s in range(1, 45) if f(s, 4) and not f(s, 2)])
```

**Разбор решения**

Главное отличие:
- если `45 <= s <= 112`, выигрывает игрок, сделавший последний ход;
- если `s > 112`, последний ход считается неудачным, поэтому выигрывает соперник.

Именно поэтому во второй проверке знак меняется на противоположный:

```python
return m % 2 != 0
```

**Ответ**

| Номер | Ответ |
|---|---|
| 19 | `41` |
| 20 | `3` |
| 21 | `12 38` |

### Прототип 3. Две кучи камней

**Текст задания**

Два игрока, Петя и Ваня, играют в игру. Перед игроками лежат две кучи камней. За один ход можно добавить в одну из куч 3 камня или увеличить количество камней в одной из куч в три раза. Игроки ходят по очереди, первым ходит Петя.

Игра завершается, когда суммарное количество камней в двух кучах становится не менее 45. Победителем считается игрок, сделавший последний ход. В начале в первой куче 4 камня, во второй куче `S` камней, `1 <= S <= 40`.

Вопрос 19. Известно, что Ваня выиграл своим первым ходом после неудачного первого хода Пети. Назовите минимальное значение `S`, при котором это возможно.

Вопрос 20. Найдите два таких значения `S`, при которых у Пети есть выигрышная стратегия, причём Петя не может выиграть первым ходом, но может выиграть своим вторым ходом независимо от того, как будет ходить Ваня. Найденные значения запишите в ответе в порядке возрастания.

Вопрос 21. Укажите такое значение `S`, при котором у Вани есть выигрышная стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети, и при этом у Вани нет стратегии, которая позволит ему гарантированно выиграть первым ходом.

**Идея решения**

Позиция задаётся уже двумя числами: `k` и `s`. В список ходов нужно включить все действия для обеих куч. Кроме того, в вопросе 19 здесь есть важная формулировка про неудачный ход Пети.

**Код решения**

```python
def f(k, s, m):
    if k + s >= 45:
        return m % 2 == 0
    if m == 0:
        return 0
    h = [
        f(k + 3, s, m - 1),
        f(k * 3, s, m - 1),
        f(k, s + 3, m - 1),
        f(k, s * 3, m - 1)
    ]
    return any(h) if m % 2 != 0 else all(h)


print([s for s in range(1, 41) if f(4, s, 2)])
print([s for s in range(1, 41) if f(4, s, 3) and not f(4, s, 1)])
print([s for s in range(1, 41) if f(4, s, 4) and not f(4, s, 2)])
```

**Разбор решения**

Что изменилось по сравнению с одной кучей:

| Элемент | Как было | Как стало |
|---|---|---|
| Состояние | `s` | `k, s` |
| Конец игры | одна куча достигла порога | сумма куч достигла порога |
| Ходы | 2 перехода | 4 перехода |

Здесь легко ошибиться именно из-за формулировки вопроса 19.

**Типичная ошибка**

Если в вопросе 19 сказано, что Ваня выиграл после неудачного первого хода Пети, то на соответствующем шаге нужно заменить `all` на `any`: нас интересует существование неудачного хода Пети, а не любой его ход.

В вопросе 20 эту замену нужно обязательно убрать и вернуть обычную схему обратно. Там снова нужна стратегия, которая работает при любой игре соперника.

**Ответ**

| Номер | Ответ |
|---|---|
| 19 | `5` |
| 20 | `8 13` |
| 21 | `12` |

### Прототип 4. Ходы на уменьшение

**Текст задания**

Два игрока, Петя и Ваня, играют в игру. Перед игроками лежат две кучи камней. За один ход игрок может убрать из одной из куч один камень или уменьшить количество камней в куче в два раза. Если количество камней нечётное, используется округление вверх.

Игра завершается в тот момент, когда суммарное количество камней в кучах становится не более 20. Победителем считается игрок, сделавший последний ход. В начале в первой куче 10 камней, во второй куче `S` камней, `S > 10`.

Вопрос 19. Найдите `S`, при котором Ваня выигрывает своим первым ходом при любой игре Пети.

Вопрос 20. Найдите минимальное и максимальное значения `S`, при котором у Пети есть выигрышная стратегия, причём одновременно выполняются два условия:
- Петя не может выиграть за один ход.
- Петя может выиграть своим вторым ходом независимо от того, как будет ходить Ваня.

Найденные значения запишите в ответе в порядке возрастания.

Вопрос 21. Найдите значение `S`, при котором одновременно выполняются два условия:
- у Вани есть выигрышная стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети;
- у Вани нет стратегии, которая позволит ему гарантированно выиграть первым ходом.

**Идея решения**

Каркас сохраняется, но игра теперь движется в сторону уменьшения. Поэтому условие окончания записывается через `<=`, а среди ходов появляется деление с округлением вверх.

**Код решения**

```python
from math import ceil


def f(k, s, m):
    if k + s <= 20:
        return m % 2 == 0
    if m == 0:
        return 0
    h = [
        f(k - 1, s, m - 1),
        f(ceil(k / 2), s, m - 1),
        f(k, s - 1, m - 1),
        f(k, ceil(s / 2), m - 1)
    ]
    return any(h) if m % 2 != 0 else all(h)


print([s for s in range(11, 1000) if f(10, s, 2)])
print([s for s in range(11, 1000) if f(10, s, 3) and not f(10, s, 1)])
print([s for s in range(11, 1000) if f(10, s, 4) and not f(10, s, 2)])
```

**Разбор решения**

Здесь важно не потерять две детали:
- игра заканчивается при `k + s <= 20`, а не при достижении верхней границы;
- при делении нечётного числа пополам используется округление вверх.

Короткая проверка:

| Было | Станет после деления на 2 |
|---|---|
| 8 | 4 |
| 9 | 5 |

**Ответ**

| Номер | Ответ |
|---|---|
| 19 | `21` |
| 20 | `22 42` |
| 21 | `24` |

### Прототип 5. Ходы зависят от делимости

**Текст задания**

Два игрока, Петя и Ваня, играют в следующую игру. Перед игроками лежит куча камней. Игроки ходят по очереди, первый ход делает Петя. За один ход игрок может выполнить одно из следующих действий:

1. убрать из кучи 5 камней;
2. если количество камней в куче чётно, уменьшить его в 2 раза;
3. если количество камней в куче кратно 3, уменьшить его в 3 раза;
4. если количество камней в куче нечётно и не кратно 3, добавить 1 камень.

Например, из 12 можно получить 7, 6 или 4, а из 11 можно получить 6 или 12.

Игра завершается, когда количество камней в куче становится не более 19. Победителем считается игрок, сделавший последний ход, то есть первым получивший кучу, в которой 19 или меньше камней. В начале игры в куче было `S` камней, `S > 19`.

Вопрос 19. Укажите минимальное значение `S`, при котором Петя не может выиграть первым ходом, но при любом первом ходе Пети Ваня может выиграть своим первым ходом.

Вопрос 20. Найдите два наименьших значения `S`, при которых Петя не может выиграть первым ходом, но у Пети есть выигрышная стратегия, позволяющая ему выиграть вторым ходом при любой игре Вани.

Вопрос 21. Найдите минимальное значение `S`, при котором у Вани есть стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети, но у Вани нет стратегии, которая позволила бы ему гарантированно выиграть первым ходом.

**Идея решения**

Это задача на одну кучу, но список ходов уже нельзя задать один раз и навсегда: он зависит от делимости числа `s`.

**Код решения**

```python
def f(s, m):
    if s <= 19:
        return m % 2 == 0
    if m == 0:
        return 0

    h = [f(s - 5, m - 1)]

    if s % 2 == 0:
        h.append(f(s // 2, m - 1))
    if s % 3 == 0:
        h.append(f(s // 3, m - 1))
    if s % 2 != 0 and s % 3 != 0:
        h.append(f(s + 1, m - 1))

    return any(h) if m % 2 != 0 else all(h)


print([s for s in range(20, 1000) if f(s, 2)])
print([s for s in range(20, 1000) if f(s, 3) and not f(s, 1)])
print([s for s in range(20, 1000) if f(s, 4) and not f(s, 2)])
```

**Разбор решения**

Главное здесь не сама рекурсия, а аккуратная сборка списка `h`.

| Условие | Какой ход добавляется |
|---|---|
| всегда | `s - 5` |
| `s % 2 == 0` | `s // 2` |
