## Разноуровневая сортировка

Разноуровневая сортировка нужна, когда объект описан несколькими признаками и порядок строится по цепочке условий, а не по одному числу.

Например:

- сначала по номеру ряда;
- при равенстве ряда по номеру места;
- при равенстве этих признаков по дополнительному правилу.

В Python списки и кортежи сравниваются слева направо. Обычная сортировка списка пар уже даёт сортировку по двум уровням:

```python
data = [[60, 160], [50, 15], [60, 22], [50, 12]]
data.sort()

print(data)
```

Результат:

```python
[[50, 12], [50, 15], [60, 22], [60, 160]]
```

Элементы сначала упорядочились по первому числу, а внутри одинаковых первых чисел - по второму.

Если направления сортировки разные, используют параметр `key`. Например, рейтинг кандидатов строится так:

- сумма баллов больше;
- при равенстве больше балл за собеседование;
- при равенстве меньше ID.

Ключ сортировки:

```python
key=lambda x: (-x[1], -x[2], x[0])
```

Минус перед числом задаёт порядок по убыванию.

## Зачем сортировка нужна в задачах 26

В 26 задании сортировка обычно нужна не сама по себе. После неё легче найти нужную структуру:

- соседние элементы внутри одной группы;
- крайние значения;
- блок элементов с одинаковым признаком;
- границу между прошедшими и непрошедшими;
- минимальное или максимальное значение для каждого ключа.

Сортировка заменяет полный перебор коротким проходом: элементы одной группы стоят рядом, а внутри группы уже идут в нужном порядке.

Частые приёмы:

- хранить запись как пару или тройку чисел;
- сортировать список целиком;
- проходить по соседним элементам;
- брать часть списка с начала или конца;
- использовать словарь, если данные нужно сгруппировать по ключу;
- удалять дубликаты через `set`, если повторные записи не должны учитываться.

## Общие приёмы чтения данных

Во всех прототипах используется один и тот же базовый способ чтения файла:

```python
f = open('26.txt')
```

Первая строка обычно содержит количество записей или параметры задачи. Остальные строки читаются в цикле.

Если в строке несколько чисел, они разбираются так:

```python
row, seat = map(int, line.split())
```

Дальше эти служебные строки не разбираются заново. В прототипах важнее структура данных, сортировка и правило обновления ответа.

## Частые ошибки

- Сравнивать элементы из разных групп как элементы одной группы.
- Перебирать все пары, хотя после сортировки хватает соседних элементов `i` и `i + 1`.
- Учитывать повторы, если по условию повторные записи не засчитываются.
- Обновлять ответ при равенстве, хотя нужен первый найденный вариант. В таких случаях используется строгое улучшение: `>`, а не `>=`.
- Записывать поля в пару или кортеж не в том порядке, который нужен для сортировки.

## Прототип 1. Два соседних свободных места между занятыми

**Текст задания**

Организация купила для сотрудников все места в нескольких подряд идущих рядах на концертной площадке. Известно, какие места уже распределены. Требуется найти ряд с наибольшим номером, где есть два соседних свободных места, а слева и справа от них в том же ряду места уже заняты.

В первой строке входного файла записано число `N` - количество занятых мест. Далее идут пары чисел: номер ряда и номер занятого места.

Ответ состоит из двух чисел:

- максимальный номер подходящего ряда;
- наименьший номер места из найденной свободной пары.

**Идея решения**

Если заняты места `x` и `x + 3`, то между ними находятся ровно два свободных соседних места:

```text
x     x + 1   x + 2   x + 3
X       O       O       X
```

Искомая ситуация сводится к двум занятым позициям в одном ряду с разностью `3`.

Каждая запись хранится как пара `[ряд, место]`. После сортировки все места одного ряда окажутся рядом, а номера мест внутри ряда пойдут по возрастанию. Остаётся проверять соседние записи.

**Код решения**

```python
f = open('26.txt')
n = int(f.readline())
data = []

for line in f:
    row, seat = map(int, line.split())
    data.append([row, seat])

data.sort()

ans_row = -1
ans_seat = -1

for i in range(len(data) - 1):
    row1, seat1 = data[i]
    row2, seat2 = data[i + 1]

    if row1 == row2 and seat2 - seat1 == 3 and row1 > ans_row:
        ans_row = row1
        ans_seat = seat1 + 1

print(ans_row, ans_seat)
```

**Подробный разбор**

`data` хранит занятые места. После `data.sort()` пары идут сначала по номеру ряда, затем по номеру места.

Цикл

```python
for i in range(len(data) - 1):
```

берёт две соседние записи: `data[i]` и `data[i + 1]`.

Условие

```python
row1 == row2 and seat2 - seat1 == 3
```

означает, что занятые места находятся в одном ряду и между ними ровно два свободных места.

Дополнительная проверка

```python
row1 > ans_row
```

оставляет ряд с максимальным номером. Так как строки отсортированы по возрастанию, первый найденный вариант внутри этого ряда даёт минимальный номер свободного места.

Если заняты места `22` и `25`, свободная пара начинается с `23`; в ответ записывается `seat1 + 1`.

**Ответ**

```python
8631 7311
```

## Прототип 2. Акция «каждый четвёртый товар за полцены»

**Текст задания**

В супермаркете проводится акция: каждый четвёртый товар в чеке продаётся за полцены. Покупатель расположил товары на ленте так, чтобы заплатить как можно меньше. Кассовая программа не учитывает порядок на ленте и сортирует цены так, чтобы итоговая стоимость стала максимально возможной.

В первой строке входного файла записано число `N` - количество товаров. Далее идут цены товаров.

Ответ состоит из двух сумм:

- сумма, которую предполагал заплатить покупатель;
- сумма, которую он заплатил фактически.

**Идея решения**

Количество товаров со скидкой равно

```python
n // 4
```

Если скидок `k`, покупателю выгодно отдать их на `k` самых дорогих товаров. Магазину выгодно, чтобы скидка попала на `k` самых дешёвых товаров.

Задача сводится к двум сортировкам одного списка:

- по возрастанию - последние `k` элементов будут самыми дорогими;
- по убыванию - последние `k` элементов будут самыми дешёвыми.

**Код решения**

```python
f = open('26.txt')
n = int(f.readline())
costs = sorted(int(x) for x in f)

k = n // 4

sm1 = sum(costs[:n - k]) + sum(costs[n - k:]) // 2

costs_desc = sorted(costs, reverse=True)
sm2 = sum(costs_desc[:n - k]) + sum(costs_desc[n - k:]) // 2

print(sm1, sm2)
```

**Подробный разбор**

`costs` - цены, отсортированные по возрастанию.

`k` показывает, сколько товаров получат скидку. Например, при `n = 10` скидка будет у двух товаров: `10 // 4 = 2`.

Сумма покупателя считается так:

```python
sm1 = sum(costs[:n - k]) + sum(costs[n - k:]) // 2
```

В срезе `costs[:n - k]` лежат товары без скидки, а в `costs[n - k:]` - `k` самых дорогих товаров. Именно на них покупатель хотел получить скидку.

Для реальной суммы список разворачивается по убыванию:

```python
costs_desc = sorted(costs, reverse=True)
```

В таком порядке последние `k` элементов - самые дешёвые товары. На них и попадает скидка в варианте, выгодном магазину:

```python
sm2 = sum(costs_desc[:n - k]) + sum(costs_desc[n - k:]) // 2
```

Разбиение через `n - k` работает и при `k = 0`: первая часть содержит весь список, вторая остаётся пустой.

**Ответ**

Итоговые числа в исходных материалах не зафиксированы. Ответ получается запуском кода на файле данных.

## Прототип 3. Самая длинная цепочка задач через одну

**Текст задания**

В системе хранится банк задач. Для каждого зачтённого решения указаны идентификатор студента и номер задачи. Один студент может несколько раз сдать одну и ту же задачу, но в зачёт она идёт только один раз.

Требуется определить:

- ID студента, который решил наибольшее количество задач через одну;
- количество задач в такой цепочке.

Если таких студентов несколько, выбирается наименьший ID.

**Идея решения**

Для каждого студента собирается множество решённых задач. Повторы одной задачи удаляются, затем номера задач сортируются.

Цепочка «через одну» - это последовательность, где соседние номера отличаются на `2`:

```python
124, 126, 128, 130
```

После сортировки проход идёт по соседним задачам одного студента. Разность `2` продолжает цепочку, другая разность начинает новую.

**Код решения**

```python
f = open('26.txt')
n = int(f.readline())
d = {}

for line in f:
    student, task = map(int, line.split())
    if student not in d:
        d[student] = [task]
    else:
        d[student].append(task)

mx = 1
students = []

for student in d:
    a = sorted(set(d[student]))
    k = 1
    best = 1

    for i in range(len(a) - 1):
        if a[i + 1] - a[i] == 2:
            k += 1
            best = max(best, k)
        else:
            k = 1

    if best > mx:
        mx = best
        students = [student]
    elif best == mx:
        students.append(student)

print(min(students), mx)
```

**Подробный разбор**

`d` - словарь вида:

```python
студент -> список решённых задач
```

После чтения данных для каждого студента строится список уникальных задач:

```python
a = sorted(set(d[student]))
```

`set` удаляет повторные сдачи одной задачи, `sorted` возвращает номера в порядке возрастания.

Для одного студента используются две переменные:

- `k` - длина текущей цепочки;
- `best` - лучшая длина цепочки у этого студента.

Внутренний цикл сравнивает соседние задачи:

```python
if a[i + 1] - a[i] == 2:
    k += 1
    best = max(best, k)
else:
    k = 1
```

Например, в списке

```python
91, 93, 95, 101, 103
```

есть две цепочки: `91, 93, 95` и `101, 103`. На переходе от `95` к `101` разность уже не равна `2`, счётчик сбрасывается.

После обработки студента его результат сравнивается с общим максимумом `mx`. Если найден новый максимум, список `students` пересоздаётся. Если результат равен максимуму, студент добавляется к кандидатам. В конце `min(students)` выбирает наименьший ID среди лучших.

**Ответ**

```python
10135 42
```

## Прототип 4. Два соседних места, перед которыми всё свободно

**Текст задания**

При онлайн-покупке билета известно, какие места в зале уже заняты. Нужно купить два соседних места в одном ряду так, чтобы перед ними все кресла с такими же номерами были свободны. Ряд выбирается как можно дальше от сцены. Если в этом ряду несколько подходящих пар, берётся пара с наименьшими номерами мест.

В первой строке входного файла записаны:

- `N` - количество занятых мест;
- `M` - количество рядов;
- `K` - количество мест в каждом ряду.

Далее идут пары чисел: номер ряда и номер занятого места.

Ответ состоит из двух чисел:

- наибольший номер подходящего ряда;
- наименьший номер первого места в найденной паре.

**Идея решения**

Здесь данные группируются не по рядам, а по номерам мест.

Для каждого места нужен первый занятый ряд, считая от сцены. Если место `6` впервые занято в ряду `3`, то в рядах `1` и `2` оно свободно, а начиная с ряда `3` брать его уже нельзя.

Для пары соседних мест `i` и `i + 1` дальность ограничивает меньшее из двух значений:

```python
min(first[i], first[i + 1]) - 1
```

Например:

```python
first[5] = 8
first[6] = 12
```

Место `5` свободно до ряда `7`, место `6` - до ряда `11`. Оба места одновременно можно взять максимум в ряду `7`.

Если какое-то место вообще не занято, для него записывается `M + 1`. Тогда формула остаётся общей: место считается свободным до последнего ряда включительно.

**Код решения**

```python
f = open('26.txt')
n, m, k = map(int, f.readline().split())
d = {i: m + 1 for i in range(1, k + 1)}

for line in f:
    row, place = map(int, line.split())
    d[place] = min(d[place], row)

max_r = 0
ans_place = -1

for i in range(1, k):
    r = min(d[i], d[i + 1]) - 1
    if r > max_r:
        max_r = r
        ans_place = i

print(max_r, ans_place)
```

**Подробный разбор**

`d` хранит минимальный занятый ряд для каждого номера места:

```python
место -> первый занятый ряд
```

Изначально для всех мест записано `m + 1`, то есть место считается свободным во всех рядах.

При чтении занятого места обновляется только минимум:

```python
d[place] = min(d[place], row)
```

Если место `6` занято в рядах `15`, `40` и `73`, для ответа нужен только ряд `15`: именно он первым запрещает использовать это место дальше от сцены.

Затем перебираются все соседние пары мест:

```python
for i in range(1, k):
    r = min(d[i], d[i + 1]) - 1
```

`i` - первое место в паре. Значение `r` - самый дальний ряд, где оба места ещё свободны.

Ответ обновляется только при строгом улучшении:

```python
if r > max_r:
```

Пары перебираются слева направо. При равенстве ряда первая найденная пара уже имеет наименьший номер места.

**Ответ**

```python
21028 6660
```

## Прототип 5. Проходной и полупроходной баллы

**Текст задания**

Каждый кандидат в отряд космонавтов проходит три испытания и собеседование. Для каждого кандидата известны:

- ID;
- три балла за испытания;
- балл за собеседование.

Кандидаты ранжируются:

- по убыванию общей суммы баллов;
- при равенстве суммы по убыванию балла за собеседование;
- при равенстве этих значений по возрастанию ID.

Ответ состоит из двух значений:

- ID кандидата, который последним в рейтинге набрал проходной балл;
- количество кандидатов, набравших полупроходной балл.

Если полупроходного балла нет, второе число равно `0`.

**Идея решения**

Сначала строится рейтинговый список. Для каждого кандидата хранятся три значения:

```python
[ID, сумма, собеседование]
```

Сортировка задаётся ключом:

```python
key=lambda x: (-x[1], -x[2], x[0])
```

После сортировки граница зачисления находится между кандидатами с индексами `k - 1` и `k`.

Если сумма последнего зачисленного больше суммы первого незачисленного, полупроходного балла нет. Если суммы равны, эта сумма считается полупроходной, а проходной балл ищется выше по рейтингу.

**Код решения**

```python
f = open('26.txt')
n, k = map(int, f.readline().split())
candidates = []

for line in f:
    ident, a, b, c, interview = map(int, line.split())
    total = a + b + c + interview
    candidates.append([ident, total, interview])

candidates.sort(key=lambda x: (-x[1], -x[2], x[0]))

last_admitted = candidates[k - 1]

if k == n or candidates[k][1] != last_admitted[1]:
    pass_score = last_admitted[1]
    semi_count = 0
else:
    semi_score = last_admitted[1]
    semi_count = sum(1 for x in candidates if x[1] == semi_score)
    i = k - 1
    while i >= 0 and candidates[i][1] == semi_score:
        i -= 1
    pass_score = candidates[i][1]

pass_id = [x[0] for x in candidates if x[1] == pass_score][-1]

print(pass_id, semi_count)
```

**Подробный разбор**

Для каждого кандидата считается `total` - сумма всех испытаний и собеседования. В `candidates` попадают только данные для рейтинга: ID, сумма и балл за собеседование.

Сортировка

```python
candidates.sort(key=lambda x: (-x[1], -x[2], x[0]))
```

полностью повторяет правило из условия:

- `-x[1]` - большая сумма выше;
- `-x[2]` - при равной сумме выше больший балл за собеседование;
- `x[0]` - при полном равенстве выше меньший ID.

Последний зачисленный:

```python
last_admitted = candidates[k - 1]
```

Если зачислены все кандидаты или следующий кандидат имеет другую сумму, проходной балл равен сумме последнего зачисленного:

```python
pass_score = last_admitted[1]
semi_count = 0
```

Если следующий кандидат имеет такую же сумму, эта сумма полупроходная:

```python
semi_score = last_admitted[1]
semi_count = sum(1 for x in candidates if x[1] == semi_score)
```

Затем цикл поднимается вверх по рейтингу, пока не закончится блок с полупроходным баллом:

```python
while i >= 0 and candidates[i][1] == semi_score:
    i -= 1
```

Первый балл выше этого блока и есть проходной.

ID последнего кандидата с проходным баллом берётся из уже отсортированного рейтинга:

```python
pass_id = [x[0] for x in candidates if x[1] == pass_score][-1]
```

**Ответ**

```python
45539 127
```
