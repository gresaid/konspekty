## Временная линия и интервалы

В задачах на временную линию обычно даны отрезки времени: начало и конец события. По ним нужно определить занятые участки шкалы, суммарную занятость, максимальный непрерывный промежуток или количество одновременных событий.

Типичные данные в таких задачах:

- начало и конец интервала;
- начало и длительность интервала;
- момент появления объекта на временной линии;
- регулярные моменты обработки или проверки состояния;
- общая граница рассматриваемого периода.

Главная идея: не нужно складывать длины всех интервалов напрямую. Если интервалы пересекаются, общая занятая длина меньше суммы отдельных длин, потому что пересечение нельзя считать дважды.

Например, два пересекающихся интервала вместе образуют один общий занятый промежуток. При подсчёте суммарной длины пересечение учитывается один раз.

## Полуинтервалы

В задачах с временем удобно считать промежутки полуинтервалами:

```text
[начало; конец)
```

Левая граница входит в промежуток, правая не входит. Если один интервал заканчивается в момент `t`, а следующий начинается в тот же момент `t`, между ними нет свободного участка. Такие интервалы объединяются в один непрерывный промежуток.

Для объединения это означает:

```python
if nach <= tek_kon:
```

Если новое начало не больше текущего конца, интервал пересекается с уже найденным занятым промежутком или продолжает его без разрыва.

## Сортировка интервалов

Чтобы объединять интервалы, их сначала сортируют по времени начала:

```python
otr.sort()
```

Если интервал записан как список или кортеж `(nach, kon)`, обычная сортировка сначала сравнивает `nach`, а при равенстве - `kon`.

После сортировки можно идти слева направо и хранить один объединённый промежуток:

- `tek_nach` - начало текущего занятого промежутка;
- `tek_kon` - его правый конец;
- `summa` - суммарная длина уже завершённых занятых промежутков;
- `maks` - максимальная длина одного непрерывного занятого промежутка.

## Общий шаблон объединения интервалов

```python
otr.sort()

tek_nach, tek_kon = otr[0]
summa = 0
maks = 0

for nach, kon in otr[1:]:
    if nach <= tek_kon:
        tek_kon = max(tek_kon, kon)
    else:
        dlina = tek_kon - tek_nach
        summa += dlina
        maks = max(maks, dlina)

        tek_nach = nach
        tek_kon = kon

dlina = tek_kon - tek_nach
summa += dlina
maks = max(maks, dlina)
```

Смысл шаблона:

- если новый интервал пересекается с текущим или примыкает к нему, двигаем правую границу;
- если новый интервал начинается после текущего конца, значит текущий занятый промежуток завершён;
- перед переходом к новому промежутку добавляем длину завершённого промежутка в ответ;
- после цикла отдельно учитываем последний текущий промежуток, потому что внутри цикла он ещё не был добавлен.

## События изменения количества

Если нужно знать не только занятость участка, но и точное количество объектов на временной линии, удобнее хранить события изменения:

- начало интервала увеличивает количество на `1`;
- конец интервала уменьшает количество на `1`.

Если правая граница не входит в интервал, для промежутка `[nach; kon)` записывают:

```python
sobytiya.append((nach, 1))
sobytiya.append((kon, -1))
```

Если по условию объект находится на линии и в момент начала, и в момент конца, интервал считается включительным: `[nach; kon]`. Тогда уменьшение нужно делать не в момент `kon`, а в следующий момент:

```python
sobytiya.append((nach, 1))
sobytiya.append((kon + 1, -1))
```

После сортировки событий количество постоянно между двумя соседними моментами изменений. Перед обработкой событий с временем `vremya` можно оценить участок от `pred` до `vremya`: на нём количество равно текущему значению `kol`.

Такой приём нужен, когда требуется найти максимальное или текущее количество объектов на временной линии.

## Поиск свободных промежутков

Иногда в задаче нужно найти свободные промежутки: участки, на которых нет ни одного активного интервала. Для этого после сортировки занятых интервалов смотрят разрывы между ними.

Если известна общая длина наблюдения `L`, важно проверить три типа свободных участков:

- от начала наблюдения до первой занятости;
- между соседними занятыми промежутками;
- от конца последней занятости до `L`.

Занятые интервалы удобно хранить в виде `[nach; kon)`, где:

```python
kon = nach + dlit
```

Текущая правая граница занятости хранится в переменной `tek_kon`. Если следующий интервал начинается позже этой границы, найден свободный промежуток:

```python
if nach > tek_kon:
    prost = nach - tek_kon
```

Если по условию учитываются только свободные участки длиной не менее `M`, в ответ попадают только промежутки с проверкой:

```python
if prost >= m:
```

## Регулярные события на временной линии

В некоторых задачах события происходят через равные промежутки времени. Такие моменты имеют вид `K`, `2K`, `3K` и так далее.

Если значение `vremya` нужно отнести к ближайшему следующему регулярному моменту, этот момент находится делением с округлением вверх:

```python
sob_vremya = ((vremya + k - 1) // k) * k
```

Это означает:

- значение `vremya` относится к моменту `sob_vremya`;
- если `vremya == sob_vremya`, оно совпало с регулярным моментом;
- если `vremya < sob_vremya`, оно появилось раньше регулярного момента;
- если задача ограничена правой границей `gran`, учитываются только события с временем не больше `gran`.

Если нужно выбрать последний объект среди нескольких одинаково лучших вариантов, ответ обновляют при равенстве:

```python
if tek >= luch:
```

## Частые ошибки

- Складывать длины всех интервалов без объединения пересечений.
- Использовать условие `nach < tek_kon` вместо `nach <= tek_kon`, если интервалы, соприкасающиеся концами, должны считаться одним непрерывным промежутком.
- Забывать обновлять `tek_kon = max(tek_kon, kon)`. Если новый интервал целиком лежит внутри текущего, правый конец не должен уменьшаться.
- Не добавить последний объединённый промежуток после цикла.
- Считать максимальную длину отдельного интервала, а не максимальную длину объединённого занятого отрезка.
- Вычитать объект в момент окончания, хотя по условию правая граница тоже должна учитываться.
- При поиске свободных промежутков забывать проверить участки до первого интервала и после последнего интервала.
- При выборе последнего максимума обновлять ответ только при строгом улучшении, хотя по условию нужно брать самый поздний вариант при равенстве.

## Прототип 1. Суммарное время показа фильмов

**Текст задания**

(№ 10726) Входной файл содержит расписание показа фильмов во всех кинотеатрах Москвы за весь прошедший месяц. Определите суммарное время, в течение которого показывался хотя бы один фильм.

В первой строке входного файла находится натуральное число `N` (`N <= 1000`) - общее количество фильмов. Следующие `N` строк содержат пары чисел, обозначающих время начала и время окончания фильмов в минутах с начала месяца. Каждое из чисел натуральное, не превосходящее `44640`.

Запишите в ответе два числа: суммарное время в минутах, в течение которого показывался хотя бы один фильм, и максимальную длину непрерывного отрезка времени в минутах, в течение которого показывался хотя бы один фильм.

**Идея решения**

Каждый фильм задаёт интервал занятости временной линии. Нужно найти объединение всех таких интервалов.

Если несколько фильмов идут одновременно, этот участок всё равно считается один раз: в каждую его минуту показывается хотя бы один фильм. Поэтому интервалы сортируются по началу и последовательно склеиваются.

Для каждого завершённого объединённого промежутка считаются два значения:

- его длина добавляется к суммарному времени;
- его длина сравнивается с максимумом.

**Код решения**

```python
f = open('26_10726.txt')
n = int(f.readline())

otr = []
for _ in range(n):
    nach, kon = map(int, f.readline().split())
    otr.append((nach, kon))

otr.sort()

tek_nach, tek_kon = otr[0]
summa = 0
maks = 0

for nach, kon in otr[1:]:
    if nach <= tek_kon:
        tek_kon = max(tek_kon, kon)
    else:
        dlina = tek_kon - tek_nach
        summa += dlina
        maks = max(maks, dlina)

        tek_nach = nach
        tek_kon = kon

dlina = tek_kon - tek_nach
summa += dlina
maks = max(maks, dlina)

print(summa, maks)
```

**Разбор решения**

В список `otr` записываются все пары `(nach, kon)`: начало и конец показа фильма в минутах с начала месяца.

После сортировки интервалы идут слева направо по временной шкале. Переменные `tek_nach` и `tek_kon` хранят границы текущего объединённого промежутка, в котором показывался хотя бы один фильм.

Проверка:

```python
if nach <= tek_kon:
```

означает, что новый фильм пересекается с текущим занятым промежутком или начинается ровно в момент его окончания. В обоих случаях непрерывный промежуток не прерывается. Правую границу берём по более позднему окончанию:

```python
tek_kon = max(tek_kon, kon)
```

Если `nach > tek_kon`, между текущим занятым промежутком и новым фильмом есть свободное время. Значит, текущий промежуток завершён. Его длина равна:

```python
dlina = tek_kon - tek_nach
```

Эта длина добавляется к `summa` и сравнивается с `maks`. После этого начинается новый текущий промежуток с границами `nach` и `kon`.

После цикла отдельно учитывается последний промежуток: внутри цикла он ещё не добавлен.

Алгоритм подходит под ограничения: `N <= 1000`, сортировка и один проход по списку выполняются быстро.

**Ответ**

```text
38032 3014
```

## Прототип 2. Пики посещаемости магазина

**Текст задания**

(№ 9847) Система наблюдения ежеминутно фиксирует вход и выход посетителей магазина в минутах, прошедших от начала суток. Считается, что в моменты фиксации входа и выхода посетитель находится в магазине. Нулевая минута соответствует моменту открытия магазина, который работает 24 часа в сутки без перерыва.

Менеджер анализирует данные за прошедшие сутки и выявляет отрезки времени наибольшей длины, в течение которых число посетителей в магазине не изменялось. Далее менеджер выбирает пики посещаемости - промежутки времени, когда количество посетителей в магазине было наибольшим. Пиков посещаемости в течение суток может быть несколько.

В первой строке входного файла находится натуральное число `N` (`N < 10000`) - количество посетителей магазина. Следующие `N` строк содержат пары чисел, обозначающих соответственно время входа и время выхода посетителя. Все числа натуральные, не превышающие `1440`.

Запишите в ответе два натуральных числа: сначала найденное количество пиков посещаемости, а затем число посетителей в момент пика посещаемости.

**Идея решения**

В этой задаче интервалы не склеиваются: важно считать, сколько посетителей находится в магазине на каждом участке без изменений.

По примеру видно, что пик записывается как промежуток между минутными отметками. Поэтому посетитель с входом `nach` и выходом `kon` учитывается на отрезке `[nach; kon)`: он добавляется с минуты входа и убирается с минуты выхода.

Для такой задачи удобно использовать разностную таблицу по минутам:

- в `razn[nach]` добавляется `1`;
- в `razn[kon]` вычитается `1`.

После накопления разностей получаем количество посетителей на каждом минутном участке. Соседние минуты с тем же максимальным количеством относятся к одному пику, поэтому пик нельзя считать заново на каждой минуте подряд.

**Код решения**

```python
f = open('26_9847.txt')
n = int(f.readline())

razn = [0] * 1441
for _ in range(n):
    nach, kon = map(int, f.readline().split())
    razn[nach] += 1
    razn[kon] -= 1

kol = 0
maks = 0
piki = 0
v_pike = False

for t in range(1440):
    kol += razn[t]

    if kol > maks:
        maks = kol
        piki = 1
        v_pike = True
    elif kol == maks and kol > 0:
        if not v_pike:
            piki += 1
            v_pike = True
    else:
        v_pike = False

print(piki, maks)
```

**Разбор решения**

Список `razn` хранит изменения количества посетителей по минутам. Если посетитель вошёл в минуту `nach`, начиная с этой минуты количество увеличивается на `1`. Если он вышел в минуту `kon`, с участка `[kon; kon + 1)` он уже не учитывается, поэтому в `razn[kon]` вычитается `1`.

Переменная `kol` хранит текущее число посетителей после применения разности для минуты `t`.

Если `kol` стал больше прежнего `maks`, найден новый максимум посещаемости: `maks` обновляется, а число пиков `piki` становится равным `1`.

Если `kol == maks`, новый пик засчитывается только тогда, когда предыдущая минута не была частью такого же пика. Для этого используется флаг `v_pike`. Так соседние минуты одного и того же пикового промежутка не считаются несколько раз.

Если количество стало меньше максимального, флаг `v_pike` сбрасывается. Следующий участок с тем же максимумом будет отдельным пиком.

**Проверка на примере**

Для посетителя с интервалом `100 150` изменения будут такими:

```text
100: +1
150: -1
```

Значит, посетитель учитывается на минутных участках от `100` до `150`, но не на участке после отметки `150`.

**Ответ**

```text
2 643
```

## Прототип 3. Простои станка

**Текст задания**

(№ 2650) На производстве станок с ЧПУ обрабатывал некоторый набор деталей. В каждый момент времени станок может обрабатывать только одну деталь. Каждая деталь изготавливалась в определённый промежуток времени с момента начала рабочего дня. Простоем считается временной участок длиной не менее `M` секунд, в который не обрабатывается ни одна деталь. Инженер решил узнать, какое количество простоев произошло за день и какова длительность наибольшего простоя. Общая длительность рабочего дня `L` секунд.

В первой строке входного файла находятся три числа: `L` - общая длина рабочего дня, `M` - минимальная длительность простоя в секундах, `N` - количество изготовленных деталей. В следующих `N` строках находится по два числа: время начала обработки от начала рабочего дня и длительность обработки.

Запишите в ответе два числа: количество простоев за день и длительность наибольшего простоя.

**Идея решения**

Каждая деталь задаёт занятый интервал станка:

```python
[nach; nach + dlit)
```

Простои - это свободные промежутки между занятыми интервалами. Поэтому детали сортируются по времени начала, а программа идёт по ним слева направо и хранит `tek_kon` - момент, до которого станок уже занят.

Если начало следующей детали больше `tek_kon`, между ними есть простой. Он учитывается только тогда, когда его длина не меньше `M`.

**Код решения**

```python
f = open('26_2650.txt')
den, m, n = map(int, f.readline().split())

otr = []
for _ in range(n):
    nach, dlit = map(int, f.readline().split())
    otr.append((nach, nach + dlit))

otr.sort()

tek_kon = 0
kol_prost = 0
maks_prost = 0

for nach, kon in otr:
    if nach > tek_kon:
        prost = nach - tek_kon
        if prost >= m:
            kol_prost += 1
            maks_prost = max(maks_prost, prost)

    tek_kon = max(tek_kon, kon)

if den > tek_kon:
    prost = den - tek_kon
    if prost >= m:
        kol_prost += 1
        maks_prost = max(maks_prost, prost)

print(kol_prost, maks_prost)
```

**Разбор решения**

В список `otr` записываются промежутки обработки деталей. Второе число в строке файла - это не время окончания, а длительность, поэтому конец обработки вычисляется как `nach + dlit`.

Переменная `tek_kon` показывает правую границу уже обработанной занятости станка. Изначально она равна `0`, поэтому первый найденный разрыв будет простоем от начала рабочего дня до первой детали.

Проверка:

```python
if nach > tek_kon:
```

означает, что новая деталь начинается позже, чем закончилась предыдущая занятость станка. Длина простоя равна `nach - tek_kon`.

Не каждый свободный участок считается простоем: по условию нужна длина не менее `M`, поэтому используется проверка `prost >= m`. Если она выполнена, увеличиваем `kol_prost` и обновляем `maks_prost`.

Строка:

```python
tek_kon = max(tek_kon, kon)
```

делает решение устойчивым даже для пересекающихся или соприкасающихся интервалов. Для станка детали по смыслу не должны обрабатываться одновременно, но такая запись не мешает искать свободные промежутки.

После цикла отдельно проверяется простой от конца последней обработки до конца рабочего дня `den`.

**Проверка на примере**

Для данных из условия занятые интервалы после сортировки:

```text
200-350
430-730
900-950
```

Свободные участки длиной не менее `100`: `0-200`, `730-900`, `950-1200`. Их три, максимальная длина равна `250`.

**Ответ**

```text
577 24426
```

## Прототип 4. Пассажиры на платформе метро

**Текст задания**

(М. В. Ишимов) В городском метрополитене на одной из станций работает система наблюдения, которая отслеживает пассажиров, зашедших в метро в течение суток, начиная с момента открытия метрополитена. Каждые `K` минут, начиная с `K`-й минуты от начала суток, на станцию прибывает очередной электропоезд. Высадка пассажиров на платформу и посадка с платформы на поезд занимает ровно одну минуту. С момента входа в метро пассажир находится на платформе станции. Посадка пассажиров происходит сразу же в момент прибытия электропоезда.

Входной файл содержит информацию о времени входа в метро каждого пассажира. Определите наибольшее количество пассажиров за 24 часа, которые одновременно находились на платформе по окончании посадки очередного электропоезда, и количество пассажиров, которые ожидали посадки на этот электропоезд не менее одной минуты. Если таких электропоездов несколько, выберите тот электропоезд, который прибыл последним за сутки.

В первой строке входного файла находится натуральное число `N` - количество пассажиров. Во второй строке находится число `K` - интервал движения электропоезда на станции. Следующие `N` строк содержат по одному числу - минуту, в которую пассажир зашёл в метро.

Запишите в ответе два числа: сначала найденное максимальное количество пассажиров, которые одновременно находились на платформе по окончании посадки электропоезда, затем количество тех пассажиров, которые ожидали посадки на этот же электропоезд не меньше одной минуты.

**Идея решения**

Поезд приходит в минуты:

```text
K, 2K, 3K, ...
```

Пассажир садится на ближайший поезд, который приходит не раньше его входа. Если пассажир вошёл ровно в минуту прибытия поезда, он сразу попадает на посадку и не считается ожидавшим не менее одной минуты.

Для каждого пассажира можно сразу определить поезд, на который он сядет:

```python
vrem_poezda = ((vhod + k - 1) // k) * k
```

Так как в задаче анализируются только сутки, учитываются только поезда с временем прибытия не больше `1440`.

Затем для каждого поезда считаем:

- сколько пассажиров сядет на него всего;
- сколько из них вошли раньше минуты прибытия поезда.

Если несколько поездов дают одинаковый максимум, нужен самый поздний. Поэтому при сравнении используется `>=`.

**Код решения**

```python
f = open('14_26.txt')
n = int(f.readline())
k = int(f.readline())

poezda = {}
zhdali = {}

for _ in range(n):
    vhod = int(f.readline())
    vrem_poezda = ((vhod + k - 1) // k) * k

    if vrem_poezda > 1440:
        continue

    if vrem_poezda not in poezda:
        poezda[vrem_poezda] = 0
        zhdali[vrem_poezda] = 0

    poezda[vrem_poezda] += 1
    if vhod < vrem_poezda:
        zhdali[vrem_poezda] += 1

maks = 0
otv_zhdali = 0

for vrem_poezda in sorted(poezda):
    if poezda[vrem_poezda] >= maks:
        maks = poezda[vrem_poezda]
        otv_zhdali = zhdali[vrem_poezda]

print(maks, otv_zhdali)
```

**Разбор решения**

Словарь `poezda` хранит количество пассажиров, которые сядут на поезд с конкретным временем прибытия. Словарь `zhdali` для того же поезда хранит количество пассажиров, которые вошли строго раньше прибытия поезда.

Формула:

```python
vrem_poezda = ((vhod + k - 1) // k) * k
```

находит ближайшее число, кратное `k`, которое не меньше `vhod`. Например, при `k = 3` пассажиры с временами `5` и `6` попадут на поезд в минуту `6`, а пассажир с временем `8` - на поезд в минуту `9`.

Проверка:

```python
if vrem_poezda > 1440:
    continue
```

отбрасывает пассажиров, чей ближайший поезд прибывает уже после рассматриваемых суток.

Проверка:

```python
if vhod < vrem_poezda:
```

отделяет пассажиров, которые действительно ждали поезд. Если `vhod == vrem_poezda`, пассажир вошёл в момент прибытия и сразу сел, поэтому ожидания не было.

В финальном цикле поезда рассматриваются по возрастанию времени. При равенстве с максимумом ответ обновляется, потому что по условию нужен последний такой поезд за сутки.

**Проверка на примере**

При `K = 3` поезд в минуту `6` забирает пассажиров, вошедших в минуты `5`, `5` и `6`. Всего их `3`, но не менее одной минуты ждали только двое: пассажиры с временем входа `5`.

**Ответ**

```text
44 38
```
