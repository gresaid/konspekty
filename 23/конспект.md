В 23 задании считают число программ для исполнителя. Здесь **программа** — не код на Python, а последовательность команд, которая переводит одно число в другое. Нужно понять, сколько таких последовательностей ведут из начального числа в конечное и удовлетворяют условию.

**Что обычно дано в задаче**

| Что есть в условии | Что это означает |
|---|---|
| Начальное число | Из него стартует исполнитель |
| Конечное число | Его нужно получить |
| Набор команд | Все допустимые переходы между числами |
| Дополнительное условие | Ограничение на траекторию или на использование команд |

Обычно дополнительные условия бывают такими:
- траектория должна проходить через одно или несколько чисел;
- траектория не должна проходить через некоторое число;
- нужно использовать команду не более заданного числа раз;
- нужно, чтобы траектория содержала одно из чисел, но не оба;
- команда работает только при выполнении условия.

**Базовые понятия**

**Траектория вычислений** — это последовательность всех результатов, которые появляются после выполнения команд.

Пример: если из числа 2 получить 8 командами `+2`, `+2`, `+2`, то траектория будет такой: `4, 6, 8`.

**Число программ** — это число разных последовательностей команд, которые приводят к нужному результату.

**Главная модель**

Вместо того чтобы перечислять программы вручную, вводят функцию:

```python
def f(s, e):
    ...
```

| Обозначение | Смысл |
|---|---|
| `s` | текущее число |
| `e` | конечное число |
| `f(s, e)` | количество программ, переводящих `s` в `e` |

Это основной шаблон всей темы: нужно описать, из каких состояний можно попасть в цель и какие ветки сразу отсекаются.

**Каркас рекурсивного решения**

```python
def f(s, e):
    if ...:
        return 1
    if ...:
        return 0
    return f(...) + f(...) + ...
```

У этой конструкции всегда один смысл:
- `return 1` — нашли одну подходящую программу;
- `return 0` — текущая ветка уже не может привести к ответу;
- сумма вызовов — перебор всех допустимых следующих команд.

**Базовые случаи**

Выбор базовых условий зависит от направления движения.

| Ситуация | Условия |
|---|---|
| Команды увеличивают число | `if s == e: return 1` и `if s > e: return 0` |
| Команды уменьшают число | `if s == e: return 1` и `if s < e: return 0` |

Если число растёт, выше цели уходить уже нельзя. Если число убывает, нельзя опускаться ниже цели.

**Рекуррентная формула**

Если из текущего числа доступны несколько команд, число программ равно сумме всех способов продолжить путь.

```python
return f(следующее_1, e) + f(следующее_2, e) + ...
```

Например, для команд `+1` и `*2`:

```python
def f(s, e):
    if s == e:
        return 1
    if s > e:
        return 0
    return f(s + 1, e) + f(s * 2, e)
```

**Как оформлять типовые ограничения**

| Ограничение | Как учитывать |
|---|---|
| Нужно просто посчитать все пути | Суммировать все переходы |
| Нужно пройти через число `k` | Разбить путь на участки и перемножить результаты |
| Нельзя проходить через число `x` | Добавить запрет: `if s == x: return 0` |
| Нужно помнить историю пути | Добавить параметры: счётчики, флаги |
| Команда доступна не всегда | Делать ветвление через `if` |
| Нужно найти не число программ, а конечное число | Перебрать возможные `e` |

**Обязательная промежуточная точка**

Если траектория обязана пройти через число `k`, ответ не считается одним вызовом `f(start, finish)`. Путь нужно разбить:

```python
f(start, k) * f(k, finish)
```

Здесь стоит произведение, а не сумма:
- сначала выбираем программу от старта до `k`;
- потом выбираем программу от `k` до финиша;
- каждый первый выбор можно соединить с каждым вторым.

Если обязательных точек несколько, формула расширяется:

```python
f(start, a) * f(a, b) * f(b, finish)
```

**Запрещённые числа**

Если траектория не должна содержать число `x`, его объявляют запрещённым состоянием:

```python
if s == x:
    return 0
```

Как только попали в запрещённую точку, эту ветку больше не считаем.

**Дополнительные параметры**

Если ответ зависит не только от текущего числа, но и от уже пройденного пути, в функцию добавляют новые параметры.

| Что нужно запомнить | Что удобно хранить |
|---|---|
| Сколько раз использовали команду | счётчик `k` |
| Проходили ли через нужное число | флаг `0/1` |
| Проходили ли через два специальных числа | два флага `f1`, `f2` |
| Какие команды уже встречались | строку или счётчик |

Примеры шаблонов:

```python
def f(s, e, k):
    ...
```

```python
def f(s, e, f1, f2):
    ...
```

**Условные команды**

Иногда одна из команд работает не всегда. Например: `прибавь 1, если число чётное`.

Тогда набор переходов зависит от текущего значения:

```python
if s % 2 == 0:
    return f(s + 1, e) + f(s * 2, e)
else:
    return f(s * 2, e)
```

Для нечётного числа первая команда просто недоступна.

**Поиск конечного числа**

Иногда в ответе нужно получить не количество программ, а само число `e`, для которого это количество известно заранее.

Тогда используют внешний перебор:

```python
for e in range(...):
    if f(start, e) == нужное_число:
        print(e)
```

Сама функция `f` при этом остаётся той же: она по-прежнему считает число программ для фиксированной цели.

**Алгоритм разбора задачи**

1. Определить, в какую сторону движется число: вверх или вниз.
2. Выбрать правильные базовые случаи.
3. Выписать все допустимые команды как переходы.
4. Проверить, есть ли обязательные или запрещённые числа.
5. Проверить, зависит ли ответ от истории пути.
6. Если зависит, добавить параметры в функцию.
7. Записать рекуррентную формулу.

**Типичные ошибки**

| Ошибка | Что идёт не так |
|---|---|
| Перепутано направление неравенства | рекурсия считает лишние ветки или обрывает нужные |
| В точке `s == e` возвращается `0` | готовая программа не засчитывается |
| При обязательной точке используется сумма | считается не то ограничение |
| Запрещённое число не отсечено | в ответ попадают лишние траектории |
| Не добавлен счётчик или флаг | невозможно учесть условие про историю пути |
| Неверно обработан `//` или `int(s ** 0.5)` | появляются неправильные переходы |

**Шпаргалка**

- Сумма рекурсивных вызовов — перебор всех допустимых команд.
- `1` возвращаем только тогда, когда пришли ровно в цель.
- `0` возвращаем, когда ветка больше не может дать ответ.
- Обязательная точка даёт произведение.
- Запрещённая точка даёт `0`.
- История пути требует дополнительных параметров.

### Прототип 1. Простой пример

**Текст задания**

У калькулятора есть две команды:
1. Прибавь 2
2. Умножь на 2

Сколько существует программ, которые число 2 преобразуют в число 8?

**Идея решения**

Эту задачу удобно сначала разобрать вручную. Из 2 в 8 можно прийти тремя способами:
- `+2, +2, +2`;
- `+2, *2`;
- `*2, *2`.

**Код решения**

```python
def f(s, e):
    if s == e:
        return 1
    if s > e:
        return 0
    return f(s + 2, e) + f(s * 2, e)

print(f(2, 8))
```

**Разбор решения**

Функция перебирает все допустимые первые команды из числа `s`:
- либо прибавляем 2;
- либо умножаем на 2.

Количество программ из `s` в `e` равно сумме количеств программ из новых состояний. Если дошли до 8, получили одну готовую программу. Если перескочили цель, эту ветку больше не учитываем.

**Ответ**

3

### Прототип 2. Траектория обязана проходить через числа 7 и 16

**Текст задания**

Исполнитель Май преобразует число на экране. У исполнителя есть две команды:
1. Прибавить 1
2. Умножить на 2

Сколько существует программ, для которых при исходном числе 2 результатом является число 39 и при этом траектория вычислений содержит числа 7 и 16?

**Идея решения**

Траектория обязана пройти через обе точки, причём при таких командах порядок единственный: `2 -> 7 -> 16 -> 39`. Поэтому путь удобно разбить на три участка и перемножить их количества.

**Код решения**

```python
def f(s, e):
    if s == e:
        return 1
    if s > e:
        return 0
    return f(s + 1, e) + f(s * 2, e)

print(f(2, 7) * f(7, 16) * f(16, 39))
```

**Альтернативный вариант через флаги**

```python
def f(s, e, f1, f2):
    if s == 7:
        f1 = 1
    if s == 16:
        f2 = 1
    if s == e and f1 == 1 and f2 == 1:
        return 1
    if s > e:
        return 0
    return f(s + 1, e, f1, f2) + f(s * 2, e, f1, f2)

print(f(2, 39, 0, 0))
```

**Разбор решения**

Здесь всё держится на том же шаблоне: из каждого числа есть два перехода, `+1` и `*2`.

Новое по сравнению с простым примером — обязательные точки. Нельзя сразу считать `f(2, 39)`, потому что не каждая программа проходит через 7 и 16. Поэтому отдельно считаем:
- сколько путей из 2 в 7;
- сколько путей из 7 в 16;
- сколько путей из 16 в 39.

Потом перемножаем результаты, потому что любой путь на первом участке можно соединить с любым путём на следующих двух.

**Ответ**

45

### Прототип 3. Движение на убывание и запрет на число

**Текст задания**

Исполнитель преобразует число на экране. У исполнителя есть три команды:

A. Вычти 3  
B. Найди целую часть от деления на 3  
C. Найди целую часть от деления на 2

Сколько существует программ, для которых при исходном числе 46 результатом является число 3 и при этом траектория вычислений содержит число 20 и не содержит числа 28?

**Идея решения**

Число уменьшается, значит рекурсию строим на движение вниз. Число 20 должно встретиться в траектории, а число 28, наоборот, встречаться не должно.

**Код решения**

```python
def f(s, e):
    if s == e:
        return 1
    if s < e or s == 28:
        return 0
    return f(s - 3, e) + f(s // 3, e) + f(s // 2, e)

print(f(46, 20) * f(20, 3))
```

**Альтернативный вариант через флаги**

```python
def f(s, e, f1, f2):
    if s == 20:
        f1 = 1
    if s == 28:
        f2 = 1
    if s == e and f1 == 1 and f2 == 0:
        return 1
    if s < e or f2 == 1:
        return 0
    return f(s - 3, e, f1, f2) + f(s // 3, e, f1, f2) + f(s // 2, e, f1, f2)

print(f(46, 3, 0, 0))
```

**Разбор решения**

Главное отличие здесь — направление движения:
- раньше число росло, и лишними были значения `s > e`;
- теперь число убывает, поэтому лишними становятся значения `s < e`.

Ещё одно отличие — запрещённое число. Если в какой-то момент получили 28, ветка сразу отбрасывается, поэтому возвращаем `0`.

Команды деления записаны как `//`, потому что по условию нужна целая часть от деления.

**Ответ**

12

### Прототип 4. Команда с квадратным корнем

**Текст задания**

Исполнитель преобразует число на экране. У исполнителя есть три команды:

A. Вычесть 4  
B. Вычесть 7  
C. Извлечь целый квадратный корень

Команда C извлекает из числа квадратный корень, а в случае нецелого результата значение округляется до ближайшего меньшего целого.

Сколько существует программ, для которых при исходном числе 44 результатом является число 3 и при этом траектория вычислений содержит число 22?

**Идея решения**

Как и в предыдущем прототипе, движение идёт на уменьшение. Число 22 должно обязательно встретиться в траектории, поэтому ответ снова равен произведению двух участков. Особенность задачи в третьей команде: вместо обычного деления используется целая часть квадратного корня.

**Код решения**

```python
def f(s, e):
    if s == e:
        return 1
    if s < e:
        return 0
    return f(s - 4, e) + f(s - 7, e) + f(int(s ** 0.5), e)

print(f(44, 22) * f(22, 3))
```

**Альтернативный вариант через флаги**

```python
def f(s, e, f1, f2):
    if s == 22:
        f1 = 1
    if s == e and f1 == 1:
        return 1
    if s < e:
        return 0
    return f(s - 4, e, f1, f2) + f(s - 7, e, f1, f2) + f(int(s ** 0.5), e, f1, f2)

print(f(44, 3, 0, 0))
```

**Разбор решения**

Первые две команды обычные: уменьшаем число на 4 или на 7.

С третьей командой нужна аккуратность. В условии сказано, что нецелый корень округляется вниз, поэтому удобно писать:

```python
int(s ** 0.5)
```

Например, из 20 получаем `int(20 ** 0.5) = 4`.

Дальше схема обычная: базовый случай `s == e`, отсечение `s < e`, разбиение через обязательную точку 22.

**Ответ**

54

### Прототип 5. Траектория должна содержать одно из двух чисел, но не оба

**Текст задания**

Исполнитель преобразует число на экране. У исполнителя есть три команды:

A. Прибавь 1  
B. Умножь на 2  
C. Умножь на 3

Сколько существует программ, для которых при исходном числе 10 результатом является число 70 и при этом траектория вычислений содержит число 30 или число 60, но не оба числа одновременно?

**Идея решения**

Здесь уже нужно помнить историю пути: встретилось ли число 30 и встретилось ли число 60. Поэтому в функцию добавляются два флага.

**Код решения**

```python
def f(s, e, f1, f2):
    if s == e and f1 + f2 == 1:
        return 1
    if s > e:
        return 0
    if s == 30:
        f1 = 1
    if s == 60:
        f2 = 1
    return f(s + 1, e, f1, f2) + f(s * 2, e, f1, f2) + f(s * 3, e, f1, f2)

print(f(10, 70, 0, 0))
```

**Альтернативный вариант через флаги**

Этот прототип уже решён через флаги. Здесь это не дополнительный приём, а основной способ записать условие про числа 30 и 60.

**Разбор решения**

Одной переменной `s` здесь уже недостаточно: ответ зависит не только от текущего числа, но и от того, какие числа уже встретились в траектории.

Параметры:
- `f1 = 1`, если уже встретилось число 30;
- `f2 = 1`, если уже встретилось число 60.

В конце подходит только та программа, для которой ровно один флаг равен 1. Это проверяется условием:

```python
f1 + f2 == 1
```

Если оба флага равны 1, траектория прошла через оба числа, а это уже не подходит.

**Ответ**

95

### Прототип 6. Ограничение на число использований команд

**Текст задания**

Исполнитель преобразует число, записанное на экране. У исполнителя есть три команды:
1. Прибавь 1
2. Умножь на 2
3. Умножь на 3

Сколько существует различных программ, которые преобразуют исходное число 1 в число 100 и содержат не более двух команд умножения?

**Идея решения**

Здесь мало просто считать пути. Нужно ещё следить, сколько раз использовались команды умножения. Для этого добавляем счётчик.

**Код решения**

```python
def f(s, e, k):
    if s == e and k <= 2:
        return 1
    if s > e:
        return 0
    return f(s + 1, e, k) + f(s * 2, e, k + 1) + f(s * 3, e, k + 1)

print(f(1, 100, 0))
```

**Альтернативный вариант через флаги**

```python
def f(s, e, f1, f2):
    if s == e:
        return 1
    if s > e:
        return 0
    ans = f(s + 1, e, f1, f2)
    if f1 == 0:
        ans += f(s * 2, e, 1, f2) + f(s * 3, e, 1, f2)
    elif f2 == 0:
        ans += f(s * 2, e, f1, 1) + f(s * 3, e, f1, 1)
    return ans

print(f(1, 100, 0, 0))
```

**Разбор решения**

Параметр `k` хранит, сколько раз уже была использована команда умножения.

Особенность проверки:
- команда `+1` не меняет `k`;
- команды `*2` и `*3` увеличивают `k` на 1.

В базовом случае программа засчитывается только тогда, когда дошли до 100 и использовали не больше двух умножений.

Ту же идею можно записать не числом, а строкой из символов команд, но счётчик здесь проще и короче.

**Ответ**

1565

### Прототип 7. Нужно найти конечное число по количеству программ

**Текст задания**

Калькулятор преобразует число, записанное на экране. У исполнителя есть три команды:
1. Прибавь 1
2. Прибавь 5
3. Умножь на 3

Определите число, для получения которого из числа 1 существует 175 программ.

**Идея решения**

Здесь неизвестно конечное число, зато известно количество программ. Поэтому перебираем возможные значения `e` и для каждого считаем число программ из 1 в `e`.

**Код решения**

```python
def f(s, e):
    if s == e:
        return 1
    if s > e:
        return 0
    return f(s + 1, e) + f(s + 5, e) + f(s * 3, e)

for e in range(1, 100):
    v = f(1, e)
    if v == 175:
        print(e)
```

**Альтернативный вариант через флаги**

В этом прототипе флаги ничего не упрощают. Ограничение связано не с историей пути, а с подбором конечного числа, поэтому естественный способ остаётся тем же: для каждого кандидата `e` отдельно считать `f(1, e)`.

**Разбор решения**

Функция `f` здесь обычная: считает число программ из 1 в фиксированное `e`.

Вся новизна здесь во внешнем цикле. Мы последовательно проверяем все кандидаты на ответ и останавливаемся на том значении, для которого число программ равно 175.

Такой приём нужен, когда в условии спрашивают не число программ, а само число, для которого это количество получается.

**Ответ**

19

### Прототип 8. Условная команда

**Текст задания**

Калькулятор преобразует число, записанное на экране. У исполнителя есть две команды:
1. Прибавь 1, если число чётное
2. Умножь на 2

Сколько существует программ, которые преобразуют исходное число 3 в число 21?

**Идея решения**

Вторая команда доступна всегда, а первая только для чётных чисел. Поэтому набор переходов зависит от текущего значения `s`.

**Код решения**

```python
def f(s, e):
    if s == e:
        return 1
    if s > e:
        return 0
    if s % 2 == 0:
        return f(s + 1, e) + f(s * 2, e)
    else:
        return f(s * 2, e)

print(f(3, 21))
```

**Альтернативный вариант через флаги**

```python
def f(s, e, f1, f2):
    if s == e:
        return 1
    if s > e:
        return 0
    if s % 2 == 0:
        f1 = 1
        return f(s + 1, e, f1, f2) + f(s * 2, e, f1, f2)
    return f(s * 2, e, f1, f2)

print(f(3, 21, 0, 0))
```

**Разбор решения**

Здесь важны не базовые случаи, а сами разрешённые переходы.

Если число чётное, доступны две команды:
- `+1`;
- `*2`.

Если число нечётное, первая команда недоступна, поэтому остаётся только умножение на 2.

Из-за такого ограничения часть чисел вообще недостижима. В этой задаче нужного пути нет, поэтому ответ равен 0.

**Ответ**

0
